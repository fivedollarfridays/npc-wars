# Bot Showcase

Community-submitted bots. Submit yours via PR!

## How to Submit

1. Build your bot: `npcwars wizard` or write it by hand
2. Validate: `npcwars validate bots/your_bot.py`
3. Copy to `showcase/your_bot.py`
4. Open a PR -- must pass `npcwars validate`

## Rules

- Your bot must pass validation (no blocked imports, valid actions, 1-second timeout)
- Unique emoji -- check existing bots first
- Max 3 bots per author
- Bots are merged as-is -- this is a gallery, not a curated roster
