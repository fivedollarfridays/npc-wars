# Objective

Enforce a single leader: only the bot with the highest score can be at tier 3 or 4. All other bots are capped at tier 2 regardless of score. If the leader is overtaken, the crown transfers instantly.

# Design

- **Leader**: The alive bot with the highest `bot.score`. Ties broken by kills, then alphabetically by emoji.
- **Tier cap for non-leaders**: Max tier 2 (Battle Fury). Score still accumulates normally — they just don't get tier 3/4 bonuses.
- **Crown transfer**: When a bot overtakes the leader's score, they become the new leader. The old leader drops to tier 2 max. This happens every round after scoring.
- **New state field**: `state["me"]["is_leader"]` (bool) — bots know if they're the leader.
- **New state field for enemies**: `state["enemies"][i]["is_leader"]` (bool) — everyone sees who leads.

# Implementation Plan

1. **Add `determine_leader()` to `engine/momentum.py`**:
   - Takes list of alive bots, returns the leader bot (or None if 0-1 alive)
   - Highest score wins. Ties: most kills, then emoji sort.

2. **Modify `apply_momentum_bonuses()`**:
   - Add `is_leader: bool` parameter
   - If not leader: cap `momentum_tier` at 2 (even if score qualifies for 3+)
   - If leader: apply all tiers normally

3. **Add `is_leader: bool` field to Bot class** (`engine/combat.py`):
   - Initialized to False
   - Set by the game loop each round
   - Include in `to_self_dict()` and `to_enemy_dict()`

4. **Update game loop** (`engine/game.py`):
   - After scoring, call `determine_leader(alive_bots)`
   - Set `bot.is_leader` for each bot
   - Pass `is_leader` to `apply_momentum_bonuses()`

5. **Tests** in `tests/test_leader.py`:
   - Leader is bot with highest score
   - Tie-breaking: kills, then emoji
   - Non-leader capped at tier 2 even with 60+ score
   - Leader gets full tier 3/4 bonuses
   - Crown transfers when overtaken
   - Dead bots cannot be leader
   - State dict has `is_leader` field
