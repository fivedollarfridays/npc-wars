# Objective

Update player profiles after each match with win/loss/streak data. The winner's profile is updated with incremented wins and streak; losers have their streaks reset. Line budgets are recalculated and profiles are saved to disk.

# Implementation Plan

1. **Create `tests/test_profile_match_update.py`** with tests for:
   - Winner's `wins` field is incremented by 1
   - Winner's `current_streak` is incremented by 1
   - Loser's `current_streak` is reset to 0
   - `line_budget` is recalculated after profile update
   - Profiles are saved to disk after match ends
   - New bots (no existing profile) get a fresh profile via `get_or_create_profile`

2. **In `engine/game.py` after match ends**:
   - Load profiles from `data/profiles.json` via `load_profiles`
   - For each bot in the match, call `get_or_create_profile` to ensure a profile exists
   - Call `update_after_match(profile, won=True/False, beat_watcher=True/False)` for each bot
   - Save updated profiles to disk via `save_profiles`

3. **Handle edge cases**:
   - New bots that have never played get fresh profiles with defaults
   - Watcher encounters tracked when The Watcher was in the match

# Acceptance Criteria

- [x] Winner's wins incremented
- [x] Winner's current_streak incremented
- [x] Losers' current_streak reset to 0
- [x] line_budget recalculated after update
- [x] Profiles saved to disk after match
- [x] New bots get fresh profiles
