# Objective

Create a web page showing tournament brackets and a spectator view for watching tournament matches.

# Implementation Plan

1. Create `server/static/tournament.html`:
   - Fetch /api/tournament/{id} for bracket data
   - Render bracket visualization (SVG or canvas):
     - Connected lines showing progression
     - Each match shows players, winner highlighted
     - Current round highlighted
   - Link to watch replay for each completed match
   - Auto-refresh during live tournament

2. Add tournament list page at `server/static/tournaments.html`:
   - Fetch /api/tournaments
   - Show active and recent tournaments
   - "Join" button for open tournaments
   - Link to bracket page

3. Add FastAPI routes for tournament pages:
   - GET /tournament/{id} → serve tournament.html
   - GET /tournaments → serve tournaments.html

4. Dark cyberpunk theme matching existing pages

5. Tests for page existence and API data shape

# Acceptance Criteria

- [ ] Bracket visualization shows tournament progression
- [ ] Completed matches link to replays
- [ ] Tournament list shows active/recent
- [ ] Pages auto-refresh during live tournament
