# Objective

Replace flat `calculate_damage()` in `resolve_attacks()` with `roll_attack()` from combat_rolls.py. Add rng parameter. Handle CombatResult: hit applies damage, miss emits new event type.

# Implementation Plan

1. Add `rng: random.Random` parameter to `resolve_attacks()`
2. Replace damage calculation:
   - OLD: `dmg = calculate_damage(bot, target)`
   - NEW: `result = roll_attack(bot.derived, target.derived, defending=is_defending, rng=rng, momentum_damage_mult=bot.momentum_damage_multiplier, momentum_defense_reduct=target.momentum_defense_reduction)`
3. Need to determine if target is defending: check `actions.get(target.emoji)` == ("defend",)
4. If result.hit: apply damage as before
5. If not result.hit: emit `{"type": "attack_miss", "attacker": bot.emoji, "target": target.emoji, "roll": result.roll, "ac": result.target_ac}`
6. Pass rng from `_resolve_combat_phases()` to `resolve_attacks()`
7. Update existing tests that assert exact damage values — use seeded RNG or range assertions

# IMPORTANT: rounds.py is at 334 LOC
Do NOT add net lines. Replace the damage calculation inline. If needed, extract helpers to combat_rolls.py.
