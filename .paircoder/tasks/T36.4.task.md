# Objective

Add feed formatters and overlay FX for tactical activations, ability usage, and evolve events.

# Implementation Plan

1. Add to `agentgrounds/wars/cli/feed.py`:
   - `_fmt_tactical_activate` — "R{rnd}: {emoji} ⚡ Battle Cry! +50% damage"
   - `_fmt_ability_use` — "R{rnd}: {emoji} 🔮 Fireball → {target} -{potency}hp"
   - `_fmt_evolve` — "R{rnd}: {emoji} 🧬 evolved! +{boost} potency"
   - Register all in _FORMATTERS

2. Add to overlay:
   - Tactical activation: ⚡ on bot's tile
   - Ability damage: 🔮 on target tile
   - Evolve: 🧬 on bot's tile

3. Tests in `tests/test_tactical_feed.py`

# Acceptance Criteria

- [ ] Tactical, ability, and evolve events render in feed
- [ ] Overlay shows FX at correct positions
- [ ] Tests pass, ruff clean
