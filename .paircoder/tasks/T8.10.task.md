# Objective

Render bump events in the HTML viewer with directional arrows and impact effects.

# Implementation Plan

1. In `viewer/match.html` `renderRound` event handling, add cases for new event types:
   - `"bump"`: draw arrow from pusher's previous position to target's new position
   - `"chain_bump"`: draw connected arrows in distinct color (orange)
   - `"wall_splat"`: red flash overlay on edge tile + screen edge pulse
   - `"storm_bounce"`: purple pulse on storm tile where bot landed
2. Add CSS keyframe animations for bump effects
3. Update kill feed to show bump events (e.g., "bumped into wall!")

# Acceptance Criteria

- [x] Bump events render as directional indicators on canvas
- [x] Wall splat shows red flash on edge tile
- [x] Storm bounce shows purple pulse
- [x] Chain bumps show connected arrow chain
- [x] No visual regression for existing hit/miss/kill/storm_damage events
- [x] Kill feed includes bump descriptions
