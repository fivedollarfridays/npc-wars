# Objective

Wire trap triggering into the combat loop. After movement resolution, check if any bot stepped onto an enemy trap. Apply damage, generate events, and clean up triggered traps.

# Implementation Plan

1. Add `TrapManager` instance to match state (created in `_prepare_match()`, passed through round execution)
2. In `_resolve_combat_phases()` (engine/game.py), after `resolve_movement()`:
   - For each alive bot, call `trap_manager.check_triggers(bot, round_num)`
   - Apply trap damage to the bot (respects armor DR)
   - Generate trap trigger events: `{"type": "trap_trigger", "victim": emoji, "owner": owner_emoji, "damage": N, "x": x, "y": y}`
   - Remove triggered traps
3. In `_resolve_combat_phases()`, handle trap placement:
   - Parse `("trap", direction)` from actions dict
   - Call `trap_manager.place_trap()` during action phase
   - Generate placement events: `{"type": "trap_placed", "emoji": owner, "x": x, "y": y}`
4. At end of each round, call `trap_manager.expire_traps(round_num)`
5. On bot death, call `trap_manager.remove_dead_bot_traps(emoji)`
6. Trap damage contributes to damage_dealt/damage_taken stats
7. Trap kills attributed correctly (killed_by = trap owner)

# Acceptance Criteria

- [ ] Bots take damage when stepping on enemy traps
- [ ] Trap damage respects armor DR
- [ ] Triggered traps are removed
- [ ] Trap trigger events appear in round data
- [ ] Trap kills correctly attributed to trap owner
- [ ] Expired traps cleaned up each round
- [ ] Dead bot traps cleaned up
- [ ] Trap damage counts in damage_dealt/damage_taken stats
- [ ] Tests pass, ruff clean
