# Objective

Calculate win streaks from match results for profile updates. Wins increment the current streak; losses reset it to zero. The best streak is preserved across losses.

# Implementation Plan

1. **Create `tests/test_win_streak.py`** with tests for:
   - Profile with 0 wins has current_streak == 0
   - Single win sets current_streak to 1
   - Consecutive wins increment current_streak
   - Loss resets current_streak to 0
   - best_streak is updated when current_streak exceeds it
   - Loss does NOT reset best_streak

2. **Add to `data/player_profiles.py`**:
   - `update_streak(profile: PlayerProfile, won: bool) -> None`
     - If `won`: increment `current_streak` by 1, update `best_streak` if `current_streak > best_streak`
     - If not `won`: reset `current_streak` to 0

# Acceptance Criteria

- [x] Win increments current_streak by 1
- [x] Loss resets current_streak to 0
- [x] best_streak updated when current_streak exceeds it
- [x] Loss does NOT reset best_streak
