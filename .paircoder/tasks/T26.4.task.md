# Objective

Update the CLI renderer to show the leader's crown, bounty indicator, and energy drain in the display.

# Display Changes

## Roster

Leader gets a 👑 crown prefix:
```
  Combatants
  🤖 AggroBot     ██████████ 100hp ⚡95  [12 pts]
  👑🐢 TankBot    ██████████ 100hp ⚡72  [45 pts] 🔥CROWD FAVORITE  ⚡-5/rd
  🧠 Cognify      █████████░  90hp ⚡15  [28 pts] ⚡BATTLE FURY  ⚡-3/rd
```

- Leader has 👑 prefix before their emoji
- Tier 2+ shows drain cost: `⚡-3/rd`, `⚡-5/rd`, `⚡-8/rd`
- Only leader can show tier 3/4 labels

## Kill Feed

Leader bounty kill:
```
  R15: 🤖 👑 REGICIDE! eliminated leader 🐢 +20pts
```

## Grid

Leader's aura is more prominent (already handled by tier 3+ in overlay.py — just ensure only the leader gets it now).

# Implementation Plan

1. **Update `_roster()` in renderer.py**:
   - Check `p.get("is_leader", False)` — if True, prefix emoji with 👑
   - Show drain cost for tier 2+ bots

2. **Update `feed.py`**:
   - Add `_fmt_leader_bounty()` formatter for the `leader_bounty` event type
   - Show 👑 REGICIDE! message

3. **Verify aura only shows for leader** — overlay.py `build_aura_overlay()` checks `momentum_tier >= 3`, which with the one-leader rule only the leader can be. Confirm this works.

4. **Tests**: roster shows crown, drain rate, bounty in feed
