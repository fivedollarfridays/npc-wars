# Objective

Add character preview rendering to the web profile page and bot editor. Players see what their bot looks like before fighting.

# Implementation Plan

1. Add to `server/static/profile.html`:
   - Small canvas showing the player's character shape
   - Uses character descriptor from API
   - Static render (no animation)

2. Add to `viewer/js/shapes.js`:
   - Export `drawCharacterPreview(canvasId, descriptor)` function
   - Draws character at center of given canvas element
   - Can be loaded as standalone script on profile/editor pages

3. Add character descriptor to profile API:
   - GET /api/stats/{player_id} includes latest bot's character descriptor

# Acceptance Criteria

- [ ] Profile page shows character preview canvas
- [ ] Character matches the bot's actual stats/equipment
- [ ] Preview renders without the full viewer loaded
