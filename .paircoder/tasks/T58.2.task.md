# Kill Switch personality profiler

Build `engine/personality.py` to analyze bot behavior across matches and generate personality profiles. Consume stat_diff history, action frequency from pattern tables, equipment choices, and callback usage. Output a trait list (e.g., "aggressive opener", "trap-obsessed", "storm dodger"), archetype variant name, and flavor bio. Used by commentary, episode intros, and viewer overlays.

# Acceptance Criteria

- [ ] `profile_bot(emoji, results_dir, patterns_dir)` returns profile dict with traits, archetype_variant, bio
- [ ] At least 10 distinct traits detected from behavior patterns
- [ ] Bio is a 1-2 sentence generated description (template-based, no LLM)
- [ ] Graceful on first match (returns "Unknown" archetype, generic bio)
- [ ] Tests cover varied bot behaviors (aggressive, defensive, balanced, trap-heavy)
- [ ] File under 200 LOC, ruff clean
