# Viewer commentary ticker

Build `viewer/js/commentary.js` — a text ticker at the bottom of the browser replay that displays commentary lines, auto-advancing with round playback. Reads from the `commentary` key in match JSON. Shows play-by-play in white, color commentary in gold. Fades in/out with round transitions. Toggleable via controls.

# Acceptance Criteria

- [ ] Commentary ticker renders below canvas during replay
- [ ] Auto-advances with round playback, manual scrubbing updates commentary
- [ ] Play-by-play and color commentary visually distinct
- [ ] Toggle button in controls panel
- [ ] Graceful when match JSON has no commentary key
- [ ] Works with existing replay controls (play, pause, speed, scrub)
- [ ] File under 200 LOC
