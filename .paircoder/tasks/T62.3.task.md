# Viewer commentary ticker

Build `viewer/js/commentary.js` — a text ticker at the bottom of the browser replay that displays commentary lines, auto-advancing with round playback. Reads from the `commentary` key in match JSON. Shows play-by-play in white, color commentary in gold. Fades in/out with round transitions. Toggleable via controls.

# Acceptance Criteria

- [x] Commentary ticker renders below canvas during replay
- [x] Auto-advances with round playback, manual scrubbing updates commentary
- [x] Play-by-play and color commentary visually distinct
- [x] Toggle button in controls panel
- [x] Graceful when match JSON has no commentary key
- [x] Works with existing replay controls (play, pause, speed, scrub)
- [x] File under 200 LOC
