# Objective

Create `engine/glyphs.py` with an approved glyph registry and validation. Wire BOT_GLYPH into loader, Bot class, round records, and game players array.

# Acceptance Criteria

- [ ] APPROVED_GLYPHS frozenset with ~60 Unicode chars
- [ ] DEFAULT_GLYPH = "◆"
- [ ] validate_glyph() returns valid glyph or DEFAULT_GLYPH with warning
- [ ] is_valid_glyph() for testing
- [ ] Loader reads BOT_GLYPH, falls back to BOT_EMOJI
- [ ] Bot class has glyph field, defaults to emoji
- [ ] to_self_dict() and to_enemy_dict() include glyph
- [ ] build_round_record() includes glyph in position data
- [ ] players array includes glyph
- [ ] Tests pass, ruff clean, < 400 lines
