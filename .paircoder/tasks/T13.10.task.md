# Objective

Implement seasonal leaderboards with periodic resets. Each season has defined start/end dates. At season boundary, current stats are archived and active stats reset. The Watcher's `__global__` profile resets per season, but player line budgets do NOT reset (earned progression is permanent). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 11 (Seasonal leaderboard) and Section 14 (Seasonal resets).

# Implementation Plan

1. **Create `tests/test_seasonal.py`** with tests for:
   - `Season` model has `start_date`, `end_date`, `name` (e.g., "Season 1: The Goose Awakens")
   - Starting a new season resets win counts, kill counts, and streak stats
   - Archived seasons are queryable (get stats for a past season by name/number)
   - Player line budgets persist across season resets (NOT reset)
   - Watcher `__global__` profile resets on new season
   - Watcher per-player profiles persist across seasons
   - `is_season_active(season, current_date)` returns correct boolean
   - `archive_season(season, leaderboard_data)` stores snapshot

2. **Add to `data/leaderboard.py`** (or create if it does not exist):
   - `Season` dataclass: `name: str`, `number: int`, `start_date: str`, `end_date: str`
   - `SeasonalLeaderboard` class with:
     - `current_season: Season`
     - `archived: list[dict]` — list of `{"season": Season, "stats": leaderboard_snapshot}`
     - `start_new_season(name: str, start_date: str, end_date: str) -> None` — archives current, resets active stats
     - `archive_season() -> None` — snapshots current leaderboard data
     - `get_archived(season_number: int) -> dict | None` — returns archived season stats
     - `is_season_boundary(current_date: str) -> bool` — checks if current season has ended
   - Reset logic: zero out wins, kills, streaks for all players; preserve line_budget
   - Watcher reset: call `decay_memory(pattern_table, 0.0)` on `__global__` only (or reset it directly)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Stats reset at season boundary
- [ ] Archived seasons are queryable
- [ ] Watcher global profile resets per season
- [ ] Player line budgets do NOT reset
