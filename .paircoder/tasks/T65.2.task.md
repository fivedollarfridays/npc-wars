# Decision tracer

Build `engine/decision_trace.py` to instrument `decide()` execution and capture which branch fired each round. Run bot's decide() in the existing sandbox with a tracing wrapper that records: conditions evaluated, which branch taken, key state variables that influenced the decision. Output per-round decision trace added to match JSON under `decision_traces` key. Does NOT expose source code — captures execution path only.
