# Objective

Create the cosmetic item catalog and player inventory system. Cosmetics are visual overrides that don't affect gameplay.

# Cosmetic Types

| Type | Examples | Effect |
|------|----------|--------|
| color_palette | "Crimson", "Neon", "Ghost" | Override archetype color with custom hex |
| glow_effect | "Fire Aura", "Ice Shimmer", "Shadow" | Custom momentum aura color/style |
| weapon_skin | "Golden Blade", "Crystal Edge" | Override weapon indicator color |
| death_effect | "Shatter Gold", "Fade to Black" | Custom death animation color |
| trail_effect | "Spark Trail", "Smoke" | Movement trail behind character |

# Implementation Plan

1. Create `server/cosmetics.py`:
   - `COSMETIC_CATALOG` dict with all items: id, name, type, rarity, price, visual_data
   - Rarity tiers: common (100 coins), rare (300), epic (800), legendary (2000)
   - ~20 cosmetic items across 5 types

2. Add to `server/db.py`:
   - `cosmetic_inventory` table: player_id, cosmetic_id, equipped (bool), purchased_at
   - `player_coins` table: player_id, balance
   - `purchase_cosmetic(conn, player_id, cosmetic_id) -> bool`
   - `get_player_inventory(conn, player_id) -> list[dict]`
   - `equip_cosmetic(conn, player_id, cosmetic_id) -> bool`
   - `get_equipped_cosmetics(conn, player_id) -> dict` (type -> cosmetic)
   - `award_coins(conn, player_id, amount)` — called after matches
   - `get_coin_balance(conn, player_id) -> int`

3. Coin rewards: 10 coins per match played, 25 bonus for winning

4. Tests in `tests/test_cosmetics.py`

# Acceptance Criteria

- [ ] Catalog with ~20 items across 5 types
- [ ] Player can purchase cosmetics with coins
- [ ] Player can equip/unequip cosmetics
- [ ] Coins earned from matches
- [ ] Inventory persisted in database
- [ ] Tests pass, ruff clean
