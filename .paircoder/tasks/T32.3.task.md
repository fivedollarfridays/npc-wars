# Objective

Create `engine/profile_db.py` — SQLite persistence for player profiles with XP, level, and match stats. Separate from server/db.py (engine layer, no server dependency).

# Schema

```sql
CREATE TABLE IF NOT EXISTS profiles (
    name        TEXT PRIMARY KEY,
    total_xp    INTEGER NOT NULL DEFAULT 0,
    level       INTEGER NOT NULL DEFAULT 1,
    matches     INTEGER NOT NULL DEFAULT 0,
    wins        INTEGER NOT NULL DEFAULT 0,
    kills       INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);
```

# Implementation Plan

1. `init_profile_db(db_path: str) -> Connection` — create table idempotently
2. `get_or_create_profile(conn, name) -> dict` — upsert on first match
3. `update_profile(conn, name, xp_earned, kills, won) -> dict` — add XP, increment stats, recalculate level
4. `get_profile(conn, name) -> dict | None`
5. `list_profiles(conn, order_by="level", limit=20) -> list[dict]`
6. `get_leaderboard(conn, limit=10) -> list[dict]` — top profiles by level then XP
7. Default DB path: `data/profiles.db`
8. Tests in `tests/test_profile_db.py` (use `:memory:` for tests)

# Acceptance Criteria

- [ ] Schema created idempotently
- [ ] `get_or_create_profile()` creates on first call, returns existing on subsequent
- [ ] `update_profile()` correctly accumulates XP, kills, matches, wins
- [ ] Level recalculated on every update (import `level_from_xp` — optional dep with fallback)
- [ ] Tests use in-memory SQLite, no disk I/O
- [ ] Tests pass, ruff clean, < 400 lines
