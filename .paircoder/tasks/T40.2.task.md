# Objective

Create GitHub Actions workflow that publishes to PyPI on tagged releases. Set up version management.

# Implementation Plan

1. Create `.github/workflows/publish.yml`:
   - Trigger on: `push` with tag `v*` (e.g., v0.2.0)
   - Steps: checkout, setup python, build (`python -m build`), publish to PyPI (`twine upload`)
   - Use PyPI API token stored as GitHub secret (PYPI_API_TOKEN)
   - Also publish to TestPyPI first for validation

2. Update pyproject.toml:
   - Ensure all metadata is correct for PyPI (author, classifiers, URLs)
   - Add project.urls: Homepage, Repository, Documentation, Bug Tracker
   - Add classifiers: Python version, license, topic

3. Test the build locally:
   - `python -m build` produces .tar.gz and .whl
   - `pip install dist/agent_grounds-*.whl` works in fresh venv
   - All CLI commands work after wheel install

4. Version bump process documentation:
   - Edit version in pyproject.toml and agentgrounds/__init__.py
   - Tag release: `git tag v0.2.0`
   - Push tag: CI auto-publishes

# Acceptance Criteria

- [ ] `python -m build` produces valid sdist and wheel
- [ ] Wheel installs and CLI works from clean venv
- [ ] GitHub Actions workflow publishes on tag push
- [ ] pyproject.toml has complete PyPI metadata
