# Objective

Fix two viewer issues: aggressive flashing effects and fixed-size canvas that doesn't adapt to viewport.

# Issue 1: Flashing Effects

6 sources of flashing identified. Fix each without breaking the viewer:

## CSS Keyframes to disable/soften (in viewer/index.html)

| Animation | Line | Problem | Fix |
|-----------|------|---------|-----|
| `fire-border` | ~390 | Infinite orange glow pulsing | Remove infinite, single soft fade |
| `screen-shake` | ~383 | Rapid translate every 0.3s | Reduce intensity, single subtle shake |
| `glitch-rgb` | ~629 | RGB color separation strobe | Remove entirely |
| `skull-flash-fade` | ~675 | Full-screen white flash | Remove entirely |

## JS Effects to disable (in viewer/js/effects.js)

| Function | Line | Problem | Fix |
|----------|------|---------|-----|
| `skullFlashEffect()` | ~261 | White overlay flash | Make function no-op |
| `glitchEffect()` | ~166 | RGB strobe overlay | Make function no-op |
| `fire-border` application | ~113 | Applied as infinite CSS animation | Remove or single-play |

## Rules for all effects going forward:
- NO rapid opacity toggling (< 500ms cycles)
- NO full-screen color flashes
- NO infinite pulsing animations
- Smooth fades only (transition: opacity 0.5s+)
- Subtle glow/shadow OK, strobe NOT OK

# Issue 2: Responsive Canvas Sizing

## Current problem (viewer/js/app.js lines 104-106):
```javascript
canvas.width = gridSize * TILE_SIZE;  // TILE_SIZE = 48, fixed
canvas.height = gridSize * TILE_SIZE;
```
No resize handler. Canvas overflows on small screens, wastes space on large ones.

## Fix:
1. Calculate TILE_SIZE dynamically from viewport:
   ```javascript
   var arenaWrap = canvas.parentElement;
   var maxW = arenaWrap.clientWidth || window.innerWidth * 0.65;
   var maxH = window.innerHeight - 120;
   var maxSize = Math.min(maxW, maxH);
   TILE_SIZE = Math.max(24, Math.min(64, Math.floor(maxSize / gridSize)));
   ```
2. Add window resize handler:
   ```javascript
   window.addEventListener('resize', function() {
     if (matchData) {
       var gridSize = matchData.grid_size;
       // Recalculate but DON'T re-init (preserve playback state)
       // Just update CSS scaling
       var arenaWrap = canvas.parentElement;
       canvas.style.maxWidth = arenaWrap.clientWidth + 'px';
       canvas.style.height = 'auto';
     }
   });
   ```
3. Set canvas CSS: `max-width: 100%; height: auto;`

## CRITICAL: Test after each change
- Load a match, verify rendering works
- Resize browser window, verify canvas adapts
- Check mobile responsive mode (768px)
- Verify kill cam zoom still works (CSS transform on canvas)
- Verify existing spectacle effects still function (non-flash ones)
