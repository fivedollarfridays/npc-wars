# Objective

Upgrade viewer/js/shapes.js to use character descriptors from match JSON for weapon indicators, armor borders, momentum glow, and HP color gradients.

# Implementation Plan

1. Update `viewer/js/shapes.js`:
   - Read character descriptor from `matchData.players[].character`
   - Draw weapon indicator: small shape at 2 o'clock position
     - dot (dagger), short line (sword), long line (spear), wedge (axe), arc (bow), circle (mace)
   - Scale border thickness from descriptor (1-3px)
   - HP color gradient: interpolate from archetype color to gray based on HP%
   - Momentum aura: ctx.shadowBlur glow for tier 3+, pulsing for leader

2. Update `viewer/js/renderer.js`:
   - Pass character descriptor to drawBotShape when available
   - Fall back to archetype-only rendering for old match JSONs

3. Add character preview function:
   - `drawCharacterPreview(ctx, descriptor, x, y, size)` — standalone render for profiles/editors

# Acceptance Criteria

- [ ] Weapon indicators visible on character shapes
- [ ] Armor border thickness varies by type
- [ ] HP affects color saturation smoothly
- [ ] Momentum tier 3+ shows glow aura
- [ ] Leader has pulsing aura
- [ ] Old match JSONs still render (fallback)
