# Objective

Implement The Watcher's decision-making brain that selects optimal counter-actions based on predicted human behavior. Given the pattern table's prediction for a target human, the brain selects the action that best counters the human's most likely move. Depends on T12.2 (PatternTable). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Counter-Action Selection).

# Implementation Plan

1. **Create `tests/test_watcher_brain.py`** with tests for:
   - Human predicted to move away -> Watcher selects intercept movement in same direction
   - Human predicted to attack -> Watcher selects defend
   - Human predicted to rest -> Watcher selects rush (move toward + attack)
   - Human predicted to defend -> Watcher selects ranged_attack
   - Falls back to `__global__` profile when target player has no data
   - Returns a valid action tuple (e.g., `("attack", "north")`, `("defend",)`, `("dash", "east")`)
   - Uses Watcher's full action set including dash, ranged_attack, taunt

2. **Create `engine/watcher_brain.py`**:
   - `COUNTER_MAP` dict mapping predicted human actions to Watcher counter-actions:
     - `"move"` -> intercept (move toward human's predicted destination)
     - `"attack"` -> `"defend"` then retaliate next round
     - `"rest"` -> rush (move toward if distant, attack if adjacent)
     - `"defend"` -> `"ranged_attack"` (bypass defense from range)
     - `"ranged_attack"` -> `"dash"` (close distance quickly)
     - `"dash"` -> `"taunt"` (force them to engage)
   - `select_counter_action(pattern_table, target_id, watcher_state, game_state) -> tuple` — main decision function:
     - Query `pattern_table.predict(target_id, current_context)`
     - If no data for target, fall back to `pattern_table.predict("__global__", current_context)`
     - Pick highest-probability predicted action
     - Look up counter from `COUNTER_MAP`
     - Resolve direction based on watcher and target positions
     - Return valid action tuple

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Counter-action is optimal response to most likely human action
- [ ] Falls back to __global__ profile for unknown players
- [ ] Uses watcher's full action set (dash, ranged, taunt)
- [ ] Returns valid action tuple
