# Objective

Visualize trap, ability, and tactical events in the browser viewer. Currently only hit/bump/kill/storm events are rendered.

# New Event Types to Visualize

From match JSON round events:
- `trap_placed` → subtle marker at (x,y)
- `trap_trigger` → explosion effect at (x,y) with damage number
- `tactical_activate` → flash on bot tile (⚡ lightning bolt effect)
- `ability_damage` → projectile from caster toward target
- `ability_heal` → green glow on bot
- `ability_shield` → blue bubble around bot
- `ability_slow` → purple tendrils toward target
- `evolve` → brief golden pulse on bot
- `crystal_pickup` → sparkle burst at position
- `wall_blocked` → bump effect against wall tile

# Implementation Plan

In the event rendering section of `renderCanvas`:

1. Add handlers for each new event type:
   - `trap_placed`: draw a small diamond marker at tile position (semi-transparent, disappears after 2 frames)
   - `trap_trigger`: draw explosion circle (red→orange gradient, expanding, fading)
   - `tactical_activate`: draw lightning bolt icon on bot's tile (yellow flash)
   - `ability_damage`: draw line from caster to target with glow (color by ability type)
   - `ability_heal`: draw expanding green rings on bot
   - `ability_shield`: draw blue circle outline around bot (persists for 2 rounds)
   - `ability_slow`: draw purple dots trailing from target
   - `evolve`: draw golden starburst expanding from bot
   - `crystal_pickup`: draw sparkle particles (magenta) at position
   - `wall_blocked`: draw red flash on wall tile

2. Add audio stingers for new events (if audio files exist, otherwise skip)

3. Update kill feed sidebar entries for new event types
