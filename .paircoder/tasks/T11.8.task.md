# Objective

Add a "Live Play" mode to the HTML viewer that connects to the WebSocket server (T11.2) for real-time human play. When connected, the viewer displays action buttons, receives state updates each round, renders the grid in real-time, and sends the human's chosen action back within the 2-second window.

# Implementation Plan

1. **Add "Live Play" button to viewer UI**:
   - New button in the controls bar: "Live Play" (disabled by default)
   - On click: prompt for server URL (default `ws://localhost:8765`) or use URL parameter `?live=HOST:PORT`
   - Establish WebSocket connection using native `WebSocket` API
   - On successful connect: switch from replay mode to live mode, hide replay controls

2. **Create action button panel** (visible only in live mode):
   - Movement buttons: north, south, east, west (arrow key icons)
   - Attack buttons: north, south, east, west (sword icons)
   - Utility buttons: Defend (shield icon), Rest (sleep icon)
   - Each button sends `{"action": ["move", "east"]}` format JSON over WebSocket
   - Keyboard shortcuts: arrow keys for move, WASD for attack direction, R for rest, D for defend

3. **Handle state updates from server**:
   - On `{"type": "state", "round": int, "state": dict}` message: render the grid using existing canvas rendering code
   - Update HP bars, positions, energy display from the state dict
   - Highlight the human's bot with a distinct border or glow

4. **Round timing UX**:
   - When state update arrives: enable action buttons, start 2-second countdown timer display
   - On button click or keyboard input: send action, disable buttons, show "Action sent" feedback
   - On countdown expiry: disable buttons, show "Bot deciding..." message
   - Between rounds: show "Waiting for round..." message

5. **Disconnect handling**:
   - On WebSocket close/error: show "Disconnected" message, re-enable "Live Play" button
   - Attempt auto-reconnect once after 1 second
   - Show fallback message: "Connection lost. Your bot is playing without you."

# Acceptance Criteria

- [ ] "Live Play" button establishes WebSocket connection to server
- [ ] Action buttons appear when connected (move, attack, defend, rest with directions)
- [ ] State updates render the grid in real-time via existing canvas code
- [ ] Action sent within the 2-second window via WebSocket
- [ ] Fallback message shown on disconnect

# Verification

Manual testing -- start a match server (T11.2), open the viewer, click "Live Play", connect, and play through rounds using buttons and keyboard.
