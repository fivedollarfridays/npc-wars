# Objective

Expose progression info to bots via the state dict so that `decide()` functions can inspect their own unlocked actions, line budget, and win streak. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 9 (State Dict Additions) and Section 12 (Extended State Dict).

# Implementation Plan

1. **Update `tests/test_state.py`** to verify:
   - `state["me"]["unlocked_actions"]` exists and is a `list[str]`
   - `state["me"]["line_budget"]` exists and is an `int`
   - `state["me"]["win_streak"]` exists and is an `int`

2. **Update `SelfInfo` TypedDict in `engine/types.py`**:
   - Add `unlocked_actions: list[str]`
   - Add `line_budget: int`
   - Add `win_streak: int`

3. **Update `build_state()` in `engine/state.py`**:
   - Include `unlocked_actions`, `line_budget`, and `win_streak` in the `"me"` section
   - Source values from the bot's profile data

4. **Thread profile data through `engine/game.py` -> `build_state`**:
   - Pass profile (or relevant fields) when constructing state for each bot

# Acceptance Criteria

- [x] state["me"]["unlocked_actions"] is a list of strings
- [x] state["me"]["line_budget"] is an int
- [x] state["me"]["win_streak"] is an int
- [x] SelfInfo TypedDict updated with new fields
