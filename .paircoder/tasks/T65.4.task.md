# Ghost replay for Kill Switch

Build `engine/ghost_replay.py` to fork match state at any round, substitute one bot's action, and re-simulate the remainder. Show "what would have happened" as an alternate timeline. Output: ghost match JSON with divergence point marked. Engine is deterministic (seeded RNG), so forking is reliable.

# Acceptance Criteria

- [x] `ghost_replay(match_data, round_num, bot_emoji, alt_action, seed)` returns ghost match JSON
- [x] Ghost match diverges from specified round, simulates to completion
- [x] Divergence point clearly marked in output
- [x] Uses same seed for deterministic replay
- [x] Original match data unmodified
- [x] Tests cover: substitute attack→defend, early divergence, late divergence
- [x] File under 200 LOC, ruff clean
