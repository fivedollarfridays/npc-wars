# Objective

Update the bot loader to read `BOT_EQUIPMENT` from bot modules, validate it, compute bonuses, and attach to bot configs. Bots without equipment get sensible defaults.

# Implementation Plan

1. Update `engine/loader.py` `_load_single_bot()`:
   - Read `BOT_EQUIPMENT` dict from module (optional)
   - Validate via `validate_equipment()`
   - If invalid or missing, use `EQUIPMENT_DEFAULTS`
   - Add `"equipment"` key to bot config dict

2. Update `engine/game.py` `_create_bots()`:
   - Read `config["equipment"]` (or default)
   - Call `compute_equipment_bonuses()` and attach to Bot
   - Apply equipment bonuses to derived stats (HP, energy, etc.)

3. Update `engine/game_async.py` similarly

4. Tests in `tests/test_equipment_loader.py`:
   - Bot with BOT_EQUIPMENT loads correctly
   - Bot without BOT_EQUIPMENT gets defaults
   - Invalid equipment (over budget) falls back to defaults with warning
   - Equipment bonuses applied during bot creation

# Acceptance Criteria

- [ ] BOT_EQUIPMENT read from bot modules
- [ ] Invalid equipment falls back to defaults with log warning
- [ ] Missing equipment uses defaults (sword + leather)
- [ ] Equipment bonuses computed and attached to Bot during creation
- [ ] Tests pass, ruff clean
