# Objective

Add incoming threat info to state dict so bots know which enemies are most dangerous to them.

# Design

In `build_state()`, for each enemy compute their hit probability against this bot:

```python
state["me"]["incoming_threat"] = [
    {"emoji": e.emoji, "hit_chance": X, "expected_damage": Y}
    for e in enemies_sorted_by_expected_damage_desc
]
```

# Acceptance Criteria

- [ ] state["me"]["incoming_threat"] is a list sorted by expected_damage desc
- [ ] Each entry has emoji, hit_chance, expected_damage
- [ ] High-POWER enemies rank higher
- [ ] Tests pass, ruff clean
