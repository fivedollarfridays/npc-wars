# Objective

Create `engine/bumpers.py` with collision detection, knockback, and chain resolution.

# Implementation Plan

1. Create `tests/test_bumpers.py` with cases: basic bump (push 1 tile), chain bump (depth 2), chain bump (depth 5 cap), wall splat (10 damage), storm bounce (storm damage), empty tile no bump, cycle prevention
2. Add `WALL_SPLAT_DAMAGE = 10` to `engine/combat.py`
3. Create `engine/bumpers.py` with:
   - `resolve_bumps(movers: list[tuple[Bot, int, int]], all_bots: list[Bot], grid_size: int, storm_border: int) -> list[dict]`
   - `_compute_impact_direction(from_x, from_y, to_x, to_y) -> tuple[int, int]`
   - `_push_bot(bot, dx, dy, grid_size, storm_border, all_bots, visited, depth) -> list[dict]`
   - Max chain depth 5, visited set per chain to prevent cycles
   - Event types: `{"type": "bump", "pusher": emoji, "target": emoji, "direction": str}`, `{"type": "chain_bump", ...}`, `{"type": "wall_splat", "target": emoji, "damage": 10}`, `{"type": "storm_bounce", "target": emoji, "damage": 10}`

# Acceptance Criteria

- [x] Basic bump: moving into occupied tile pushes occupant 1 tile
- [x] Chain bump: pushed bot hits another, secondary push occurs
- [x] Max depth 5: chain stops, last bot stays put
- [x] Wall splat: pushed into grid edge, takes WALL_SPLAT_DAMAGE (10)
- [x] Storm bounce: pushed into storm, takes STORM_DAMAGE (10) immediately
- [x] Cycle prevention: A->B->A does not infinite loop
- [x] Module <400 LOC, <15 functions
