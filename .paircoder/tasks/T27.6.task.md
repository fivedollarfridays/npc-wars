# Objective

Wire derived stats into all game loop references. Replace hardcoded STARTING_HP, STARTING_ENERGY, MAX_HP, MAX_ENERGY with per-bot derived values throughout the engine.

# Implementation Plan

1. `engine/game.py._execute_round()` — replace `bot.attack_power = STARTING_ATTACK_POWER + bonus` with derived damage values (store min/max from derived stats, add round bonus)
2. `engine/rounds.py.apply_energy_and_rest()` — replace `min(MAX_HP, ...)` with `min(bot.derived.max_hp, ...)`, replace `min(MAX_ENERGY, ...)` with `min(bot.derived.max_energy, ...)`
3. Add MIND energy regen bonus: rest restores `REST_ENERGY_RESTORE + bot.derived.energy_regen + bot.momentum_energy_bonus`
4. `engine/game.py._prepare_match()` — mode override `mode.starting_hp` should still work (override derived HP if mode specifies)
5. Verify `resolve_deaths` still works (checks `hp <= 0`, no change needed)

# Acceptance Criteria

- [ ] 25/25/25/25 bots: HP caps at 100, energy caps at 100, rest restores 20 energy (unchanged)
- [ ] 50-ARMOR bot: HP caps at 120, energy at 100
- [ ] 50-MIND bot: rest restores 25 energy (20 base + 5 regen bonus)
- [ ] Round bonus attack still scales with round number
- [ ] Match mode HP override still works
- [ ] Tests pass, ruff clean
