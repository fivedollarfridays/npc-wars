# Objective

Create a landing page for Kill Switch and wire it to the root `/` route so players have a front door to the browser experience.

# Implementation Plan

1. Create `server/static/index.html`:
   - Game title: "Kill Switch" + tagline "You don't play. You code."
   - Dark cyberpunk theme (match existing pages — JetBrains Mono, black bg, cyan/pink accents)
   - Three entry points:
     - **Quick Play** → `/static/editor.html`
     - **Tournaments** → `/tournaments`
     - **Leaderboard** → `/leaderboard`
   - If `localStorage` has API key, show "My Profile" link → `/profile/{id}`
   - Minimal — no JS dependencies, pure HTML/CSS

2. Add root route in `server/routes/pages.py`:
   - `GET /` → serve `server/static/index.html`

3. Tests in `tests/test_s48_landing.py`:
   - `index.html` exists and contains game title
   - `GET /` returns 200 (FastAPI test client)
   - Page contains links to editor, tournaments, leaderboard

# Acceptance Criteria

- [ ] `server/static/index.html` exists with game title and 3 entry links
- [ ] `GET /` serves the landing page (200 status)
- [ ] Dark theme matches existing pages
- [ ] Tests pass, ruff clean
