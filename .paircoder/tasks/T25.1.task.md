# Objective

Create `engine/scoring.py` — a per-round scoring engine that calculates points for each alive bot based on their actions and outcomes.

# Scoring Table

| Source | Points | Condition |
|--------|--------|-----------|
| Survival | +1 | Alive at end of round |
| Kill | +10 | Eliminated an enemy this round |
| Full HP round | +2 | HP == 100 at end of round |
| Damage dealt (per 25hp) | +1 | Cumulative damage this round / 25, floored |
| Clean kill | +5 bonus | Got a kill AND took 0 damage this round |
| Last standing | +15 | Won the match (only 1 alive) |
| Storm survivor | +3 | Alive when storm first activates |

# Implementation Plan

1. Create `engine/scoring.py` with `ScoreEvent` dataclass and `calculate_round_scores()`
2. Add `score: int` field to Bot class in `engine/combat.py`
3. Wire into game loop after combat resolution
4. Add `state["me"]["score"]` and `state["enemies"][i]["score"]` to state dict
5. Add score events to round data
6. Tests in `tests/test_scoring.py`

# Acceptance Criteria

- [ ] `calculate_round_scores()` returns correct points per scoring table
- [ ] Bot.score field tracks cumulative points
- [ ] `state["me"]["score"]` exposed to bots
- [ ] Score events recorded in round data
- [ ] Tests pass, ruff clean, < 400 lines
