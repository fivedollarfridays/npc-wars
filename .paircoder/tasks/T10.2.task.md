# Objective

Map drama scores to five effect tiers and select visual/audio triggers for each round. Extend `SpectacleEngine` to classify rounds into tiers and map game event triggers to specific visual and audio effects.

# Implementation Plan

1. **Add tests to `tests/test_spectacle.py`** for tier classification:
   - Score 0-3 returns tier `"calm"`
   - Score 4-7 returns tier `"heating"`
   - Score 8-12 returns tier `"intense"`
   - Score 13-18 returns tier `"hype"`
   - Score 19+ returns tier `"chaos"`
   - Boundary values tested: 0, 3, 4, 7, 8, 12, 13, 18, 19, 25

2. **Add tests for trigger-to-effect mapping**:
   - Kill event triggers `"shatter"` visual effect
   - Kill streak triggers `"fire_border"` visual effect
   - Near-death triggers `"slow_mo"` visual effect
   - Bumper chain triggers `"multiball"` visual effect
   - Last-2-alive triggers `"split_screen"` visual effect
   - Storm kill triggers `"glitch"` visual effect
   - Multiple triggers can fire in the same round (test with combined events)

3. **Extend `SpectacleEngine`**:
   - Add `classify_tier(drama_score: int) -> str` method
   - Add `TIER_RANGES` constant: `[(0, 3, "calm"), (4, 7, "heating"), (8, 12, "intense"), (13, 18, "hype"), (19, float("inf"), "chaos")]`
   - Add `TRIGGER_EFFECT_MAP` constant mapping event triggers to visual/audio effect names
   - Add `select_effects(events: list[dict], bots: list[dict]) -> list[str]` returning applicable effect names
   - Update `SpectacleData` to include `tier: str`, `triggers: list[str]`, `effects: list[str]`

# Acceptance Criteria

- [ ] 5 tiers correctly assigned by score range: calm (0-3), heating (4-7), intense (8-12), hype (13-18), chaos (19+)
- [ ] Each trigger maps to a specific visual and audio effect: kill->shatter, kill_streak->fire_border, near_death->slow_mo, bumper_chain->multiball, last_2->split_screen, storm_kill->glitch
- [ ] Multiple triggers can fire in the same round and all corresponding effects are returned
