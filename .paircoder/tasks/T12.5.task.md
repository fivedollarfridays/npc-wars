# Objective

Calculate how accurately The Watcher predicts each human's actions. The sync rating is a rolling accuracy percentage over the last 10 predictions per player, displayed to spectators (but NOT to the player). This is a key spectacle metric: "can the human stay unpredictable faster than The Watcher adapts?" Depends on T12.2, T12.3. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Sync Rating).

# Implementation Plan

1. **Create `tests/test_watcher_sync.py`** with tests for:
   - New player starts at 0% sync
   - Correct prediction increases sync rating
   - Incorrect prediction decreases sync rating
   - Sync is capped at 0% minimum and 100% maximum
   - Sync is tracked per-player (Player A's sync does not affect Player B)
   - Sync is calculated over last 10 predictions (rolling window)
   - Breaking pattern (human switches up) drops sync by 10-15%

2. **Add to `engine/watcher_brain.py`**:
   - `SyncTracker` class with:
     - Internal storage: `dict[str, list[bool]]` — per-player list of last 10 prediction outcomes (True = correct, False = incorrect)
     - `record_prediction(player_id: str, predicted_action: str, actual_action: str) -> None` — appends outcome, trims to last 10
     - `get_sync(player_id: str) -> float` — returns percentage (0.0-100.0) based on rolling accuracy
     - `calculate_sync(predicted: str, actual: str, current_sync: float) -> float` — static helper for one-off calculation
   - Sync starts at 0% for players with no prediction history

3. **Run tests and verify** all pass

# Acceptance Criteria
