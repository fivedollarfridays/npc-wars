# Objective

Implement The Watcher's spawn conditions for mid-match entry. The Watcher does not start in every match -- it spawns when a human player demonstrates skill (surviving 5+ rounds with >50% HP, or getting a kill). When triggered, it spawns at a random valid tile 3+ tiles from any human with full spectacle treatment. Depends on T12.1. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Spawn Conditions).

# Implementation Plan

1. **Create `tests/test_watcher_spawn.py`** with tests for:
   - Watcher does NOT spawn in pure bot matches (no human bots present)
   - Watcher spawns after a human survives 5+ rounds with >50% HP
   - Watcher spawns after a human gets any kill
   - Spawn position is at least 3 tiles (Manhattan distance) from nearest human
   - Spawn position is a valid tile (inside grid, not in storm, not occupied)
   - A `watcher_spawn` event is emitted in the round events
   - Watcher does not spawn if already present in the match

2. **Add spawn logic to `engine/game.py`** (or create `engine/watcher_spawn.py` if game.py is large):
   - `check_watcher_spawn(round_events: list[dict], human_bots: list, round_num: int, watcher_present: bool) -> bool` — returns True if spawn should occur:
     - Returns False if no human bots or watcher already present
     - Returns True if any human has survived `round_num >= 5` with current HP > 50% of max
     - Returns True if any human got a kill this round (check events for kill by human)
   - `find_spawn_position(grid_size: int, storm_border: int, occupied: list[tuple], human_positions: list[tuple], rng) -> tuple[int, int]` — find valid tile 3+ tiles from any human
   - Emit `{"type": "watcher_spawn", "x": x, "y": y}` event on spawn

3. **Run tests and verify** all pass

# Acceptance Criteria
