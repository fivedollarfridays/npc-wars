# Objective

Add `agentgrounds wars upload my_bot.py` CLI command that uploads a bot to the server and joins the lobby.

# Implementation Plan

1. Create `agentgrounds/wars/cli/cmd_upload.py`:
   - `register(subparsers)` — add "upload" subcommand
   - `run(args)`:
     - Read bot file from disk
     - Validate locally first (scan_bot_source)
     - POST to server /api/submit-bot with source
     - If no API key configured, auto-generate and save to config
     - POST to /api/lobby/join with returned bot_id
     - Print lobby status (waiting for opponents...)
     - Poll /api/lobby/status until match starts
     - Print match result URL when complete

2. Args:
   - positional: bot file path
   - `--server` — server URL (default from config or env)
   - `--api-key` — API key (default from config file)
   - `--no-join` — upload only, don't join lobby

3. Config storage:
   - Store API key in `~/.agentgrounds/config.toml` or `agentgrounds.toml`
   - Server URL configurable

4. Register in `agentgrounds/wars/cli/__init__.py`

5. Tests in `tests/test_cli_upload.py`

# Acceptance Criteria

- [ ] `agentgrounds wars upload my_bot.py` uploads and joins lobby
- [ ] API key auto-generated on first use, saved to config
- [ ] Local validation runs before upload
- [ ] Lobby status polled until match starts
- [ ] Match result URL printed when complete
