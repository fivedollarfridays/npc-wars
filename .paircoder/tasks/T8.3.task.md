# Objective

Add +2 attack power per 10 rounds after R15 to force late-game fights to resolve faster.

# Implementation Plan

1. Create `tests/test_damage_scaling.py` with tests: `bonus(14)==0`, `bonus(15)==0`, `bonus(25)==2`, `bonus(35)==4`
2. Add `get_round_bonus_attack(round_num: int) -> int` to `engine/combat.py`
3. In `engine/game.py` `_execute_round`, before `resolve_decisions`: set `bot.attack_power = STARTING_ATTACK_POWER + get_round_bonus_attack(round_num)` for all alive bots

# Acceptance Criteria

- [x] get_round_bonus_attack(14) == 0
