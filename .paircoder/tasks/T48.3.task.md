# Objective

Replace the fake 30s countdown in `editor.html` with real lobby status polling so players see actual opponents joining and a real countdown.

# Implementation Plan

1. Modify `server/static/editor.html` — replace fake countdown (lines ~301-321):
   - After successful submit, start polling `GET /api/lobby/status` every 2s
   - Show lobby panel below editor:
     - Player grid: emoji + name for each joined bot
     - Counter: "3/8 players"
     - Countdown: real `time_remaining` from API
     - Fill indicator: "AI bots will fill remaining slots"
   - When status returns `match_id`:
     - Show "Match starting..." message
     - After 1s delay, redirect to `/viewer?match={match_id}`

2. Preserve bot source in `localStorage`:
   - On submit, save editor content to `localStorage.setItem('lastBotSource', code)`
   - On page load, if `lastBotSource` exists, pre-fill editor

3. Handle edge cases:
   - Stop polling if lobby resets (status returns empty)
   - Network errors — show retry message, don't crash
   - Prevent double-submit

4. Tests in `tests/test_s48_editor.py`:
   - editor.html contains `/api/lobby/status` reference
   - editor.html contains lobby polling JS
   - editor.html contains localStorage save logic

# Acceptance Criteria

- [ ] Editor polls real lobby status after submit (no fake countdown)
- [ ] Player list shows emoji + name for each joined bot
- [ ] Real countdown timer from API response
- [ ] Redirect to viewer when match_id appears
- [ ] Bot source preserved in localStorage
- [ ] Tests pass, ruff clean
