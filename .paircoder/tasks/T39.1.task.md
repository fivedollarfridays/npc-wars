# Objective

Create a comprehensive balance simulation that tests ALL Phase 2 systems together: stats, equipment, abilities, traps, terrain, callbacks, archetypes. This is the final validation before Phase 2 closes.

# Implementation Plan

1. Create `tools/phase2_balance_sim.py`:
   - 1000 matches across all 5 terrain maps (200 per map)
   - Full bot pool: all builtin bots with equipment + callbacks
   - Give appropriate unlocked_actions/callbacks to bots that have them
   - Random 4-8 bot subsets per match
   - Track per-bot: win rate, kills, damage, survival, score
   - Track per-archetype: win rate across all matches
   - Track per-map: win rate spread, avg duration
   - Track per-weapon: win rate by weapon type
   - Track per-armor: win rate by armor type

2. Balance targets:
   - No bot > 60% win rate overall
   - No archetype > 60% win rate overall
   - No map produces > 15% deviation from average match duration
   - Balanced archetype (25/25/25/25) between 40-55% win rate

3. Save comprehensive results to `tools/phase2_balance_results.json`

4. Create `tests/test_phase2_gate.py` (rename from existing test_phase1_gate.py pattern):
   - Skip if results not generated
   - All balance targets met
   - All archetypes have >= 50 matches
   - All maps represented

# Acceptance Criteria

- [ ] 1000-match sim runs successfully
- [ ] Results cover all dimensions (bot, archetype, map, weapon, armor)
- [ ] Balance targets met or issues documented for tuning
- [ ] Regression test guards balance
