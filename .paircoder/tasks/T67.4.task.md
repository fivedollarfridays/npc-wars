# SDK guide: Build Your Own Game

Write a guide for community developers to build new Agent Grounds games. Cover: implementing the platform contracts (GameEvent adapter, commentary generator, personality profiler), engine requirements (deterministic, seeded RNG, replay format), viewer integration, and how to register a new game in the CLI. Based on the actual interfaces from Kill Switch and Code Circuit.
