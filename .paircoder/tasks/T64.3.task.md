# Discord channel posting

After TV pipeline renders a match, post the video and episode summary to game-specific Discord channels (`#kill-switch-tv`, `#code-circuit-tv`). Main message: video file + winner + key stats. Threaded reply: full stat diffs, highlight descriptions, Watcher dossier (Kill Switch only), season standings update. Use existing `discord_bot/formatters.py` patterns.

# Acceptance Criteria

- [x] Video posted to correct game channel based on match type
- [x] Main message includes: video attachment, winner, match duration, top highlights
- [x] Thread reply includes: full stats table, stat diffs, season standings change
- [x] Kill Switch thread includes Watcher dossier section
- [x] Handles video >25MB gracefully (posts highlights-only or link)
- [x] Tests cover: KS posting, CC posting, thread formatting
