# Website episode browser

Add episode browser to agentgrounds.ai (agentgrounds-web). Static Astro page that loads episode JSON files and renders them in an embedded viewer. Episode list with thumbnails (generated from first frame), winner, drama tier, date. No server — episodes served as static JSON from a `public/episodes/` directory synced from Nathan.

- [ ] Responsive design (desktop + mobile)
- [ ] Test: page loads, episode renders, navigation works
