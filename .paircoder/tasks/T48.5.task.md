# Objective

Add a results overlay to the viewer that shows match outcome and provides a "Play Again" button to complete the gameplay loop.

# Implementation Plan

1. Add results overlay to viewer:
   - When playback reaches final round, pause 2s then show overlay
   - Overlay content:
     - Winner: emoji + name (large, centered)
     - Kill feed: last 8 eliminations
     - Top 5 stats: emoji, kills, damage, rounds survived
   - Buttons:
     - "Play Again" → `/static/editor.html`
     - "Leaderboard" → `/leaderboard`
     - "Watch Again" → restart replay from round 1

2. Add overlay HTML/CSS to viewer HTML file:
   - Hidden div, shown on match end
   - Semi-transparent black background
   - Cyberpunk styled card (match existing theme)
   - Smooth fade-in animation

3. Create `viewer/js/results.js` (or add to `app.js`):
   - `showResults(matchData)` function
   - Extracts winner, eliminations, stats from match JSON
   - Builds overlay DOM dynamically
   - "Watch Again" calls existing replay restart function

4. Tests in `tests/test_s48_results.py`:
   - Viewer HTML contains results overlay div (or JS creates it)
   - Results JS file exists and is loaded
   - Overlay has Play Again and Leaderboard links

# Acceptance Criteria

- [ ] Results overlay appears after final round
- [ ] Shows winner, kill feed, top stats
- [ ] "Play Again" links to editor
- [ ] "Leaderboard" links to rankings
- [ ] "Watch Again" restarts replay
- [ ] Tests pass, ruff clean
