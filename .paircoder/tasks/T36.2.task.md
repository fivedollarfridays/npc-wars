# Objective

Implement the `power_up` callback (level 18+) and `use_ability` action. The power_up callback lets bots define a custom ability at match start. The use_ability action activates it during combat.

# Design

The `power_up()` callback returns an ability definition dict:

```python
def power_up(state):
    return {
        "name": "Fireball",
        "type": "damage",        # damage, heal, shield, slow
        "potency": 30,           # effect strength
        "range": 2,              # tiles
        "cooldown": 5,           # rounds
        "energy_cost": 25,       # energy
    }
```

Ability types:
- **damage**: deal potency damage to target at range
- **heal**: restore potency HP to self
- **shield**: gain potency temp DR for 2 rounds
- **slow**: reduce target's initiative by potency for 3 rounds

# Implementation Plan

1. Add to `engine/callbacks.py` CALLBACK_NAMES: already includes "power_up"
2. Create `engine/abilities.py`:
   - `AbilityDef` dataclass: name, type, potency, range, cooldown, energy_cost
   - `validate_ability(definition: dict) -> AbilityDef | None` — validate type, ranges, costs
   - `ABILITY_TYPES = {"damage", "heal", "shield", "slow"}`
   - `resolve_ability(bot, target, ability, round_num) -> list[dict]` — execute ability effect

3. Wire power_up callback into match setup (after setup callbacks):
   - Call `bot.callbacks.power_up(state)` → get ability definition
   - Validate and store as `bot.ability: AbilityDef | None`

4. Wire use_ability action:
   - `("use_ability", direction)` or `("use_ability",)` for self-target
   - Check cooldown, energy, range
   - Call `resolve_ability()` to apply effect

5. Add ability info to state dict:
   - `state["me"]["ability"]` — name, type, cooldown_remaining, uses
   - `state["enemies"][i]["has_ability"]` — boolean

6. Tests in `tests/test_abilities.py`
