# Kill Switch commentary engine

Build `engine/commentary.py` — template-based commentary generator that consumes round-by-round match data, spectacle data, personality profiles, and rivalry data. Generate play-by-play (factual: "Tank moves to high ground") and color commentary (analytical: "Smart positioning — that's how they beat Kiter last match"). Drama tier modulates tone: calm=observational, heating=building, hype=excited, chaos=screaming. Output per-round commentary strings with timing and tone markers.

# Acceptance Criteria

- [x] `generate_commentary(match_data, profiles, rivalries)` returns list of CommentaryLine(round, text, tone, type)
- [x] Play-by-play covers: kills, movement, defend, trap placement, ability use, storm damage
- [x] Color commentary references: personality traits, rivalry history, equipment choices, Watcher events
- [x] Tone scales with drama tier (5 tiers = 5 tone levels)
- [x] At least 50 unique commentary templates
- [x] Produces commentary for a full match with zero crashes on any builtin_bot matchup
- [x] Tests cover all drama tiers and major event types
- [x] File under 400 LOC (may split into commentary.py + commentary_templates.py), ruff clean
