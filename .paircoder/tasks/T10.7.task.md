# Objective

Add Pillow-based spectacle visual effects to the video frame rendering pipeline. The video renderer reads spectacle metadata from match JSON and composites effects (screen shake, fire border, slow-mo, damage flash) onto each frame, with intensity scaling by drama tier.

# Implementation Plan

1. **Create `tests/test_video_effects.py`** with tests for:
   - Frame rendered with spectacle data has pixel differences from frame rendered without
   - Screen shake effect offsets the frame by 2-4 pixels (compare origin pixel positions)
   - Fire border effect adds orange/red pixels along frame edges
   - Damage flash effect applies a red overlay (verify red channel increase)
   - Effect intensity scales: calm=no modification, heating=subtle, chaos=maximum

2. **Extend `video/video_effects.py`** with new function:
   - `render_spectacle_effects(image: Image, spectacle_data: dict, cell_size: int) -> Image`
   - Screen shake: crop and offset the image by 2-4 pixels in a random direction (seeded by round number for determinism), fill exposed edge with black
   - Fire border: draw orange-to-red gradient rectangles along all four edges (width = cell_size // 4)
   - Slow-mo: return the frame 3 times in the frame list (caller handles frame duplication for extended display)
   - Damage flash: composite a semi-transparent red overlay, opacity scaled by tier (heating=10%, intense=20%, hype=40%, chaos=60%)

3. **Wire into the frame rendering loop**:
   - After rendering grid, sprites, and overlays, call `render_spectacle_effects`
   - Pass `round_data["spectacle"]` to the function
   - Handle slow-mo by duplicating the returned frame in the frame list

# Acceptance Criteria

- [ ] Screen shake offsets frame by 2-4 pixels during intense+ tiers
- [ ] Fire border renders orange gradient on frame edges during hype+ tiers
- [ ] Slow-mo duplicates frame for extended display on near_death triggers
- [ ] Effect intensity scales with drama tier (calm=none, chaos=maximum)
