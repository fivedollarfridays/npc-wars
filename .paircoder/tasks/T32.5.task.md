# Objective

Add `npcwars profile [name]` CLI command that displays a player's level, XP, progress to next level, and match stats.

# Output Format

```
╔═══════════════════════════════════════╗
║  GooseLoose — Level 5                ║
║  ████████████░░░░░░ 600/1200 XP      ║
║                                      ║
║  Matches: 47  │  Wins: 12  │  W/R: 25.5%  ║
║  Kills: 89    │  K/M: 1.9               ║
║                                      ║
║  Unlocked: move attack rest defend   ║
║            ranged_attack dash        ║
║  Next: taunt (Level 8)              ║
╚═══════════════════════════════════════╝
```

# Implementation Plan

1. Add `profile` subcommand to CLI argparse in appropriate CLI module
2. Read profile from `data/profiles.db`
3. Calculate progress bar: `(current_xp - level_xp) / (next_level_xp - level_xp)`
4. Show cumulative unlocks from `unlocks_at_level()`
5. Show next unlock milestone
6. If no name given, list top 10 profiles (leaderboard view)
7. Tests in `tests/test_cli_profile.py`

# Acceptance Criteria

- [x] `npcwars profile GooseLoose` displays correct stats
- [x] `npcwars profile` (no name) shows leaderboard
- [x] Progress bar renders correctly at 0%, 50%, 100%
- [x] Handles unknown player name gracefully
- [x] Tests pass, ruff clean, < 400 lines
