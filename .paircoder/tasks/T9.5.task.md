# Objective

Add `ranged_attack` action -- hits a tile 2 away in the specified direction, costs 20 energy, deals a fixed 15 damage (not scaled by attack_power). This is the first unlockable action, available at 3-win streak. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 9.

# Implementation Plan

1. **Create `tests/test_ranged_attack.py`** with tests for:
   - `("ranged_attack", "north")` is a valid action
   - Hits target at Manhattan distance 2 in specified direction
   - Does NOT hit a bot at distance 1
   - Does NOT hit a bot at distance 3
   - Costs 20 energy (bot must have >= 20 energy)
   - Deals exactly 15 damage (fixed, not scaled by attack_power)
   - Generates `"ranged_hit"` event on hit
   - Generates `"ranged_miss"` event on miss

2. **Add constants to `engine/combat.py`**:
   - `RANGED_ATTACK_COST = 20`
   - `RANGED_ATTACK_DAMAGE = 15`

3. **Update `engine/sandbox.py` VALID_ACTIONS**:
   - Add `"ranged_attack": 1` (takes 1 argument: direction)

4. **Add `resolve_ranged_attacks()` to `engine/rounds.py`**:
   - Similar structure to `resolve_attacks` but checks tile exactly 2 away in the specified direction
   - Uses `RANGED_ATTACK_DAMAGE` (fixed 15) instead of bot's attack_power
   - Emits `"ranged_hit"` or `"ranged_miss"` events

5. **Wire into `_execute_round`** after `resolve_attacks` call

# Acceptance Criteria
