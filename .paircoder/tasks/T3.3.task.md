# Objective

Auto-post match announcements when matches start and end.

# Implementation Plan

- Create discord_bot/announcements.py
- Match start: post grid size, player list with emojis, match seed
- Match end: post winner, final standings, key stats
- Channel config: dedicated announcement channel
- Embed formatting with bot emojis and colors
- Hook into match runner (callback or event)

- [ ] Embeds use bot emojis and colors
