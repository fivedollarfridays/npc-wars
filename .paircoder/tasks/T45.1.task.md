# Objective

Add kill cam (slow-mo zoom on eliminations) and death animations (character dims → particles → empty) to the viewer.

# Context

- viewer/js/effects.js has existing particle effects (shatterEffect, deathExplosion)
- viewer/js/renderer.js renders rounds with interpolation
- viewer/js/app.js controls playback speed and animation loop
- Kill events are in round.events with type "kill"

# Implementation Plan

1. Add to viewer/js/effects.js:
   - `triggerKillCam(ctx, canvas, x, y, duration)`:
     - Save current playback speed
     - Set speed to 0.25x (slow-mo)
     - Zoom canvas to 2x centered on kill position via CSS transform
     - Hold for `duration` ms (default 1500)
     - Restore speed and zoom
   - `playDeathAnimation(ctx, x, y, character, frames)`:
     - Frame 1: character at 50% opacity
     - Frame 2: character at 20% + red tint
     - Frame 3: particle burst (8-12 particles)
     - Frame 4: empty tile
     - Each frame ~200ms

2. Wire into viewer/js/renderer.js:
   - On kill event detected during round playback:
     - Trigger kill cam if spectacle tier >= "intense"
     - Always play death animation
   - On critical hit: trigger screen shake (already exists in effects.js)

3. Keep effects subtle for normal kills, dramatic for multi-kills and leader kills

# Acceptance Criteria

- [ ] Kill cam triggers on eliminations (slow-mo + zoom)
- [ ] Death animation plays (dim → particles → gone)
- [ ] Screen shake on critical hits
- [ ] Kill cam duration configurable
- [ ] Normal playback resumes after kill cam
