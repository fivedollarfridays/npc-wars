# Objective

Fix PROMPT.md bundling so `agentgrounds wars generate` works after pip install, not just from the repo. Also add `__version__` to package code.

# Current Problem

`cmd_generate.py` references PROMPT.md via:
```python
_PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent.parent
prompt_path = _PROJECT_ROOT / "PROMPT.md"
```

After pip install, `_PROJECT_ROOT` points to site-packages, not the repo. PROMPT.md isn't there.

# Implementation Plan

1. Move PROMPT.md into the package: `agentgrounds/wars/data/PROMPT.md`
   - Or use `importlib.resources` to load it from package data
   - Update pyproject.toml: `[tool.setuptools.package-data]` section
   - Update cmd_generate.py to use `importlib.resources` or `__file__` relative path

2. Add `__version__ = "0.1.0"` to `agentgrounds/__init__.py`

3. Create MANIFEST.in if needed for sdist builds

4. Verify: `pip install .` in a fresh venv, then `agentgrounds wars generate --strategy "test"` outputs the prompt

# Acceptance Criteria

- [ ] PROMPT.md accessible after pip install (not just from repo)
- [ ] `agentgrounds wars generate` works from any directory after install
- [ ] `__version__` importable from agentgrounds package
- [ ] Tests pass, ruff clean
