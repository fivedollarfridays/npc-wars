# Objective

Integration gate for S35. Verify full equipment pipeline end-to-end: catalog → validation → combat hooks → state dict → bot loading → balance.

# Implementation Plan

1. Create `tests/test_s35_integration.py` with test classes:

   **TestEquipmentValidation**
   - Valid loadout passes validation
   - Over-budget rejected
   - Missing weapon rejected
   - 3 accessories rejected
   - Default equipment valid

   **TestCombatWithEquipment**
   - Sword user gets +1 to-hit in real match
   - Plate armor user has higher effective AC
   - Axe user gets higher crit multiplier
   - Mace user bypasses some armor DR
   - Spear user attacks at 2-tile range

   **TestEquipmentInMatch**
   - Run real match with equipped bots
   - Equipment bonuses apply (verify damage/DR differences)
   - Match JSON includes equipment data

   **TestStateDict**
   - state["me"]["equipment"] has all fields
   - state["enemies"][i] shows weapon/armor but not accessories

   **TestBotLoading**
   - Bot with BOT_EQUIPMENT loads correctly
   - Bot without BOT_EQUIPMENT gets defaults
   - All builtin bots load with equipment

   **TestNoDeadCode**
   - All public functions in equipment.py have callers
   - Equipment catalog fully consumed

2. Verify no regressions

# Acceptance Criteria

- [ ] Integration tests verify full equipment pipeline
- [ ] Real match with equipment runs correctly
- [ ] State dict accurate
- [ ] No dead code
- [ ] No regressions, ruff clean
