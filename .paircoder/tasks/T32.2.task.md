# Implementation Plan

1. Define `LEVEL_TABLE` as a list of dicts with xp_required, line_budget, unlocked_actions, unlocked_callbacks
2. Interpolate unlisted levels (4, 6, 7, 9, etc.) — line budget scales linearly between defined thresholds
3. `level_from_xp(total_xp: int) -> int` — highest level where xp_required <= total_xp
4. `xp_for_next_level(current_level: int) -> int` — XP needed to reach current_level + 1
5. `unlocks_at_level(level: int) -> LevelUnlocks` — actions, callbacks, line_budget at this level
6. Tests in `tests/test_levels.py`

# Acceptance Criteria

- [ ] `LEVEL_TABLE` covers levels 1–30
- [ ] `level_from_xp()` returns correct level for boundary values
- [ ] `xp_for_next_level()` returns correct delta
- [ ] `unlocks_at_level()` returns cumulative unlocks up to that level
- [ ] Pure functions — no DB, no I/O
- [ ] Tests pass, ruff clean, < 400 lines
