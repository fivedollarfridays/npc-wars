# Objective

Add CSS/JS visual effects to the HTML viewer that are triggered by spectacle metadata in the match JSON. Effects escalate with drama tier, from no effects during calm rounds to full screen shake, fire borders, and banners during chaos rounds.

# Implementation Plan

1. **Read spectacle data from round JSON**:
   - In the viewer's `renderRound` function, extract `round.spectacle.tier`, `round.spectacle.triggers`, and `round.spectacle.effects`
   - Pass tier and effects list to a new `applySpectacleEffects(tier, triggers, effects)` function

2. **Create CSS `@keyframes` animations** in the viewer's `<style>` block:
   - `screen-shake`: translate X/Y by 2-4px for 0.3s, triggered on kills during intense+ tiers
   - `fire-border`: animated orange/red gradient border (box-shadow or border-image), for hype+ tiers
   - `slow-mo-flash`: brief white flash + desaturation effect for near_death triggers
   - `subtle-pulse`: gentle scale pulse (1.0 to 1.01) for heating tier

3. **Implement tier escalation logic in JS**:
   - `calm`: no effects applied
   - `heating`: `subtle-pulse` animation on the grid container
   - `intense`: `screen-shake` on kills, crowd cheer audio cue
   - `hype`: `fire-border` + `screen-shake` on kills
   - `chaos`: all effects active simultaneously (shake, fire, slow-mo, pulse)

4. **Add kill streak / multi-bump banner overlays**:
   - When `triggers` contains `"kill_streak"`: show "UNSTOPPABLE" text banner, fade out over 2s
   - When `triggers` contains `"bumper_chain"`: show "MULTI-BUMP" text banner
   - When `triggers` contains `"last_2"`: show "FINAL SHOWDOWN" split-screen effect
   - Banners use absolute positioning over the grid, large bold text, glow effect

# Acceptance Criteria

- [ ] Screen shake plays on kills during intense+ tiers
- [ ] Fire border appears during hype+ tiers
- [ ] Slow-mo effect triggers on near_death triggers
- [ ] "UNSTOPPABLE" and "MULTI-BUMP" banners appear for kill_streak and bumper_chain triggers
- [ ] No effects during calm tier

# Verification

Manual testing -- open viewer with a spectacle-enriched match JSON file and step through rounds to verify visual effects at each tier level.
