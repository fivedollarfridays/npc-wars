# Objective

Render equipped cosmetics on character shapes in the browser viewer. Cosmetics override default archetype colors/effects.

# Implementation Plan

1. Update `viewer/js/shapes.js`:
   - `drawBotShape` reads cosmetic data from player's character descriptor
   - color_palette: override fill color with custom hex
   - glow_effect: custom shadowBlur color instead of archetype color
   - weapon_skin: override weapon indicator color
   - death_effect: custom particle color in death animation

2. Update `viewer/js/effects.js`:
   - Death animation uses cosmetic death_effect color if present
   - Trail effect: add movement trail particles if trail_effect equipped

3. Read cosmetics from match JSON:
   - `matchData.players[].cosmetics` contains equipped cosmetics
   - Build lookup table on match load

4. Character preview (`drawCharacterPreview`) applies cosmetics

5. Web store page:
   - Create `server/static/store.html` — browse and buy cosmetics
   - Preview cosmetic on character shape before purchase
   - Show coin balance

6. Tests for viewer cosmetic rendering

# Acceptance Criteria

- [ ] Custom color palette renders on character shape
- [ ] Custom glow effect visible on momentum aura
- [ ] Custom weapon skin color applied
- [ ] Death effect uses custom color
- [ ] Store page shows catalog with preview
- [ ] Old matches without cosmetics render normally
