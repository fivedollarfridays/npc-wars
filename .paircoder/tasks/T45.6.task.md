# Objective

Add a preflight execution check that runs decide() with a sample state before a bot is accepted. Crashing bots never enter a match.

# Current Problem

Bots pass AST security scan but crash at runtime (e.g., use unlocked actions, reference missing state keys). They enter matches, fail 3 times silently, die with no explanation.

# Implementation Plan

1. Create `engine/preflight.py`:
   - `run_preflight(source: str, unlocked_actions: set[str] | None = None) -> tuple[bool, str]`
   - Steps:
     a. Load module from source (temp file + load_bot_module)
     b. Build a sample state dict with all expected fields (use build_state with fake bots)
     c. Call decide(state) with 2-second timeout
     d. Validate returned action against unlocked_actions (default: base actions)
     e. Return (True, "OK") or (False, "error description")
   - Catches: ImportError, NameError, KeyError, TypeError, TimeoutError, invalid actions
