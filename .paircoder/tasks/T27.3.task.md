# Objective

Modify `Bot.__init__()` in `engine/combat.py` to accept optional `stat_allocation` parameter. Store allocation and derived stats. Wire starting HP/energy from derived stats.

# Implementation Plan

1. Add `stat_allocation: StatAllocation | None = None` parameter to Bot.__init__
2. If None, use DEFAULT_ALLOCATION
3. Store `self.stats = alloc` and `self.derived = calculate_derived(alloc)`
4. Set `self.hp = self.derived.max_hp` instead of `STARTING_HP`
5. Set `self.energy = self.derived.max_energy` instead of `STARTING_ENERGY`
6. Keep STARTING_HP/STARTING_ENERGY constants for backward compat references
7. Update `make_bot()` in `tests/conftest.py` to accept optional stats
8. Update MAX_HP/MAX_ENERGY references in combat.py to use derived values

# Acceptance Criteria

- [ ] Bot(stat_allocation=None) produces hp=100, energy=100 (backward compatible)
- [ ] Bot(stat_allocation=StatAllocation(15,15,50,20)) produces hp=120
- [ ] self.stats and self.derived accessible
- [ ] Tests pass, ruff clean
