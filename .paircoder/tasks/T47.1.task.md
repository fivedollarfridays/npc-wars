# Objective

Create the tournament bracket engine — manages bracket state, seeding, match pairing, and advancement.

# Implementation Plan

1. Create `server/tournament.py`:
   - `Tournament` class:
     - `__init__(name, size, seed)` — size must be 8, 16, or 32
     - `bracket: list[list[dict]]` — rounds of matches, each match: {player_a, player_b, winner, match_id}
     - `seed_bracket(players: list[str]) -> None` — randomize seeding, fill bracket round 1
     - `get_current_round() -> int` — which round we're on
     - `get_pending_matches() -> list[dict]` — matches that need to be played
     - `record_result(match_idx: int, winner: str, match_id: int) -> None` — advance winner
     - `is_complete() -> bool` — tournament over?
     - `get_winner() -> str | None` — final winner
     - `to_dict() -> dict` — serializable bracket state
     - `from_dict(data) -> Tournament` — restore from dict

   - Bracket structure (8-player example):
     ```
     Round 1: [A vs B, C vs D, E vs F, G vs H]  (4 matches)
     Round 2: [winner(AB) vs winner(CD), winner(EF) vs winner(GH)]  (2 matches)
     Final:   [winner(ABCD) vs winner(EFGH)]  (1 match)
     ```

   - Each match is a group of 4 bots (battle royale style, not 1v1):
     - Round 1: 4 groups of 2 → top 1 from each advances
     - Or: treat as bracket pairs, winner of each pair advances

2. Design decision: **bracket pairs with battle royale matches**
   - Each "match" in the bracket is a 4-bot battle royale
   - Top 2 from each group advance to next round
   - Final is a 4-bot battle royale, winner takes tournament

3. Tests in `tests/test_tournament.py`
