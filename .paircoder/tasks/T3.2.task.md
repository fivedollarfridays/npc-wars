# Objective

Implement emoji claim system: /claim, /unclaim, /roster Discord commands.

# Implementation Plan

- Create discord_bot/commands/claims.py
- /claim <emoji>: claim an emoji (uses data/emoji_claims.py)
- /unclaim <emoji>: release an emoji claim
- /roster: show all claimed emojis and their owners
- Validation: emoji must exist in bots/, user limits enforced
- Response embeds with confirmation/error messages

# Acceptance Criteria

- [ ] /claim command works with validation
- [ ] /unclaim command releases claims
- [ ] /roster displays all claims as embed
- [ ] User limit (3 emojis) enforced
- [ ] Error messages for invalid/taken emojis
- [ ] Tests with ≥6 cases
- [ ] All tests pass
