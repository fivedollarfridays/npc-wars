# Objective

Harden CORS configuration, secure cookie defaults, and database path validation.

# Implementation Plan

1. Fix `server/app.py` CORS (lines 47-55):
   - Change `allow_methods=["*"]` → `allow_methods=["GET", "POST"]`
   - Change `allow_headers=["*"]` → explicit list: `["Content-Type", "X-API-Key", "Authorization"]`

2. Fix `server/middleware/session.py` (line 29):
   - Default `NPCWARS_SECURE_COOKIES` to `"1"` (secure by default)
   - Only disable via explicit `NPCWARS_SECURE_COOKIES=0` for local dev
   - Log a warning when secure cookies are disabled

3. Fix `server/app.py` DB default (line 26):
   - If `DB_PATH` env var is not set and not in test context:
     - Log a loud WARNING: "DB_PATH not set — using in-memory database, data will not persist"
   - Detect test context via env var like `TESTING=1` or check for pytest

4. Tests in `tests/test_s49_middleware.py`:
   - CORS only allows GET and POST methods
   - CORS headers are restricted (not wildcard)
   - Secure cookie flag defaults to True
   - DB warning emitted when DB_PATH not set (check log output)

# Acceptance Criteria

- [ ] CORS restricted to GET/POST methods
- [ ] CORS headers explicitly listed (no wildcard)
- [ ] Secure cookie flag defaults to on
- [ ] DB path warning when using :memory: in non-test
- [ ] Tests pass, ruff clean
