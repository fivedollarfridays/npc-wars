# Objective

Create web pages for leaderboard and player profiles served by the FastAPI server.

# Context

- GET /api/leaderboard already returns ranked player data (server/routes/stats.py)
- GET /api/stats/{player_id} already returns player stats
- Static files served at /static in server/app.py
- viewer/index.html is the battle viewer pattern

# Implementation Plan

1. Create `server/static/leaderboard.html`:
   - Fetch /api/leaderboard via JS
   - Render ranked table: rank, name, wins, win rate, kills, level
   - Sort buttons (wins, kills, win rate)
   - Search/filter by name
   - Click player name → profile page
   - Clean dark theme matching viewer aesthetic

2. Create `server/static/profile.html`:
   - Fetch /api/stats/{player_id} and /api/bots?player_id={id}
   - Show: name, level, XP, win rate, total matches, kills
   - Match history list (recent 20 matches with result)
   - Equipment loadout of current bot
   - Archetype badge
   - Link to watch replay for each match

3. Add routes in FastAPI:
   - GET /leaderboard → serve leaderboard.html
   - GET /profile/{player_id} → serve profile.html
   - Enhance GET /api/leaderboard to include level, archetype
   - Add GET /api/matches/{player_id} → list of recent match IDs with results

4. Tests: validate API responses have required fields

# Acceptance Criteria

- [ ] /leaderboard shows ranked player table
- [ ] /profile/{id} shows player stats and match history
- [ ] Leaderboard sortable by different metrics
- [ ] Profile links to match replays
- [ ] Mobile responsive
