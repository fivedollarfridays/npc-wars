# Wire TV into play command

Wire commentary, highlights, personality, rivalry, and Watcher dossier into the match output. After `run_match()` completes, run the TV pipeline: generate commentary, extract highlights, build profiles, compute rivalries, build dossier. Append results to match JSON under new top-level keys: `commentary`, `highlights`, `profiles`, `rivalries`, `watcher_dossier`. Existing viewer and video pipeline ignore unknown keys, so this is additive-only.
