# Objective

Implement YouTube API authentication: OAuth2 flow and token storage.

# Implementation Plan

- Create youtube/__init__.py and youtube/auth.py
- OAuth2 flow using google-auth-oauthlib
- Token storage: youtube/token.json (gitignored)
- Client secrets: youtube/client_secrets.json (gitignored)
- Functions: authenticate(), get_youtube_service(), refresh_token()
- First run: opens browser for consent; subsequent: uses stored token
