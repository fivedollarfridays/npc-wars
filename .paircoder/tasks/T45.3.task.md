# Objective

Add visual polish to round transitions and match flow — brief fade between rounds, final standings presentation, winner celebration.

# Implementation Plan

1. Round transition effect in viewer/js/renderer.js:
   - Brief 100ms dim (canvas globalAlpha 0.7) between rounds
   - Round number flash in center ("R15" in large text, fades in 500ms)
   - Storm closing indicator when storm_border increases

2. Winner celebration in viewer/js/effects.js:
   - When match ends: golden particle fountain from winner position
   - Winner character shape pulses bright
   - "WINNER" text scales up with glow
   - Existing winner overlay enhanced with these effects

3. Match start intro:
   - Brief pan across all bot positions
   - Each bot highlighted with name tag for 200ms
   - "FIGHT!" text flash before round 1

# Acceptance Criteria

- [ ] Round transitions have brief visual indicator
- [ ] Winner celebration has particle effects
- [ ] Match start shows bot introductions
- [ ] All effects tie to existing spectacle tier system
