# Objective

Add Discord match result announcements and a challenge command. After a match completes on the server, post results to a Discord channel.

# Context

- discord_bot/ directory has an existing bot with /leaderboard command
- discord_bot/bot.py initializes the bot
- discord_bot/commands/leaderboard.py has the leaderboard slash command
- engine/discord_integration.py has notify_match_start/notify_match_end hooks

# Implementation Plan

1. Create `discord_bot/commands/announce.py`:
   - Post match result embed to a configured channel after match completes
   - Embed shows: winner, kill feed, top stats, match duration, link to replay
   - Triggered by server worker after match completion (webhook or direct call)

2. Create `discord_bot/commands/challenge.py`:
   - `/challenge @player` slash command
   - Creates a private lobby for the two players
   - Both must upload bots within 5 minutes
   - Match auto-runs when both bots are submitted

3. Wire match completion → Discord announcement:
   - In server/worker.py, after match completes, call announcement function
   - Or: add a webhook endpoint that the worker POSTs to

4. Configure Discord channel for announcements:
   - Environment variable: DISCORD_ANNOUNCE_CHANNEL_ID
   - Bot checks channel exists on startup

5. Tests in `tests/test_discord_announce.py`:
   - Announcement embed has correct fields
   - Challenge command creates lobby
   - Mock Discord API for tests

# Acceptance Criteria

- [ ] Match results posted to Discord channel after completion
- [ ] Embed shows winner, kills, stats, replay link
- [ ] /challenge command creates private lobby
- [ ] Tests pass with mocked Discord API
