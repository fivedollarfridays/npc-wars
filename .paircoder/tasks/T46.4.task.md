# Objective

Validate the cosmetic system end-to-end: earn coins → buy cosmetic → equip → see it in match.

# Implementation Plan

1. Create `tests/test_s46_integration.py`:

   **TestCosmeticFlow**
   - Player earns coins from match
   - Player buys cosmetic from store
   - Player equips cosmetic
   - Match includes equipped cosmetics in player data

   **TestStoreAPI**
   - GET /api/store returns catalog
   - POST /api/store/buy works with sufficient coins
   - POST /api/store/buy fails with insufficient coins

   **TestViewerRendering**
   - shapes.js handles cosmetic color override
   - effects.js handles cosmetic death effect
   - Store page HTML exists

- [ ] Full cosmetic loop works (earn → buy → equip → render)
