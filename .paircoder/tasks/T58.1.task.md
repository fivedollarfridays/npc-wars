# Kill Switch rivalry tracker

Build `engine/rivalry.py` and `data/rivalry_db.py` to track head-to-head history between bot pairs across matches. Iterate `data/match_history` and `data/matchup_stats` to aggregate wins, losses, kill counts, streaks, and rounds of dominance per bot pair. Output a rivalry score (0-100), trending direction, and notable stats as JSON. This becomes the data source for commentary callouts and episode cold opens.

# Acceptance Criteria

- [x] `compute_rivalry(emoji_a, emoji_b, results_dir)` returns rivalry dict with wins, losses, streak, score
- [x] Rivalry score 0-100 reflects historical dominance (50 = even, 100 = total dominance)
- [x] Handles edge cases: no history, single match, same bot
- [x] All functions are pure (no I/O in core logic; I/O wrapper separate)
- [x] Tests cover 0, 1, 5+ match histories
