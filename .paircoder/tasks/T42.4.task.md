# Objective

End-to-end validation: two players upload bots from different "machines" (simulated), they fight on the server, both can watch the replay.

# Implementation Plan

1. Create `tests/test_s42_integration.py`:

   **TestServerE2E**
   - Start FastAPI TestClient
   - Player A: POST /api/submit-bot → get API key + bot_id
   - Player B: POST /api/submit-bot → get API key + bot_id
   - Both: POST /api/lobby/join with bot_id
   - Lobby fills with AI bots → match runs
   - Both: GET /api/match/{match_id} → valid replay JSON
   - Replay has both players' bots

   **TestPlayerAuth**
   - No API key → auto-generates one
   - Valid key → authenticated
   - Invalid key → 401
   - Player can list their bots

   **TestLobbyFlow**
   - Join lobby → status shows waiting
   - 4 players join → match auto-triggers
   - Match result accessible after completion

   **TestCLIUpload**
   - CLI upload command sends bot to server
   - API key saved to config

2. Manual validation:
   - Start server: `uvicorn server.app:app`
   - Terminal 1: `agentgrounds wars upload bots/reaper.py`
   - Terminal 2: `agentgrounds wars upload bots/example_tank.py`
   - Both see match result

# Acceptance Criteria

- [ ] Two simulated players upload and fight successfully
- [ ] Replay accessible by both players
- [ ] Auth flow works (auto-generate + validate)
- [ ] Lobby fills and triggers match
- [ ] CLI upload command works against test server
