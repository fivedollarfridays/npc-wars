# Objective

Add dodge mechanic: after a hit is confirmed, defender rolls dodge based on SPEED-derived dodge_chance. Dodged hits deal half damage.

# Design

- In `_resolve_hit()` (combat_rolls.py), after confirming roll >= AC:
  - Roll dodge: `rng.random() < defender.dodge_chance / 100`
  - If dodged: `damage = damage // 2` (minimum 1)
  - Crits can be dodged (still deal crit_damage // 2)
- Add `dodged: bool` field to CombatResult
- Add `defender` DerivedStats parameter to `_resolve_hit()`
- Hit events get `"dodged": true/false` field
- Update `_fmt_hit` in feed.py to show "glancing" for dodged hits

# Default stats: dodge_chance=10% (SPEED=25)
