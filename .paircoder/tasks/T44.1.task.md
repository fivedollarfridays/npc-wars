# Objective

Create `engine/character.py` — generates a character descriptor dict from stats + equipment that the viewer uses for rendering. Single source of truth for visual identity.

# Implementation Plan

1. Create `engine/character.py`:
   - `build_character_descriptor(stats, equipment, archetype) -> dict`
   - Returns: shape, color, border_thickness, weapon_indicator, size_scale, glow_tier
   - Shape: circle/square/triangle/hexagon/diamond from archetype
   - Color: hex color from archetype (red/blue/purple/green/white)
   - Border: 1-3px from armor type (leather=1, chain=2, reinforced=2, plate=3, crystal=1)
   - Weapon: indicator type (dot/line/long_line/wedge/arc/circle) from weapon name
   - Size: base 14 + (armor_stat - 25) * 0.15

2. Add character descriptor to match JSON:
   - In match_setup.py or game.py, compute descriptor per bot
   - Add to `players` list in match data: `"character": {...}`

3. Tests in `tests/test_character.py`

# Acceptance Criteria

- [ ] build_character_descriptor returns correct shape/color/border for each archetype
- [ ] Weapon indicator mapped correctly for all 6 weapons
- [ ] Armor border thickness correct for all 5 armors
- [ ] Character data in match JSON
- [ ] Tests pass, ruff clean
