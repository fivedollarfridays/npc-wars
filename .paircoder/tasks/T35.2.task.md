# Objective

Wire equipment bonuses into the combat pipeline. Weapons modify to-hit and damage. Armor modifies DR and action energy costs. Accessories add stat bonuses.

# Implementation Plan

1. Add equipment fields to `Bot` class in `engine/combat.py`:
   - `equipment: dict` — raw loadout selections
   - `equipment_bonuses: EquipmentBonuses` — computed bonuses (from compute_equipment_bonuses)
   - Apply bonuses to derived stats during bot init (max_hp, max_energy, dodge, crit, initiative, DR, energy_regen)

2. Modify `engine/combat_rolls.py`:
   - `_compute_ac()` — add `equipment_dr: int = 0` parameter
   - `roll_attack()` — add `equipment_to_hit: int = 0` parameter, apply to modifier
   - `roll_ranged_attack()` — same
   - `calculate_hit_probability()` — include equipment bonuses

3. Modify `engine/rounds.py` or `engine/rounds_combat.py`:
   - Pass equipment bonuses when calling `roll_attack()` / `roll_ranged_attack()`
   - Apply weapon damage bonuses (min/max) to the damage range before roll
   - Apply armor energy penalties via modified `apply_action_cost()`

4. Handle weapon specials:
   - `finesse`: add `(bot.stats.speed - 25) // 10` to to-hit (if speed > 25)
   - `armor_piercing`: reduce defender's DR by pierce amount before AC calc
   - `reach`: allow attack at 2-tile distance (modify adjacency check)

5. Modify `Bot.apply_action_cost()` to include armor energy penalties

6. Tests in `tests/test_equipment_combat.py`

# Key Context

- `roll_attack()` is in `engine/combat_rolls.py` — takes DerivedStats, returns CombatResult
- `_roll_melee()` in `engine/rounds_combat.py` calls `roll_attack()` and applies damage to bots
- `apply_action_cost()` uses `ACTION_COSTS` dict
- Equipment bonuses should be additive (not multiplicative) with existing stat-derived values
