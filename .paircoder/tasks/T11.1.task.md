# Objective

Define an abstract interface for human input sources that the engine can consume during copilot mode. Create the `HumanInputAdapter` ABC and two concrete implementations: `MockInputAdapter` for testing and `LocalInputAdapter` for keyboard input.

# Implementation Plan

1. **Create `tests/test_human_input.py`** with tests for:
   - `MockInputAdapter.get_action` returns pre-configured actions in sequence
   - `MockInputAdapter.get_action` returns `None` after exhausting the sequence (simulates timeout)
   - `get_action` receives a `state` dict and a `timeout_s` float
   - Timeout returns `None` (meaning bot's `decide()` is used as fallback)
   - Multiple calls return actions in order

2. **Create `engine/human_input.py`**:
   - `HumanInputAdapter` ABC:
     - Abstract method `get_action(state: dict, timeout_s: float) -> tuple | None`
     - `state` is the same state dict the bot sees
     - Returns an action tuple like `("move", "east")` or `("attack", "north")` or `None` on timeout
   - `MockInputAdapter(HumanInputAdapter)`:
     - `__init__(actions: list[tuple | None])` -- accepts a list of pre-configured actions
     - `get_action` pops and returns the next action from the list; returns `None` if list is empty
   - `LocalInputAdapter(HumanInputAdapter)`:
     - `get_action` reads keyboard input with a timeout (using `select` or `threading.Timer`)
     - Maps arrow keys to move actions, WASD to attack directions, R to rest, D to defend
     - Returns `None` if no input within `timeout_s`

3. **Ensure clean interface boundary**:
   - The adapter does NOT validate actions -- that is the engine's job (T11.3)
   - The adapter does NOT know about bot logic -- it only collects raw human input
   - The adapter is injected into the match runner, not imported globally

# Acceptance Criteria

- [ ] ABC defines `get_action` with `state: dict` and `timeout_s: float` parameters
- [ ] `MockInputAdapter` returns pre-configured action sequence in order
- [ ] Timeout (or exhausted sequence) returns `None`, meaning bot's `decide()` is used
