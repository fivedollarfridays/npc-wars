# Objective

Create `engine/stats.py` with the stat allocation system: `StatAllocation` dataclass, validation (sum=100, min=5, max=80), and default allocation constant.

# Implementation Plan

1. Create `engine/stats.py` with:
   - `StatAllocation` frozen dataclass: `power: int, speed: int, armor: int, mind: int`
   - `STAT_BUDGET = 100`, `STAT_MIN = 5`, `STAT_MAX = 80`
   - `DEFAULT_ALLOCATION = StatAllocation(25, 25, 25, 25)`
   - `validate_allocation(power, speed, armor, mind) -> StatAllocation` — raises ValueError if invalid
   - Add to `__all__`

2. Tests in `tests/test_stats.py`:
   - Valid allocation (25/25/25/25) passes
   - Valid asymmetric (50/20/15/15) passes
   - Sum != 100 raises ValueError
   - Any stat < 5 raises ValueError
   - Any stat > 80 raises ValueError
   - Default allocation is 25/25/25/25
