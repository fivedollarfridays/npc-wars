# Objective

Replace emoji text rendering with drawn geometric shapes. Each archetype gets a distinct shape and color. Equipment modifies the visual (weapon indicator, armor border thickness).

# Design (Geometry Wars aesthetic)

- **Shape from archetype** (using stats from match JSON):
  - Balanced (all 20-30) → circle
  - Tank (ARMOR > 35) → square
  - Assassin (SPEED > 35) → triangle (pointing up)
  - Bruiser (POWER > 35) → hexagon
  - Controller (MIND > 35) → diamond
  - Default → circle

- **Size from ARMOR stat**: higher armor = larger shape (20-32px radius range)

- **Color from archetype**:
  - Bruiser → red (#ff4444)
  - Tank → blue (#4488ff)
  - Assassin → purple (#aa44ff)
  - Controller → green (#44ff88)
  - Balanced → white (#ffffff)

- **HP-dependent rendering**:
  - >75% HP → full brightness/saturation
  - 50-75% → slightly desaturated
  - 25-50% → desaturated + yellow tint
  - <25% → dim + red tint + flickering (toggle opacity each frame)

- **Equipment indicators**:
  - Weapon: small shape attached to bot (dot for dagger, line for sword/spear, wedge for axe, circle for mace, arc for bow)
  - Armor border: thin (leather) → medium (chain/reinforced) → thick (plate)

- **Momentum aura**: tier 3+ gets glow ring around shape, leader gets bright pulse

# Implementation Plan

In `viewer/match.html`, modify the bot drawing section of `renderCanvas`:

1. For each alive bot, instead of `fillText(emoji)`:
   - Determine archetype from stats (need archetype in match JSON — already added in S38)
   - Draw filled shape at bot position with archetype color
   - Apply HP-based color modification
   - Draw border with armor-appropriate thickness
   - Draw small weapon indicator
   - If momentum tier >= 3, draw glow ring

2. Keep emoji as fallback for old match JSONs without archetype data

3. Keep HP bar and energy bar below the shape (already exist)

4. Dead bots: draw shape at 20% opacity with X through it

# Acceptance Criteria

- [ ] Bots render as colored geometric shapes, not emoji text
- [ ] Different archetypes produce different shapes
- [ ] HP affects color brightness/saturation
- [ ] Armor affects border thickness
- [ ] Weapon type shown as small indicator
- [ ] Momentum aura visible for tier 3+
- [ ] Old match JSONs fall back to emoji rendering
- [ ] Dead bots visually distinct
