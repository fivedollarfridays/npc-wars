# Objective

Create `engine/spectacle.py` with a `SpectacleEngine` class that scores each round's intensity using a weighted drama formula. The engine consumes round events and bot state to produce a `SpectacleData` object containing the drama score. This is the foundational component for all spectacle effects in Sprint 3.

# Implementation Plan

1. **Create `tests/test_spectacle.py`** with tests for:
   - `score_round` returns `SpectacleData` with `drama_score` of 0 for an empty round (no events, no low-HP bots)
   - Kills in events add 3 points each to drama score
   - Bumper chain events add 2 points each
   - Near-death detection: bots that survived the round with <5 HP add 4 points each
   - Streak events (kill streaks) add 5 points each
   - Watcher sync milestone events add 3 points each
   - Multiple event types in one round accumulate correctly

2. **Create `engine/spectacle.py`**:
   - `SpectacleData` dataclass with fields: `drama_score: int`, `near_deaths: list[str]` (emoji list of near-death bots)
   - `SpectacleEngine` class with method `score_round(events: list[dict], bots: list[dict]) -> SpectacleData`
   - Drama formula: `kills * 3 + bumper_chains * 2 + near_death_escapes * 4 + streak_events * 5 + watcher_sync_milestone * 3`
   - Near-death detection: iterate `bots` list, check for `hp > 0 and hp < 5` after round resolution
   - Event type counting: count events by `type` field -- `"kill"` for kills, `"chain_bump"` for bumper chains, `"kill_streak"` for streaks, `"watcher_sync"` for watcher milestones

3. **Run tests and verify** all pass with correct weights

# Acceptance Criteria

- [ ] `score_round` returns `SpectacleData` with `drama_score` as int
- [ ] Empty round (no events, no low-HP bots) scores 0
- [ ] Each event type contributes the correct weight: kills=3, bumper_chains=2, near_death=4, streaks=5, watcher_sync=3
- [ ] Near-death detected from bot HP after round resolution (survived with <5 HP)
