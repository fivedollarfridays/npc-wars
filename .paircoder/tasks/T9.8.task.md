# Objective

Gate new actions behind win streak thresholds via sandbox validation. Bots can only use actions they have unlocked through progression. The base 4 actions are always available; `ranged_attack` requires 3+ streak, `dash` requires 5+ streak, `taunt` requires 10+ streak. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 9.

# Implementation Plan

1. **Create `tests/test_action_gating.py`** with tests for:
   - Base actions (`move`, `attack`, `rest`, `defend`) always pass validation regardless of unlocked_actions
   - `ranged_attack` rejected when not in `unlocked_actions` list
   - `dash` rejected when not in `unlocked_actions` list
   - `taunt` rejected when not in `unlocked_actions` list
   - `ranged_attack` accepted when present in `unlocked_actions`
   - Rejection counts as a `consecutive_failure`
   - Locked action returns `None` from validate

2. **Update `validate_action()` in `engine/sandbox.py`**:
   - Accept an `unlocked_actions: list[str] | None` parameter
   - Before standard validation, check if the action type is in `unlocked_actions`
   - If not unlocked, return `None` (treated as invalid action)

3. **Update `execute_decide` and `resolve_decisions`** to pass `unlocked_actions` from the bot's profile data through to validation

# Acceptance Criteria

- [x] Base 4 actions always pass validation
- [x] ranged_attack rejected if not in unlocked_actions
- [x] dash rejected if not in unlocked_actions
- [x] taunt rejected if not in unlocked_actions
- [x] Rejection counts as consecutive_failure
