# Objective

Implement the `evolve` callback (level 22+). Called once mid-match when a trigger condition is met, allowing bots to adapt their strategy.

# Design

Evolve triggers when the bot reaches 3 kills OR round 20 (whichever first). The callback can modify the bot's ability definition or swap tactical focus.

```python
def evolve(state):
    """Called once when evolve triggers. Return adaptation dict."""
    return {
        "ability_boost": 10,    # +10 potency to ability
        "stat_shift": {"power": +5, "speed": -5},  # within original budget
    }
```

# Implementation Plan

1. Add to `engine/callback_runner.py`:
   - `check_evolve_trigger(bot, round_num) -> bool` — 3 kills or round 20
   - `run_evolve_callback(bot, round_num, grid_size, storm_border) -> None`
   - Track `bot.has_evolved: bool` to ensure single invocation

2. Wire into game loop:
   - After scoring each round, check evolve trigger for alive bots with evolve callback
   - If triggered, call callback, validate response, apply adaptations
   - Generate evolve event in round data

3. Validate adaptations:
   - stat_shift must sum to 0 (budget-neutral)
   - ability_boost capped at +15 potency
   - Invalid adaptations silently ignored

4. Tests in `tests/test_evolve.py`

# Acceptance Criteria
