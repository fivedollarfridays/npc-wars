# Objective

Add situational to-hit modifiers: resting targets are easier to hit, taunted attackers are less accurate.

# Design

Add `to_hit_modifier: int = 0` parameter to `roll_attack()` and `roll_ranged_attack()`. The modifier is added to the roll total.

Modifiers computed in rounds_combat.py before calling roll:
- Target resting: +3 to-hit (`actions.get(target.emoji)[0] == "rest"`)
- Attacker taunted attacking non-taunter: -3 to-hit (`bot.taunt_target and target.emoji != bot.taunt_target`)

Constants: `REST_HIT_BONUS = 3`, `TAUNT_HIT_PENALTY = 3`

# Acceptance Criteria

- [ ] roll_attack accepts to_hit_modifier parameter
- [ ] Resting targets get hit more often
- [ ] Taunted attackers miss more when attacking non-taunter
- [ ] Modifier appears in combat events
- [ ] Tests pass, ruff clean
