# Objective

Add `agentgrounds wars leaderboard` CLI command that fetches rankings from the server.

# Context

- CLI profile command exists (cmd_profile.py) — shows local profile from SQLite
- Server has GET /api/leaderboard endpoint
- CLI upload command (cmd_upload.py) handles server URL + API key config

# Implementation Plan

1. Create `agentgrounds/wars/cli/cmd_leaderboard.py`:
   - `agentgrounds wars leaderboard` — fetch from server, display ranked table
   - `--local` flag falls back to local profile_db leaderboard
   - `--sort wins|kills|win_rate` — sort options
   - Uses server URL from ~/.agentgrounds/config.json (same as upload)
   - Falls back to local if server unreachable

2. Register in CLI __init__.py

3. Tests in `tests/test_cli_leaderboard.py`

# Acceptance Criteria

- [ ] `agentgrounds wars leaderboard` shows ranked players
- [ ] Fetches from server by default
- [ ] Falls back to local if server unavailable
- [ ] Sort options work
