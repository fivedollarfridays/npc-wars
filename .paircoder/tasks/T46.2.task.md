# Objective

Create API endpoints for browsing, purchasing, equipping cosmetics and earning coins from matches.

# Implementation Plan

1. Create `server/routes/cosmetics.py`:
   - GET /api/store — browse cosmetic catalog with prices
   - GET /api/inventory — player's owned cosmetics (requires auth)
   - POST /api/store/buy — purchase cosmetic (requires auth, deducts coins)
   - POST /api/inventory/equip — equip a cosmetic (requires auth)
   - POST /api/inventory/unequip — unequip a cosmetic
   - GET /api/coins — player's coin balance

2. Wire coin rewards into match completion:
   - In server/worker.py or server/routes/lobby.py: after match, award coins
   - 10 coins per participant, 25 bonus for winner

3. Include equipped cosmetics in match JSON:
   - When building bot configs for match, fetch equipped cosmetics
   - Add `cosmetics` dict to player data in match result

4. Register routes in server/app.py

5. Tests in `tests/test_cosmetic_api.py`

# Acceptance Criteria

- [ ] GET /api/store returns catalog
- [ ] POST /api/store/buy deducts coins, adds to inventory
- [ ] POST /api/inventory/equip marks cosmetic as equipped
- [ ] Coins awarded after match completion
- [ ] Equipped cosmetics in match JSON player data
