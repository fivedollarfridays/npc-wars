# Objective

Polish the viewer UI: updated roster sidebar with archetype/equipment info, improved controls, mobile responsiveness.

# Implementation Plan

1. **Roster sidebar update:**
   - Show archetype name next to bot shape (e.g., "Bruiser" tag)
   - Show weapon + armor names (e.g., "Axe / Plate")
   - Show score and momentum tier
   - Color-code roster entries by archetype color
   - Sort by placement (alive first, then by elimination order)

2. **Kill feed update:**
   - Add icons for new event types (trap 🪤, ability 🔮, tactical ⚡, evolve 🧬)
   - Show damage numbers in feed entries
   - Limit feed to last 10 entries (scrollable)

3. **Map info:**
   - Show map name prominently (e.g., "Fortress" in header)
   - Show terrain legend (wall/water/high_ground/cover/crystal icons with labels)

4. **Controls polish:**
   - Add zoom buttons (+/- or mousewheel)
   - Center-on-action button (auto-tracks clusters of combat)
   - Round counter: "Round 15 / 41"

5. **Mobile responsive:**
   - Canvas fills viewport width on mobile
   - Roster collapses to bottom drawer
   - Kill feed overlays bottom of canvas (semi-transparent)
   - Touch controls for playback

# Acceptance Criteria

- [ ] Roster shows archetype, equipment, score
- [ ] Kill feed shows new event types with icons
- [ ] Map name displayed
- [ ] Zoom works (mousewheel or buttons)
- [ ] Mobile layout usable
