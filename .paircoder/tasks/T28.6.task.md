# Objective

Ensure all combat events include roll data for the renderer and viewer. Verify event schema consistency.

# Event Schema

- Hit: `{"type": "hit", "attacker": ..., "target": ..., "damage": N, "hp_before": N, "roll": N, "ac": N, "is_crit": bool}`
- Attack miss: `{"type": "attack_miss", "attacker": ..., "target": ..., "roll": N, "ac": N}`
- No-target miss: `{"type": "miss", "attacker": ..., "direction": ...}` (unchanged)
- Ranged hit: same as hit but type="ranged_hit"
- Ranged attack miss: `{"type": "ranged_attack_miss", ...}`
- Ranged no-target miss: `{"type": "ranged_miss", ...}` (unchanged)

# Acceptance Criteria

- [ ] Hit events have roll, ac, is_crit fields
- [ ] Attack miss events have roll, ac fields
- [ ] Ranged hit/miss events have same roll data
- [ ] No-target misses unchanged
- [ ] Match JSON contains roll data in events
- [ ] Tests pass, ruff clean
