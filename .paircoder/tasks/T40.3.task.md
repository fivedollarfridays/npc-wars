# Objective

Ensure `agentgrounds wars init` creates a complete, working arena in any directory after pip install. Polish the first-run experience.

# Current Problem

The init command copies bots from `agentgrounds/wars/builtin_bots/` but may not include all the bots we've created (trapper, knight, mage, etc.). Need to verify all starter bots are bundled.

# Implementation Plan

1. Verify `agentgrounds wars init`:
   - Creates bots/ directory with starter bots
   - Creates replays/ directory
   - Creates agentgrounds.toml config
   - Works from any directory (not just repo root)

2. Ensure builtin bots include a good starter set:
   - starter.py (guided TODOs)
   - template.py (blank template)
   - example_aggro.py, example_tank.py, example_kiter.py (demonstrates different playstyles)
   - example_random.py, example_vibes.py (simple examples)
   - Do NOT include trapper/knight/mage/viper (those use advanced features)

3. Post-init message:
   - Clear next steps: "Run `agentgrounds wars play` to watch your first match"
   - Mention `agentgrounds wars generate` for AI-assisted bot creation
   - Mention `bots/starter.py` for learning

4. Fix any path issues when running from init'd directory (not repo)

5. Test: fresh directory, `agentgrounds wars init`, `agentgrounds wars play` — works

# Acceptance Criteria

- [ ] Init creates working arena from any directory
- [ ] Starter bots included and functional
- [ ] Post-init message guides next steps
- [ ] `agentgrounds wars play` works from init'd directory
- [ ] Tests pass
