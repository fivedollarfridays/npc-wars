# Objective

Build video composer: ffmpeg frame-to-MP4 pipeline.

# Implementation Plan

- Create video/video_render.py
- render_match_video(match_json_path, output_path, fps=4) -> MP4 path
- Pipeline: load match JSON -> generate frame per round -> pipe to ffmpeg
- Frame rate: 4 FPS default (each round = 0.25s)
- Resolution: auto from grid size + scoreboard width
- Codec: H.264 with decent quality preset
- Temp frames in memory (pipe to ffmpeg stdin), no disk I/O per frame

# Acceptance Criteria

- [ ] video/video_render.py exists
- [ ] Generates MP4 from match JSON
- [ ] Frames piped to ffmpeg (no temp files)
- [ ] Configurable FPS
- [ ] Output MP4 playable in standard players
- [ ] Tests verify MP4 creation and basic properties
- [ ] Under 400 lines
- [ ] All tests pass
