# Objective

Wire bumpers into `resolve_movement()` so collisions happen during the movement phase.

# Implementation Plan

1. Create `tests/test_bumper_integration.py`: test bump events appear in round data, test no-bump when moving to empty tile, test bump damage applied to HP
2. Refactor `resolve_movement()` in `engine/rounds.py`:
   - Collect intended moves as list of `(bot, new_x, new_y)`
   - Call `resolve_bumps()` to get final positions and events
   - Apply final positions to bots
   - Return bump events list
3. Update `_execute_round()` in `engine/game.py`: collect movement events, extend `round_events`
4. Update `build_round_record()` to include bump events

# Acceptance Criteria

- [ ] resolve_movement() returns bump event list
- [ ] Bump events appear in match JSON round data
- [ ] Moving to empty tile still works (no regression)
- [ ] Bump damage (wall splat, storm bounce) reflected in bot HP
- [ ] rounds.py stays <400 LOC
