# Objective

Add a pure-math hit probability calculator so bots can make informed attack decisions. Exposed in state dict as `state["me"]["hit_chance_vs"]`.

# Design

New function in `engine/combat_rolls.py`:
```python
def calculate_hit_probability(
    attacker: DerivedStats, defender: DerivedStats,
    *, defending: bool = False, to_hit_modifier: int = 0,
    momentum_defense_reduct: float = 0.0,
) -> dict[str, float]:
```

Returns: `{"hit_chance": 85.0, "crit_chance": 10.0, "dodge_chance": 10.0, "expected_damage": 22.5}`

Wire into `build_state()`:
```python
state["me"]["hit_chance_vs"] = {
    enemy.emoji: calculate_hit_probability(bot.derived, enemy.derived)
    for enemy in alive_enemies
}
```

# Acceptance Criteria

- [ ] calculate_hit_probability returns correct probabilities
- [ ] state["me"]["hit_chance_vs"] populated for each enemy
- [ ] Expected damage accounts for miss, dodge, and crit rates
- [ ] Tests pass, ruff clean
