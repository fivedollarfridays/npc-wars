# Objective

High momentum tiers drain energy each round. This forces high-tier bots to actively fight or rest — no coasting on bonuses.

# Drain Table

| Tier | Energy Drain per Round | Net with Tier 1 Bonus (+5 regen) |
|------|----------------------|----------------------------------|
| 0 | 0 | 0 |
| 1 | 0 | +5 net (pure bonus) |
| 2 | -3 | +2 net (slight cost) |
| 3 | -5 | 0 net (breakeven — leader pays to lead) |
| 4 | -8 | -3 net (leader bleeds energy) |

The drain is applied AFTER energy restore/deduction in the round. A bot at 0 energy with drain stays at 0 (no negative energy).

# Implementation Plan

1. **Add `TIER_ENERGY_DRAIN` dict to `engine/momentum.py`**:
   ```python
   TIER_ENERGY_DRAIN = {0: 0, 1: 0, 2: 3, 3: 5, 4: 8}
   ```

2. **Add `apply_energy_drain()` to `engine/momentum.py`**:
   - Takes a bot, deducts `TIER_ENERGY_DRAIN[bot.momentum_tier]` from energy
   - Clamp to 0 minimum

3. **Wire into game loop** (`engine/game.py`):
   - After `apply_momentum_bonuses()`, call `apply_energy_drain()` for each alive bot
   - This runs after the rest/energy phase, so the bot gets their rest benefit first, then pays the drain

4. **Add drain event to round data**:
   - `{"type": "momentum_drain", "emoji": bot.emoji, "energy_cost": N}` when drain > 0

5. **Tests** in `tests/test_energy_drain.py`:
   - Tier 0/1: no drain
   - Tier 2: -3 energy
   - Tier 3: -5 energy (leader)
   - Tier 4: -8 energy (leader)
   - Energy doesn't go below 0
   - Bot at 2 energy with tier 4 drain → 0 (not negative)

# Acceptance Criteria
