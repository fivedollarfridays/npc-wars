# Watcher dossier

Build `engine/watcher_dossier.py` to surface the Watcher's PatternTable as a human-readable dossier. Read pattern data via existing `server/rival_patterns.py` helpers (`get_pattern_summary`, `compact_for_embed`). Format as "Context: below_30_hp → Predicted action: rest (78%), Expected counter: attack". Include sync score as "How well does the Watcher know you?" percentage and pattern change rate between matches.

# Acceptance Criteria

- [ ] `build_dossier(player_id, patterns_dir, watcher_stats_path)` returns dossier dict
- [ ] Dossier includes: per-context predictions (top 3 actions with probabilities), sync_score, predictability_change
- [ ] Human-readable text summary generated (template-based)
- [ ] Returns empty/intro dossier for players with no history
- [ ] Tests cover: no data, 1 match, 5+ matches, high/low sync scores
- [ ] File under 200 LOC, ruff clean
