# Objective

Validate the complete install → play flow works end-to-end from a fresh environment.

# Gate Tests

1. **Clean install test:**
   - Create fresh venv
   - `pip install .` (or `pip install agent-grounds` from TestPyPI)
   - `agentgrounds --version` → shows version
   - `agentgrounds wars --help` → shows subcommands

2. **Init + play test:**
   - `cd /tmp && mkdir test-arena && cd test-arena`
   - `agentgrounds wars init`
   - `agentgrounds wars play --no-watch`
   - Match completes with results

3. **Generate test:**
   - `agentgrounds wars generate --strategy "aggressive" --name "Test" --emoji "🔥"`
   - Output includes game rules and bot instructions
   - No installation instructions or product pitches in output

4. **Post-install import test:**
   - `python -c "from agentgrounds import __version__; print(__version__)"`
   - `python -c "from agentgrounds.wars.helpers import Me, Enemies, Storm"`

5. **External user test gate (manual, not automated):**
   - Have someone who has never seen the project run the 3-command flow
   - Document where they get confused
   - Fix what they hit

# Implementation

Create `tests/test_s40_integration.py` with automated gate tests (1-4).
Gate test 5 is manual — document results in PR description.

# Acceptance Criteria

- [ ] All automated gate tests pass
- [ ] External user test completed (or documented as pending)
- [ ] Package builds and installs cleanly
- [ ] Full loop works: install → init → play → generate
