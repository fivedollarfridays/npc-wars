# Post-match hook: write match JSON to broadcast inbox

Add an optional post-match hook to `cmd_play.py` (and `cmd_race.py` for Code Circuit) that writes the finalized match JSON to a configurable "broadcast inbox" directory. The broadcast Sprint 2 watcher daemon in agentgrounds-web will poll that directory and trigger episode generation. Controlled via env var `BROADCAST_INBOX_PATH`; when unset, the hook is a no-op (preserves existing behavior). When set, the hook runs after `write_match()` and writes a copy (not a move) to `${BROADCAST_INBOX_PATH}/{game}/{match_id}.json`. Idempotent (overwrite on collision). Silent failures are NOT acceptable — log a warning if the write fails but don't block the match from completing.
