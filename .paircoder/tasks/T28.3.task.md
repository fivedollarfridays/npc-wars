# Objective

Thread the match-level `random.Random(seed)` through the game loop so combat rolls can use deterministic RNG. Currently the sync path discards the RNG (`_rng =` in game.py).

# Implementation Plan

1. `engine/game.py`:
   - `run_match()`: Change `_rng` to `rng`, pass to `_execute_round()`
   - `_execute_round()`: Add `rng: random.Random` parameter, pass to `_resolve_combat_phases()`
   - `_resolve_combat_phases()`: Add `rng: random.Random` parameter (will be passed to resolve_attacks in T28.4)

2. `engine/game_async.py`:
   - `_execute_round_async()`: Add `rng: random.Random` parameter, pass to `_resolve_combat_phases()`
   - `run_match_async()`: Already has `rng` from `_prepare_match()`, pass to `_execute_round_async()`

3. Do NOT change `resolve_attacks()` or `resolve_ranged_attacks()` signatures yet — that's T28.4/T28.5

# Acceptance Criteria

- [ ] run_match() retains rng from _prepare_match (no longer discarded)
- [ ] _execute_round() accepts and passes rng parameter
- [ ] _resolve_combat_phases() accepts rng parameter
- [ ] Async path threads rng through _execute_round_async
- [ ] Same seed produces same match results (determinism preserved)
- [ ] All existing tests still pass
- [ ] Tests pass, ruff clean
