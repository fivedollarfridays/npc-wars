# Objective

Add trap event rendering to the CLI feed and combat overlay so players can see trap placement and triggers during matches.

# Background

Traps work mechanically (S33) but are invisible to observers — `_FORMATTERS` in `feed.py` has no entries for `trap_placed` or `trap_trigger` events. Similarly, `overlay.py` doesn't show trap FX on the grid.

# Implementation Plan

1. Add to `agentgrounds/wars/cli/feed.py`:
   - `_fmt_trap_placed(evt, rnd)` — Format: `"R{rnd}: {emoji} 🪤 trap set ({x},{y})"`
   - `_fmt_trap_trigger(evt, rnd)` — Format: `"R{rnd}: {victim} 💥 hit {owner}'s trap! -{damage}hp"`
   - Register both in `_FORMATTERS` dict

2. Add to `agentgrounds/wars/cli/overlay.py`:
   - In `build_combat_overlay()`, handle `trap_trigger` events:
     - Show `💥` at trap trigger location `(x, y)`
   - Trap placement: show `🪤` at placement coords (if owner is alive)

3. Tests in `tests/test_trap_feed.py`:
   - trap_placed event formats correctly
   - trap_trigger event formats correctly
   - Unknown trap events don't crash formatter
   - Overlay includes trap trigger FX at correct position

# Key Context

- Feed formatters are functions `(evt: dict, rnd: int) -> str`
- `_FORMATTERS` dict maps event type string to formatter function
- Overlay returns `dict[tuple[int, int], str]` mapping grid coords to FX chars
- Trap events: `{"type": "trap_placed", "emoji": "🤖", "x": 5, "y": 3}` and `{"type": "trap_trigger", "victim": "🎯", "owner": "🤖", "damage": 22.5, "x": 5, "y": 3}`

# Acceptance Criteria

- [ ] `trap_placed` events show in kill feed with trap emoji
- [ ] `trap_trigger` events show in kill feed with damage
- [ ] Trap trigger shows FX on grid overlay
- [ ] Tests pass, ruff clean
