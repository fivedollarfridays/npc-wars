# Objective

Create `npcwars/cli/__init__.py` as the unified CLI entry point with argparse subcommands, and wire it into `pyproject.toml` as a console script.

# Implementation Plan

1. Create `npcwars/cli/__init__.py` with:
   - `main(argv=None)` — entry point function
   - argparse parser with subparsers: `init`, `wizard`, `validate`, `battle`
   - `--version` flag using `importlib.metadata.version("npc-wars")`
   - Each subcommand sets a `func` attribute; stub handlers print "Not implemented yet"
2. Add to `pyproject.toml`:
   - `[project.scripts]` section: `npcwars = "npcwars.cli:main"`

# Acceptance Criteria

- [ ] `npcwars/cli/__init__.py` exists with `main()` function
- [ ] `main(["--help"])` prints help with all 4 subcommands listed
- [ ] `main(["--version"])` prints version string
- [ ] `main(["init", "--help"])` prints init help
- [ ] `[project.scripts]` added to pyproject.toml
- [ ] 8+ tests in `tests/test_cli_dispatch.py`
- [ ] Tests pass, ruff clean
