# Objective

Build upload pipeline: generate metadata, thumbnail, and tags from match data.

# Implementation Plan

- Create youtube/upload.py
- upload_video(video_path, match_data) -> video_id
- Auto-generate: title ("NPC Wars Match #X -- Winner: BotName"), description (stats summary), tags
- Thumbnail: extract key frame (final kill or winner celebration)
- Category: Gaming (category_id=20)
- Privacy: unlisted by default, configurable
- Uses YouTube Data API v3 resumable upload
