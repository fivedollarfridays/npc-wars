# Objective

Implement Co-op Raid mode: 2-4 humans team up against 10-15 bots. Bounty rewards scale down with more humans to prevent snowballing. Humans can see each other's positions (team_members field in state dict). Friendly fire is ON (bumps still apply between humans). The Watcher spawns if humans are winning. Depends on T13.1, T11.4 (async tick), T11.6 (co-op state). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 6 (Scaling for Co-op), Section 10 (Co-op Raid).

# Implementation Plan

1. **Create `tests/test_coop.py`** with tests for:
   - Co-op mode accepts 2-4 humans (rejects 0, 1, or 5+)
   - Match starts with 10-15 bots plus the humans
   - Bounty rewards scale with human count: 1 human = full restore + 3 rounds, 2 = full restore + 2, 3-4 = energy only + 1
   - State dict includes `team_members` field with positions of allied humans
   - Friendly fire ON: bumps between humans still apply
   - Watcher spawns if humans are winning (watcher_enabled=True in ModeConfig)
   - Match JSON includes `"mode": "coop_raid"` in metadata

2. **Add Co-op Raid mode handling**:
   - Validate 2-4 human bots in bot list
   - Select 10-15 random bots from available pool
   - Place scaled bounties on all humans based on human count
   - Add `team_members` to each human's state dict: `[{"emoji": str, "x": int, "y": int, "hp": int}]`
   - Enable watcher spawn checks
   - Wire into `run_match(mode=MatchMode.COOP_RAID)`

3. **Run tests and verify** all pass
