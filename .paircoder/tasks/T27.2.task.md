# Objective

Add `DerivedStats` dataclass and `calculate_derived()` function to `engine/stats.py`. Maps raw stat allocation to gameplay values. Critical: default 25/25/25/25 must produce exactly current game values.

# Design

**DerivedStats fields:** max_hp, max_energy, min_damage, max_damage, crit_multiplier, dodge_chance, initiative, damage_reduction, energy_regen

**Formulas (25/25/25/25 = current game):**

- ARMOR → `max_hp = int(80 + armor * 0.8)` → 25 = 100 (current)
- ARMOR → `damage_reduction = max(0, int((armor - 25) * 0.3))` → 25 = 0 (current)
- MIND → `max_energy = int(80 + mind * 0.8)` → 25 = 100 (current)
- MIND → `energy_regen = max(0, int((mind - 25) * 0.2))` → 25 = 0 (current)
- POWER → `min_damage = max(1, int(power * 0.6))` → 25 = 15
- POWER → `max_damage = int(power * 1.4)` → 25 = 35 (avg 25, matching current flat 25)
- POWER → `crit_multiplier = 1.5 + (power - 25) * 0.02` → 25 = 1.5
- SPEED → `dodge_chance = min(40, power * 0.4)` → 25 = 10 (percent)
- SPEED → `initiative = speed` → 25 = 25
