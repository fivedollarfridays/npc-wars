# Objective

Extend bot loader to read BOT_POWER, BOT_SPEED, BOT_ARMOR, BOT_MIND from bot modules. Validate allocation. Pass through config dict to Bot construction.

# Implementation Plan

1. In `engine/loader.py`, read optional module attributes: BOT_POWER, BOT_SPEED, BOT_ARMOR, BOT_MIND (default 25 each)
2. Call `validate_allocation()` — log warning and use default on failure (don't crash loader)
3. Add `stat_allocation` to returned config dict
4. In `engine/game.py._create_bots()`, pass stat_allocation to Bot constructor
5. In `engine/bot_scanner.py`, validate stat constants are integer literals via AST check (optional enhancement)

# Acceptance Criteria

- [ ] Bots without stat constants load with 25/25/25/25
- [ ] Bots with valid stats (e.g., BOT_POWER=40) load with custom allocation
- [ ] Invalid stats (sum != 100) fall back to default with warning
- [ ] stat_allocation flows through config → _create_bots → Bot.__init__
- [ ] Tests pass, ruff clean
