# Objective

End-to-end integration tests validating all match modes run to completion and produce valid match JSON. Verify the scheduled match script works in dry-run mode. Fix any remaining failures across the full test suite. Depends on T13.1-T13.12.

# Implementation Plan

1. **Create `tests/test_integration_modes.py`** with integration tests:
   - **Classic mode**: Run a Classic match with 5 bots, verify match JSON has all required fields (rounds, positions, events, stats, winner)
   - **Invasion mode**: Run an Invasion match with 1 mock human + 5 bots, verify bounty placed, human_enter event in round 1, mode metadata
   - **Co-op Raid mode**: Run a Co-op match with 2 mock humans + 10 bots, verify team_members in state, scaled bounties, mode metadata
   - **Gauntlet mode**: Run a Gauntlet match with 1 mock human, verify wave progression events, stats scaling, match termination
   - **Boss Fight mode**: Run a Boss Fight with 2 mock humans + 1 boss, verify boss stats (500 HP, 2x damage), match termination conditions
   - **Scheduled match script**: Run `scripts/scheduled_match.py --dry-run` via subprocess, verify exit code 0
   - **Mode enum coverage**: Verify every `MatchMode` member has a corresponding `ModeConfig`

2. **Create shared fixtures**:
   - `mock_human_bot` — simulated human with predictable override pattern
   - `bot_pool` — collection of test bots for match population
   - `tmp_results_dir` — temporary directory for match output

3. **Run full test suite and fix any failures**:
   - `pytest --tb=short` must pass with 0 failures
   - No architecture violations in any modified files

# Acceptance Criteria

- [ ] All tests pass
- [ ] Each match mode produces valid match JSON
- [ ] Scheduled match script runs in dry-run mode
- [ ] No architecture violations
