# Objective

Display XP breakdown and level-up notifications in the console after each match completes.

# Output Format

```
── XP Awards ──────────────────────────
  GooseLoose    +150 XP  (10 base + 45 kills + 40 survival + 50 win + 5 bonus)
    ⟶ LEVEL UP! Level 4 → 5  ★ Unlocked: dash, on_kill()
  AggroBoy      +82 XP   (10 base + 30 kills + 32 survival + 0 win + 10 bonus)
  TankBot       +52 XP   (10 base + 0 kills + 42 survival + 0 win + 0 bonus)
  ChaosBot      +22 XP   (10 base + 0 kills + 12 survival + 0 win + 0 bonus)
────────────────────────────────────────
```

# Implementation Plan

1. Create `engine/xp_display.py` with `format_xp_summary(xp_awards: dict) -> str`
2. Call after XP calculation in match runner
3. Highlight level-ups with star marker and unlock list
4. Sort by XP earned descending
5. Tests in `tests/test_xp_display.py`

# Acceptance Criteria

- [ ] XP breakdown shows all components per bot
- [ ] Level-up highlighted with new unlocks listed
- [ ] Sorted by XP earned (winner first)
- [ ] Clean formatting, no extra dependencies
- [ ] Tests pass, ruff clean, < 400 lines
