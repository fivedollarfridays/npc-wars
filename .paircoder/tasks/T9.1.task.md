# Objective

Create a persistent JSON-based player profile system that stores bot identity, progression data (line budget, win streaks), and unlocked actions. This is the foundational data layer for all Sprint 2 progression features.

# Implementation Plan

1. **Create `tests/test_player_profiles.py`** with tests for:
   - Creating a new `PlayerProfile` with correct default values
   - Load/save roundtrip preserves all fields
   - Missing file on load creates a new empty profiles dict
   - `get_or_create_profile` returns existing profile when present
   - `get_or_create_profile` creates new profile with defaults when absent

2. **Create `data/player_profiles.py`**:
   - `PlayerProfile` dataclass with fields:
     - `player_id: str` (GitHub username)
     - `bot_name: str`
     - `emoji: str`
     - `line_budget: int` (default `50`)
     - `wins: int` (default `0`)
     - `current_streak: int` (default `0`)
     - `best_streak: int` (default `0`)
     - `unlocked_actions: list[str]` (default `["move", "attack", "rest", "defend"]`)
     - `watcher_encounters: int` (default `0`)
     - `watcher_wins: int` (default `0`)
     - `watcher_losses: int` (default `0`)
   - `load_profiles(path: Path) -> dict[str, PlayerProfile]` -- reads JSON, returns dict keyed by player_id
   - `save_profiles(profiles: dict[str, PlayerProfile], path: Path) -> None` -- writes JSON
   - `get_or_create_profile(profiles: dict[str, PlayerProfile], player_id: str, bot_name: str, emoji: str) -> PlayerProfile`

3. **Storage**: `data/profiles.json` (add to `.gitignore`)

# Acceptance Criteria

- [x] PlayerProfile has all required fields with correct defaults
- [x] load/save roundtrip preserves all data
- [x] get_or_create returns existing profile or creates new with defaults
- [x] line_budget defaults to 50, unlocked_actions defaults to base 4
- [x] Missing profiles.json file handled gracefully (returns empty dict)
