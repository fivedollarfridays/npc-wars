# Objective

Add audio stingers for new event types (abilities, traps, terrain) and terrain-specific ambient audio.

# Context

- viewer/js/audio.js has AudioEngine class with Web Audio API
- 15 existing WAV stingers in audio/assets/
- AudioEngine.play(eventType, tier) plays stingers synced to spectacle tier
- New event types: trap_trigger, tactical_activate, ability_damage, ability_heal, crystal_pickup, evolve

# Implementation Plan

1. Generate new audio stingers using Web Audio API synthesis (no external files needed):
   - In viewer/js/audio.js, add synthesized stinger functions:
     - `playTrapTrigger()` — sharp metallic snap + reverb
     - `playTacticalActivate()` — rising energy whoosh
     - `playAbilityDamage()` — deep impact thud
     - `playAbilityHeal()` — gentle chime ascending
     - `playCrystalPickup()` — sparkle arpeggio
     - `playEvolve()` — dramatic chord swell
   - Use oscillator + gain envelope patterns (no WAV files needed)

2. Add terrain ambient:
   - Water tiles: subtle low-frequency hum when camera near water
   - Storm: wind howl intensifies as storm closes (tie to storm_border)
   - Crystal: gentle ping when near uncollected crystal

3. Wire into viewer/js/events.js:
   - On each new event type, call the appropriate synth stinger
   - Events already render visually — just add audio trigger

4. Volume controls: tie to existing AudioEngine volume/mute

# Acceptance Criteria

- [ ] Trap trigger plays metallic snap sound
- [ ] Ability damage plays impact thud
- [ ] Ability heal plays ascending chime
- [ ] Crystal pickup plays sparkle
- [ ] All synthesized (no external audio files needed)
- [ ] Tied to existing volume/mute controls
