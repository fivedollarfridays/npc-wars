# Objective

Build results display: Discord embed with stats, kills, placements.

# Implementation Plan

- Create discord_bot/commands/results.py
- /results [match_id]: show match results (defaults to latest)
- Embed fields: winner, placements, kills, damage dealt, rounds survived
- Per-bot breakdown in embed fields
- Pagination for long results (buttons or multiple embeds)
