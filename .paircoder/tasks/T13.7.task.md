# Objective

Create a script for automated weekly match execution suitable for cron scheduling. The script runs a Classic match, saves results to the results/ directory, and exits cleanly. Configurable match parameters (seed, bot count) via command-line args or environment variables. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 11 (Weekly scheduled matches).

# Implementation Plan

1. **Create `tests/test_scheduled_match.py`** with tests for:
   - Script parses command-line arguments (--seed, --bot-count, --dry-run, --output-dir)
   - --dry-run flag prints configuration without running a match
   - Match results saved to `results/` directory with timestamped filename
   - Script exits 0 on success
   - Script exits 1 on failure (e.g., no bots available)
   - No interactive input required (suitable for cron)
   - Default bot count matches Classic mode config

2. **Create `scripts/scheduled_match.py`**:
   - Parse arguments: `--seed` (int, optional), `--bot-count` (int, default from ModeConfig), `--dry-run` (flag), `--output-dir` (str, default "results/")
   - Load available bots from bots/ directory
   - Run `run_match(mode=MatchMode.CLASSIC, seed=seed, bots=selected_bots)`
   - Save match JSON to `{output_dir}/match_{timestamp}.json`
   - Print summary to stdout (winner, kill count, rounds)
   - Exit 0 on success, exit 1 on any error
   - Cron example in docstring: `0 20 * * 5 python scripts/scheduled_match.py`

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Script runs match and saves results to results/
- [ ] Configurable match parameters (seed, bot count)
- [ ] Exit 0 on success, exit 1 on failure
- [ ] Suitable for cron execution (no interactive input)
