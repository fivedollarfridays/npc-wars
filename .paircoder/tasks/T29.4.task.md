# Objective

Higher SPEED bots resolve attacks first. If a fast bot kills a slow bot, the slow bot doesn't get to attack that round.

# Design

In `resolve_attacks()` (rounds_combat.py), sort attacking bots by `bot.derived.initiative` descending before iterating. Same in `resolve_ranged_attacks()`.

At default (all SPEED=25): initiative is equal, list order preserved (backward compatible).

# Acceptance Criteria

- [ ] Bots sorted by initiative before attack resolution
- [ ] Higher-SPEED bot's attack resolves first
- [ ] If fast bot kills slow bot, slow bot doesn't attack
- [ ] Default stats: no change in behavior
- [ ] Tests pass, ruff clean
