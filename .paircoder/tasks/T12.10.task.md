# Objective

Implement learning decay so The Watcher retains 70% of pattern data within a session and 30% between sessions. This prevents The Watcher from becoming omniscient while still letting it "remember" returning players. The `__global__` aggregate profile never decays, so The Watcher gets smarter community-wide over time. Depends on T12.9. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Learning Persistence).

# Implementation Plan

1. **Create `tests/test_watcher_decay.py`** with tests for:
   - Within-session decay: all per-player frequency counters multiplied by 0.7
   - Cross-session decay: all per-player frequency counters multiplied by 0.3
   - `__global__` profile is exempt from decay (counters unchanged)
   - Decay with retention_rate=1.0 leaves data unchanged
   - Decay with retention_rate=0.0 zeros out all per-player data
   - Decayed fractional counts are kept as floats (not rounded to zero prematurely)

2. **Add to `engine/watcher_memory.py`**:
   - `SESSION_RETENTION = 0.7`
   - `CROSS_SESSION_RETENTION = 0.3`
   - `decay_memory(pattern_table: PatternTable, retention_rate: float) -> None` — in-place mutation:
     - Iterate all player profiles except `__global__`
     - Multiply every frequency counter by `retention_rate`
     - Leave `__global__` profile untouched
   - Call `decay_memory(table, SESSION_RETENTION)` at session end (after a match batch)
   - Call `decay_memory(table, CROSS_SESSION_RETENTION)` on `load_memory()` (when loading from disk at startup)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Within-session retention = 70%
- [ ] Cross-session retention = 30%
- [ ] __global__ profile never decays
- [ ] Decay multiplies all frequency counters by retention rate
