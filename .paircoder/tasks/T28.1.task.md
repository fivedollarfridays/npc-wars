# Objective

Create `engine/combat_rolls.py` with the roll-based combat engine. CombatResult dataclass and `roll_attack()` function that resolves a melee attack using d20 mechanics.

# Design

- `CombatResult` frozen dataclass: hit, damage, roll, target_ac, is_crit, is_miss
- `BASE_AC = 5` — calibrated so default stats give ~85% hit rate
- `DEFEND_AC_BONUS = 8` — defending raises AC significantly
- `roll_attack(attacker, defender, *, defending, rng, momentum_damage_mult, momentum_defense_reduct) -> CombatResult`
- Roll: `rng.randint(1, 20) + attacker.initiative // 10`
- AC: `BASE_AC + defender.damage_reduction + (DEFEND_AC_BONUS if defending)`
- Miss: roll < AC → damage=0, is_miss=True
- Hit: roll >= AC → `rng.randint(attacker.min_damage, attacker.max_damage)`, apply momentum multipliers
- At default 25/25/25/25: to-hit +2, AC=5, hit on 3+ = 90%, avg damage=25

# Acceptance Criteria

- [ ] CombatResult dataclass with hit/damage/roll/target_ac/is_crit/is_miss
- [ ] roll_attack returns CombatResult with correct hit/miss logic
- [ ] Default stats: ~90% hit rate (d20+2 vs AC 5)
- [ ] Default stats: avg damage on hit = 25 (range 15-35)
- [ ] Defending target: AC=13, hit rate ~50%
- [ ] RNG is deterministic (same seed = same results)
- [ ] Tests pass, ruff clean
