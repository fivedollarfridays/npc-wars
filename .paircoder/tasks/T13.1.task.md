# Objective

Define match modes as an enum and their configuration parameters. Five modes exist: Classic (pure bot), Invasion (solo human), Co-op Raid (2-4 humans), Gauntlet (wave survival), and Boss Fight (humans vs community boss). Each mode specifies human/bot count ranges and Watcher availability. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 10 (Match Modes).

# Implementation Plan

1. **Create `tests/test_modes.py`** with tests for:
   - `MatchMode` enum has exactly 5 members: `CLASSIC`, `INVASION`, `COOP_RAID`, `GAUNTLET`, `BOSS_FIGHT`
   - Each mode has a corresponding `ModeConfig` with valid min/max human/bot counts
   - CLASSIC: min_humans=0, max_humans=0, min_bots=5, max_bots=20, watcher_enabled=False
   - INVASION: min_humans=1, max_humans=1, min_bots=5, max_bots=10, watcher_enabled=True
   - COOP_RAID: min_humans=2, max_humans=4, min_bots=10, max_bots=15, watcher_enabled=True
   - GAUNTLET: min_humans=1, max_humans=1, min_bots=3, max_bots=10 (waves), watcher_enabled=True
   - BOSS_FIGHT: min_humans=2, max_humans=4, min_bots=0, max_bots=0, boss_bot=True, watcher_enabled=False
   - `get_config(mode)` returns the correct `ModeConfig`

2. **Create `engine/modes.py`**:
   - `MatchMode` enum with values: `CLASSIC`, `INVASION`, `COOP_RAID`, `GAUNTLET`, `BOSS_FIGHT`
   - `ModeConfig` dataclass with fields:
     - `min_humans: int`, `max_humans: int`
     - `min_bots: int`, `max_bots: int`
     - `watcher_enabled: bool`
     - `boss_bot: bool = False`
   - `MODE_CONFIGS: dict[MatchMode, ModeConfig]` — mapping of each mode to its configuration
   - `get_config(mode: MatchMode) -> ModeConfig` — returns config for given mode

3. **Run tests and verify** all pass

# Acceptance Criteria
