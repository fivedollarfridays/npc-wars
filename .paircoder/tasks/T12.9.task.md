# Objective

Persist The Watcher's pattern tables across matches using JSON file storage. Pattern data survives process restarts so The Watcher retains learned human behavior across sessions. Depends on T12.2. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Learning Persistence) and Section 12 (watcher_memory.py).

# Implementation Plan

1. **Create `tests/test_watcher_memory.py`** with tests for:
   - `save_memory` writes pattern table to JSON file
   - `load_memory` restores full pattern data from JSON file
   - Save/load roundtrip preserves all player profiles, contexts, and counts
   - `load_memory` with missing file returns empty `PatternTable`
   - File path is configurable (not hardcoded)
   - JSON file is human-readable (indented)

2. **Add to `engine/watcher_memory.py`**:
   - `DEFAULT_MEMORY_PATH = "data/watcher_memory.json"`
   - `save_memory(pattern_table: PatternTable, path: str = DEFAULT_MEMORY_PATH) -> None`:
     - Serialize `PatternTable` internal data to JSON
     - Create parent directory if it does not exist
     - Write with indent=2 for readability
   - `load_memory(path: str = DEFAULT_MEMORY_PATH) -> PatternTable`:
     - If file does not exist, return empty `PatternTable()`
     - Read JSON, reconstruct `PatternTable` from data
   - Add `to_dict()` and `from_dict(data)` methods to `PatternTable` for serialization support

3. **Add `data/watcher_memory.json` to `.gitignore`** if not already present

4. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Pattern table saves to JSON
- [ ] Load restores full pattern data
- [ ] Missing file creates empty table
- [ ] File path configurable
