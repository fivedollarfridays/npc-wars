# Objective

Create `engine/xp.py` — pure functions that calculate XP earned per match for each participant. No DB dependency, no side effects.

# XP Formula (from roadmap)

| Source | XP | Condition |
|--------|-----|-----------|
| Base | 10 | Participation (every match) |
| Per kill | 15 | Per enemy eliminated |
| Per round survived | 2 | Each round alive |
| Win bonus | 50 | 1st place |
| 2nd place | 25 | Runner-up |
| 3rd place | 15 | Third |
| First blood | 20 | First kill of the match |
| Leader bounty | 25 | Killed the momentum leader |

# Implementation Plan

1. Create `XpBreakdown` dataclass: base, kills, survival, placement, bonuses, total
2. Create `calculate_match_xp(match_result) -> dict[str, XpBreakdown]` — takes match result dict, returns XP breakdown per bot name
3. Helper: `_placement_xp(placement: int) -> int`
4. Helper: `_bonus_xp(events: list) -> int` for first blood / leader bounty
5. Tests in `tests/test_xp.py`

# Acceptance Criteria

- [ ] `XpBreakdown` dataclass with all fields
- [ ] `calculate_match_xp()` returns correct XP per formula table
- [ ] Edge cases: 0 kills, 0 rounds, tie placements
- [ ] Pure functions — no DB, no I/O, stdlib only
- [ ] Tests pass, ruff clean, < 400 lines
