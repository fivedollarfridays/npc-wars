# Objective

End-to-end integration test verifying the complete XP flow: run a match → XP calculated → profiles updated → levels correct → CLI profile shows accurate data.

# Test Scenarios

1. **Fresh player flow**: Run match with new bots → profiles created → XP awarded → level 1 with correct XP
2. **Level-up flow**: Seed profile near level boundary → run match → verify level-up detected → new unlocks available
3. **Multi-match accumulation**: Run 3 matches → verify XP accumulates correctly across matches
4. **XP formula accuracy**: Known match result → verify exact XP breakdown matches formula
5. **Profile persistence**: Write profile → close DB → reopen → verify data intact
6. **No-XP flag**: Run with `--no-xp` → verify no profile changes
7. **Leaderboard ordering**: Multiple profiles → verify sorted by level then XP

# Implementation Plan

1. Create `tests/test_s32_integration.py`
2. Use in-memory SQLite for speed
3. Use deterministic match results (seeded RNG or mock)
4. Test the full pipeline: xp.py → levels.py → profile_db.py → match runner → display

# Acceptance Criteria

- [ ] All 7 test scenarios pass
- [ ] Tests use in-memory DB (fast, no disk)
