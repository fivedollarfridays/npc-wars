# Pool-bot liveness test

New `tests/test_pool_bot_liveness.py`: load every shipped bot (`agentgrounds/wars/builtin_bots/` plus `bots/`, excluding `template.py`) via `engine.loader.load_bots`, run each in a 2-bot match against a stationary dummy for 20 rounds with a fixed seed, and assert the bot never increments `consecutive_failures` and never dies by `disconnected`. Today this fails for Trapper, Viper, and Mage (they return locked `trap`/`use_ability` actions and disconnect by round 4) — mark those three `xfail(strict=True)` referencing T73.5, which makes locked actions degrade gracefully and flips the xfails. Also assert every bot survives the validator (`scripts/validate_bot.validate_bot`) so shipping a broken example becomes impossible.
