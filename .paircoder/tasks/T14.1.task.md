# Objective

Create `npcwars/builtin_bots/` package that ships 5 example bots + template inside the installed package, accessible via `importlib.resources`.

# Implementation Plan

1. Create `npcwars/builtin_bots/__init__.py` with:
   - `BUILTIN_NAMES: tuple[str, ...]` — names of all shipped bots
   - `list_builtin_bots() -> list[str]` — returns list of bot filenames
   - `get_bot_source(name: str) -> str` — reads and returns source text of a built-in bot
   - Use `importlib.resources.files("npcwars.builtin_bots")` for path resolution
2. Copy these existing bots from `bots/` into `npcwars/builtin_bots/`:
   - `example_aggro.py`, `example_tank.py`, `example_kiter.py`, `example_random.py`, `example_vibes.py`, `template.py`
3. Do NOT copy `goose_loose.py` (founder bot, stays in repo only)

# Acceptance Criteria

- [ ] `npcwars/builtin_bots/` is a proper Python package with `__init__.py`
- [ ] All 6 bot files exist in the package
- [ ] `list_builtin_bots()` returns 6 names
- [ ] `get_bot_source("template")` returns valid Python source
- [ ] `get_bot_source("nonexistent")` raises ValueError
- [ ] 6+ tests in `tests/test_builtin_bots.py`
- [ ] Tests pass, ruff clean
