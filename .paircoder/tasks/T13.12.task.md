# Objective

Lower the Python version requirement from 3.13 to 3.10 to expand the potential player base (~10x more compatible environments). The codebase uses `X | None` union syntax (3.10+) and `list[...]` generics (3.9+) -- nothing requires 3.11+. Verify no match/case statements, ExceptionGroups, or other 3.11+ features are used. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 14 (Python version requirement).

# Implementation Plan

1. **Audit codebase for 3.11+ features**:
   - Search for `match ` / `case ` statements (3.10 structural pattern matching is fine, but verify syntax)
   - Search for `ExceptionGroup`, `except*` (3.11+)
   - Search for `tomllib` usage (3.11+ stdlib; use `tomli` backport if needed)
   - Search for `StrEnum` (3.11+; use `str, Enum` mixin instead)
   - Search for `Self` type hint (3.11+; use `from __future__ import annotations` or string literal)

2. **Update `pyproject.toml`**:
   - Change `requires-python = ">=3.13"` to `requires-python = ">=3.10"`
   - Add any needed backport dependencies (e.g., `tomli` for <3.11)

3. **Update CI workflow** (`.github/workflows/*.yml`):
   - Add Python 3.10 to test matrix
   - Keep Python 3.13 in matrix
   - Verify all tests pass on both versions

4. **Update `CONTRIBUTING.md`**:
   - Change minimum Python version to 3.10
   - Note that union syntax `X | Y` is used (requires 3.10+)

5. **Run full test suite** on 3.10 if available, otherwise verify no incompatible syntax
