# Objective

Place bounties on human players that are visible in every bot's `state` dict, incentivizing bots to hunt humans. When a bot kills a bounty target, it receives a massive reward: full HP + full energy restore + 3 rounds of +50% damage bonus. No bounties in pure bot matches.

# Implementation Plan

1. **Create `tests/test_bounty.py`** with tests for:
   - `place_bounties` returns a bounty list when humans are present
   - `place_bounties` returns empty list in pure bot matches (no humans)
   - Bounty contains `target_emoji`, `target_x`, `target_y`, `reward`, `bonus_damage` fields
   - `claim_bounty` on kill: killer receives full HP restore + full energy restore
   - `claim_bounty` grants 3 rounds of +50% damage bonus
   - Bounty appears in `state["bounties"]` for all bots
   - Killing a non-bounty target does not trigger bounty rewards

2. **Create `engine/bounty.py`**:
   - `BountyInfo` dataclass: `target_emoji: str`, `target_x: int`, `target_y: int`, `reward: str`, `bonus_damage_rounds: int`
   - `place_bounties(bots: list[dict], humans: list[str]) -> list[BountyInfo]`
     - For each human-controlled bot, create a bounty with `reward="full_restore"` and `bonus_damage_rounds=3`
     - Position fields populated from bot's current x, y
     - Returns empty list if `humans` is empty
   - `claim_bounty(killer: dict, target: dict, bounties: list[BountyInfo]) -> dict | None`
     - Check if target's emoji matches any bounty target
     - If match: return reward dict `{"hp_restore": "full", "energy_restore": "full", "damage_bonus": 0.5, "bonus_rounds": 3}`
     - If no match: return `None`
   - `apply_bounty_reward(killer: dict, reward: dict) -> None`
     - Set killer HP to max, energy to max
     - Add damage bonus tracker: `killer["damage_bonus"] = {"multiplier": 1.5, "rounds_remaining": 3}`

3. **Wire bounties into state dict**:
   - In round setup, call `place_bounties` and add result to `state["bounties"]` as list of dicts
   - Each bot's state view includes the bounties list
   - After a kill, call `claim_bounty` and apply rewards

# Acceptance Criteria

- [ ] `state["bounties"]` contains bounty list when humans are present
- [ ] Bounty has `target_emoji`, `target_x`, `target_y`, `reward` fields populated
- [ ] Killing a bounty target triggers full HP + full energy restore
- [ ] Damage bonus (+50%) applied for 3 subsequent rounds after bounty kill
- [ ] No bounties in pure bot matches (empty list)
