# Objective

Update Bot.to_self_dict() and Bot.to_enemy_dict() to expose stat information. Bots see their own full stats; enemies show partial hints.

# Implementation Plan

1. `to_self_dict()` — add: `power, speed, armor, mind` (raw stats), `max_hp, max_energy, min_damage, max_damage, dodge_chance, damage_reduction` (derived)
2. `to_enemy_dict()` — add: `max_hp` (visible — you can see how beefy they are), `speed_class` (qualitative: "slow" if speed<15, "normal" if 15-30, "fast" if 30-45, "blazing" if 45+)
3. Update `build_round_record()` in `engine/rounds.py` to include `max_hp` in position data

# Acceptance Criteria

- [ ] state["me"] contains power, speed, armor, mind, max_hp, max_energy, min_damage, max_damage, dodge_chance, damage_reduction
- [ ] state["enemies"][i] contains max_hp and speed_class
- [ ] Round position data includes max_hp
- [ ] Tests pass, ruff clean
