# Objective

Integration gate for S28. Statistical validation that roll-based combat produces expected damage distributions. Verify events contain roll data.

# Tests

1. Run 50 seeded matches with 4x default (25/25/25/25) bots
2. Collect all hit events, verify avg damage per hit is 20-30
3. Collect all attack_miss events, verify miss rate is 5-20%
4. Collect all crit hits, verify crit rate is 5-15%
5. Verify match length is 15-60 rounds
6. Verify events contain roll/ac/is_crit fields
7. Run match with high-POWER bot (50), verify higher avg damage
8. Run match with high-ARMOR bot (50), verify lower hit rate against them
9. Verify all builtin bots still load and run
10. Full regression — no new test failures

# Acceptance Criteria

- [ ] Avg damage per hit: 20-30 at default stats
- [ ] Miss rate: 5-20% at default stats
- [ ] Crit rate: 5-15% of hits
- [ ] Match length: 15-60 rounds
- [ ] Events have roll/ac/is_crit data
- [ ] High POWER → more damage
- [ ] High ARMOR → fewer hits taken
- [ ] No regressions, ruff clean
