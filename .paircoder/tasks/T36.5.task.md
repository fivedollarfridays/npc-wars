# Objective

Create an example bot using the ability system and run balance sim.

# Implementation Plan

1. Create `bots/example_mage.py`:
   - High MIND stats (15/20/20/45)
   - Equipment: bow + crystal + pendant_of_mind + battle_cry
   - `power_up()` defines a damage ability
   - `evolve()` boosts ability potency
   - `decide()` uses ability when ready, ranged attacks otherwise

2. Run 200-match balance sim with full bot pool (all archetypes + equipment + abilities)

3. Balance regression test

# Acceptance Criteria

- [ ] Mage bot uses power_up, evolve, and use_ability
- [ ] 200-match sim shows balanced results
- [ ] No bot > 60% win rate
