# Objective

Update kill feed formatters for new combat event types: crit indicator on hits, attack_miss formatter, ranged_attack_miss formatter.

# Implementation Plan

1. Update `_fmt_hit` — if event has `is_crit=True`, show "CRIT!" indicator
2. Add `_fmt_attack_miss` — "R5: A → B miss" (target existed but roll failed)
3. Add `_fmt_ranged_attack_miss` — same for ranged
4. Register in _FORMATTERS dict
5. Keep existing `_fmt_miss` and `_fmt_ranged_miss` for no-target misses

# Acceptance Criteria

- [ ] Crit hits show "CRIT!" in feed
- [ ] attack_miss events formatted and displayed
- [ ] ranged_attack_miss events formatted
- [ ] Existing miss/ranged_miss formatters unchanged
- [ ] Tests pass, ruff clean
