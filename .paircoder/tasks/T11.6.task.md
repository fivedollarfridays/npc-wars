# Objective

Diminish bounty rewards when multiple humans are present in co-op mode. Prevents bots from snowballing off multiple human kills. Scaling is automatic based on the number of human players in the match.

# Implementation Plan

1. **Add tests to `tests/test_bounty.py`** for scaling:
   - 1 human: full HP restore + full energy restore + 3 rounds +50% damage
   - 2 humans: full HP restore + full energy restore + 2 rounds +50% damage
   - 3 humans: full energy restore only + 1 round +50% damage (no HP restore)
   - 4 humans: full energy restore only + 1 round +50% damage (no HP restore)
   - Scaling is automatic -- no manual configuration needed

2. **Update `engine/bounty.py`**:
   - Modify `place_bounties(bots, humans)` to accept the full humans list and scale rewards
   - Add `BOUNTY_SCALING` constant:
     ```python
     BOUNTY_SCALING = {
         1: {"hp_restore": "full", "energy_restore": "full", "bonus_rounds": 3},
         2: {"hp_restore": "full", "energy_restore": "full", "bonus_rounds": 2},
         3: {"hp_restore": "none", "energy_restore": "full", "bonus_rounds": 1},
         4: {"hp_restore": "none", "energy_restore": "full", "bonus_rounds": 1},
     }
     ```
   - For `len(humans) >= 4`, use the same scaling as 4
   - Update `BountyInfo` to reflect scaled reward values
   - Update `apply_bounty_reward` to respect `hp_restore: "none"` (skip HP restore)

3. **Ensure backward compatibility**:
   - Single-human matches behave identically to T11.5 (no regression)
   - The `claim_bounty` function uses the reward values from the bounty itself (already scaled at placement time)
