# Objective

Create `engine/momentum.py` — a tier system that converts accumulated score into real gameplay advantages. Momentum carries over between matches for winners.

# Momentum Tiers

| Tier | Threshold | Name | Advantages |
|------|-----------|------|------------|
| 0 | 0-9 | — | None |
| 1 | 10-24 | Momentum | +5 energy regen per round |
| 2 | 25-39 | Battle Fury | +10% damage dealt |
| 3 | 40-59 | Crowd Favorite | Visible aura on grid |
| 4 | 60+ | Unstoppable | -15% incoming damage |

Advantages are cumulative. Winner carries over 50% of final score (capped at 50) to next match.

# Implementation Plan

1. Create `engine/momentum.py` with tier definitions and `apply_momentum_bonuses()`
2. Hook into round resolution after scoring
3. Add `momentum_tier` and `carryover_score` to Bot class
4. Add to state dict: `state["me"]["momentum_tier"]`, `state["enemies"][i]["momentum_tier"]`
5. Tests in `tests/test_momentum.py`

# Acceptance Criteria

- [ ] 5 momentum tiers with correct thresholds
- [ ] Tier bonuses apply to actual combat calculations
- [ ] Winner carryover: 50% capped at 50
