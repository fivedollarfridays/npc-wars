# Objective

Add Discord bot commands for community engagement features: Bot of the Week selection, bounty challenge creation, and Watcher lifetime stats display. Bot of the Week auto-selects the most creative decide() function (most unique actions used, best win rate among small bots). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 11 (Community Hooks).

# Implementation Plan

1. **Create `tests/test_community_commands.py`** with tests for:
   - `/bot_of_week` command returns a bot with name, emoji, author, and reason for selection
   - Bot of Week selection criteria: most unique action types used + best win rate among bots with <=75 line budget
   - `/bounty_challenge` command creates a challenge with target bot name and reward description
   - `/bounty_challenge` requires admin permissions
   - `/watcher_stats` command returns The Watcher's lifetime stats (matches, kills, deaths, win rate, current streak)
   - All commands return proper Discord embed format

2. **Create `discord_bot/commands/community.py`**:
   - `bot_of_week(interaction)` slash command:
     - Query leaderboard for bots with line_budget <= 75
     - Score by: unique_actions_used * 2 + win_rate * 10
     - Return embed with bot name, emoji, author, line count, win rate, and "why it's cool" summary
   - `bounty_challenge(interaction, target_bot: str, description: str)` slash command:
     - Requires admin role
     - Creates challenge entry (stored in `data/bounty_challenges.json`)
     - Returns confirmation embed with target and description
   - `watcher_stats(interaction)` slash command:
     - Load WatcherStats from persistence
     - Return embed with: matches, kills (human/bot), deaths, win rate, current streak, most-studied player

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] /bot_of_week shows this week's featured bot
- [ ] /bounty_challenge creates a challenge with target and description
- [ ] /watcher_stats shows Watcher lifetime stats
- [ ] All commands have appropriate permissions
