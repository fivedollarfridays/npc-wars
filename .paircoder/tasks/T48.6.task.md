# Objective

Integration gate validating the complete browser player flow works end-to-end.

# Implementation Plan

1. Create `tests/test_s48_integration.py`:

   **TestBrowserFlow**
   - `GET /` returns 200, contains links to editor + tournaments + leaderboard
   - `GET /static/editor.html` returns 200, contains lobby polling JS
   - `GET /api/lobby/status` returns correct shape with player_list
   - `GET /viewer` returns 200
   - `GET /api/match/{id}` returns match JSON for known match

   **TestLobbyToMatch**
   - Submit bot via `POST /api/submit-bot` → join lobby
   - Poll lobby status → see player in list
   - Force trigger (fill lobby or wait timer)
   - Verify match_id appears in lobby status
   - Fetch match via `GET /api/match/{match_id}` → valid JSON

   **TestNavigation**
   - All links in index.html resolve to real routes (no 404s)
   - Editor viewer redirect format matches actual viewer route
   - Viewer page loads all required JS files

2. Run full test suite + ruff check
3. Verify no regressions in existing tests

# Acceptance Criteria

- [x] Complete flow: landing → editor → lobby → viewer works
- [x] Lobby status transitions correctly through states
- [x] Match accessible via viewer after lobby trigger
- [x] No broken links between pages
- [x] All tests pass, ruff clean
- [x] No regressions
