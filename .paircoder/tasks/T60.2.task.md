# Code Circuit personality profiler

Build Code Circuit `engine/personality.py` with game-specific traits: "conservative tire manager", "late braker", "rain specialist", "one-stop hero", "aggressive defender", "slipstream hunter". Derive from pit strategy patterns, tire wear rates, weather performance, overtake/defend ratios, and qualifying vs race pace delta.
