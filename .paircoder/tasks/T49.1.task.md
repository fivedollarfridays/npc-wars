# Objective

Close the two CRITICAL sandbox escape vectors: dangerous builtins in exec namespace and missing getattr/vars in AST scanner blocked calls.

# Implementation Plan

1. Harden `server/docker_sandbox.py` (lines 46-57):
   - Remove `__import__` from `_safe_builtins`
   - Remove `getattr` and `setattr` from `_safe_builtins`
   - Remove `type`, `object`, `property`, `staticmethod`, `classmethod` (dunder traversal aids)
   - Keep only genuinely safe builtins: `len`, `range`, `int`, `float`, `str`, `bool`, `list`, `dict`, `tuple`, `set`, `frozenset`, `sorted`, `reversed`, `enumerate`, `zip`, `map`, `filter`, `min`, `max`, `sum`, `abs`, `round`, `any`, `all`, `isinstance`, `issubclass`, `hasattr`, `hash`, `id`, `repr`, `print`, `True`, `False`, `None`

2. Harden `engine/bot_scanner.py` (line 27):
   - Add to `BLOCKED_CALLS`: `getattr`, `setattr`, `delattr`, `vars`, `locals`, `globals`, `dir`, `__build_class__`
   - Add to `_BLOCKED_ATTR_CALLS`: `__init__`, `__call__`, `__getattr__`, `__setattr__`

3. Tests in `tests/test_s49_sandbox.py`:
   - Test that `__import__("os")` is blocked in sandbox exec
   - Test that `getattr((), '__class__')` is blocked by scanner
   - Test that `vars()` is blocked by scanner
   - Test that legitimate builtins (`len`, `range`, `min`, `max`) still work
   - Test that existing example bots still pass validation

# Acceptance Criteria

- [ ] `__import__` removed from sandbox builtins
- [ ] `getattr`/`setattr` removed from sandbox builtins
- [ ] `getattr`, `vars`, `locals`, `globals` added to BLOCKED_CALLS
- [ ] All example bots still pass validation
- [ ] Sandbox escape attempts are blocked (test proves it)
- [ ] Tests pass, ruff clean
