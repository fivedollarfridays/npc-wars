# Objective

Validate the viewer overhaul end-to-end. Run matches on different maps, load in viewer, verify all features render.

# Implementation Plan

1. Generate test match JSONs:
   - Match on Fortress map (walls + corridors)
   - Match on Highlands map (high ground + water)
   - Match with trap-using bot (trap_placed + trap_trigger events)
   - Match with ability-using bot (ability_damage events)

2. Manual validation checklist:
   - [ ] Open viewer in browser
   - [ ] Load Fortress match → walls render as dark blocks
   - [ ] Load Highlands match → water blue, high ground gold
   - [ ] Bots render as colored shapes (not emoji)
   - [ ] Different archetypes show different shapes
   - [ ] HP changes affect bot color brightness
   - [ ] Trap events show marker + explosion
   - [ ] Ability events show projectile/glow
   - [ ] Roster shows archetype and equipment
   - [ ] Playback controls work (play/pause, speed, scrub)
   - [ ] Mobile layout is usable (test in dev tools responsive mode)
   - [ ] Old match JSONs (without terrain/archetype) still load and play

3. Create `tests/test_viewer_data.py`:
   - Match JSON has terrain_tiles field
   - Match JSON has archetype in stats
   - Match JSON has map field
   - All event types have required fields for viewer rendering

# Acceptance Criteria

- [ ] All terrain types render correctly on canvas
- [ ] Bots render as geometric shapes with archetype colors
- [ ] New event types visualized (traps, abilities, tactical)
- [ ] Roster updated with archetype + equipment info
- [ ] Old match JSONs backward compatible
- [ ] Mobile-responsive layout works
