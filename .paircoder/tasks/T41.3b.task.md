# Objective

Split the monolithic viewer/match.html (2952 lines, 64 functions) into a modular JS structure. Pure refactor — zero behavior changes.

# Target Structure

```
viewer/
  index.html              # HTML skeleton + CSS + script imports
  js/
    app.js                 # Init, data loading, playback loop
    renderer.js            # Canvas: terrain, grid, bot shapes
    effects.js             # Particles, spectacle, screen shake
    events.js              # Event FX rendering (hits, traps, abilities)
    audio.js               # AudioEngine class
    sidebar.js             # Roster, kill feed, match info
    controls.js            # Playback controls, zoom, speed
    live.js                # WebSocket live play mode
    shapes.js              # Bot shape drawing helper functions
```

# Implementation Plan

1. Create viewer/js/ directory
2. Extract each logical section into its own file
3. Use ES modules (import/export) or simple script tag ordering
4. index.html loads all JS files via script tags
5. Shared state (matchData, canvas, ctx) passed via global or module pattern
6. All existing functionality preserved — pure refactor

# Acceptance Criteria

- [ ] No single JS file > 400 lines
- [ ] All existing viewer features work (terrain, shapes, effects, live play)
- [ ] index.html is mostly HTML/CSS, minimal inline JS
- [ ] Old match JSONs still load and play
