# Objective

Create tournament API endpoints and an automated runner that executes bracket matches.

# Implementation Plan

1. Create `server/routes/tournament.py`:
   - POST /api/tournament/create — create tournament (name, size, optional map)
   - POST /api/tournament/{id}/join — join with bot_id (requires auth)
   - GET /api/tournament/{id} — tournament status + bracket
   - GET /api/tournament/{id}/results — final results
   - GET /api/tournaments — list active/recent tournaments

2. Tournament storage in SQLite (`server/db.py`):
   - `tournaments` table: id, name, size, status (open/running/complete), bracket_json, created_at, winner
   - CRUD functions

3. Automated runner (`server/tournament_runner.py`):
   - `run_tournament_round(tournament_id)`:
     - Get pending matches for current round
     - Build bot configs from stored bot sources
     - Run each match via `run_match()`
     - Record results, advance bracket
     - If tournament complete, set winner
   - Can be triggered by API call or background task

4. Wire into Discord: announce tournament results (use existing announce.py)

5. Tests in `tests/test_tournament_api.py`

# Acceptance Criteria

- [ ] Create tournament via API
- [ ] Players join with their bots
- [ ] Tournament runs matches and advances bracket
- [ ] Results accessible via API
- [ ] Tournament completion detected
