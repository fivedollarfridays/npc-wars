# Objective

Create `npcwars/config.py` that reads/writes `npcwars.toml` config files using stdlib `tomllib`.

# Implementation Plan

1. Create `npcwars/config.py` with:
   - `default_config() -> dict` — returns `{"bots_dir": "bots", "replays_dir": "replays", "seed": None}`
   - `load_config(path: Path) -> dict` — reads TOML file, merges with defaults
   - `write_default_config(path: Path)` — writes a default TOML template string with comments
2. Config keys: `bots_dir` (str), `replays_dir` (str), `seed` (int | None)
3. Use `tomllib` (stdlib, Python 3.11+) for reading
4. For writing, hand-build the TOML string (no toml writer in stdlib)

# Acceptance Criteria

- [ ] `default_config()` returns dict with expected keys
- [ ] `load_config()` reads valid TOML and merges with defaults
- [ ] `load_config()` on missing file returns defaults (no error)
- [ ] `write_default_config()` writes parseable TOML
- [ ] Round-trip: write then load returns defaults
- [ ] 8+ tests in `tests/test_npcwars_config.py`
- [ ] Tests pass, ruff clean
