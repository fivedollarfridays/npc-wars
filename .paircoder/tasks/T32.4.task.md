# Objective

Wire XP calculation and profile updates into the match runner. After a match ends, calculate XP for each bot, update profiles in SQLite, and emit XP data in match result JSON.

# Implementation Plan

1. In `run_match.py` (or `engine/game.py` post-match hook): after match completes, call `calculate_match_xp(result)`
2. For each bot: call `update_profile(conn, bot_name, xp_earned, kills, won)`
3. Check for level-ups: compare level before/after update
4. Add `xp_awards` field to match result JSON:
   ```json
   "xp_awards": {
     "BotName": {
       "base": 10, "kills": 30, "survival": 40,
       "placement": 50, "bonuses": 20, "total": 150,
       "new_level": 3, "leveled_up": true
     }
   }
   ```
5. Profile DB connection: open at start of `run_match`, close after XP update
6. Opt-out flag: `--no-xp` CLI flag to skip XP tracking (for testing/casual)
7. Tests in `tests/test_xp_integration.py`

# Acceptance Criteria

- [ ] Match runner calculates and persists XP after every match
- [ ] Match result JSON includes `xp_awards` field
- [ ] Level-up detection works (compares before/after)
- [ ] `--no-xp` flag skips XP tracking
- [ ] Profile DB is created automatically on first match
- [ ] Tests pass, ruff clean, < 400 lines per file
