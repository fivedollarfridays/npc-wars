# Objective

Create a Docker Compose production configuration for deploying NPC Wars with all required services on the Mac Mini M4.

# Implementation Plan

1. Create `docker-compose.yml` with three services: `app` (FastAPI), `redis`, and `worker`
2. Configure the `app` service to build from the project Dockerfile, expose the API port, and depend on `redis`
3. Configure the `redis` service using the official Redis image with persistence enabled
4. Configure the `worker` service for background match execution, sharing the same image as `app`
5. Add environment variable configuration for all services (database path, Redis URL, API keys)
6. Add volume mounts for the `data/` directory to persist match results and database
7. Add health checks on all three services (HTTP for app, `redis-cli ping` for Redis, process check for worker)
8. Create/update `server/config.py` to read configuration from environment variables with sensible defaults
9. Write a deploy guide section for Mac Mini M4 setup

# Acceptance Criteria

- [x] `docker-compose.yml` defines three services: FastAPI app, Redis, and worker
- [x] All services are configured via environment variables
- [x] Volume mounts persist the `data/` directory
- [x] Health checks are defined for all three services
- [x] `server/config.py` reads configuration from environment variables with defaults
- [x] Deploy guide covers Mac Mini M4 setup steps
