# Objective

Add `agentgrounds wars tournament` CLI command that runs evolutionary tournaments from the terminal.

> **AW2 context:** This is the local tournament command. AW2 Sprint 7 adds `--ranked` flag for online matchmaking. The infrastructure built here carries forward unchanged.

# Implementation Plan

1. Create `agentgrounds/wars/cli/cmd_tournament.py` with `register()` and `run()`
2. Arguments:
   - `--generations N` (default 5)
   - `--matches-per-gen N` (default 10)
   - `--population N` (default 8)
   - `--bots-dir DIR` (default "bots")
   - `--output-dir DIR` (default "data/tournament")
   - `--seed N` (optional, for reproducibility)
3. Output per generation:
   ```
   ═══ Generation 1/5 ═══
   Running 10 matches...
   Rankings:
     1. 💀 Reaper     W:7 L:3 WR:70% Score:0.82
     2. 🌟 Starter    W:5 L:5 WR:50% Score:0.61
     3. 🤖 AggroBot   W:3 L:7 WR:30% Score:0.45
   Survivors: 💀, 🌟
   Mutants: 💀→🔮 (energy threshold 30→24), 🌟→⚡ (chase range 4→5)
   ```
4. Final output: best bot file path, overall stats
5. Register in CLI dispatcher

# Acceptance Criteria

- [ ] `agentgrounds wars tournament` runs a multi-generation tournament
- [ ] Per-generation output shows rankings and mutations
- [ ] Final output shows best bot and path
- [ ] All flags work: generations, matches, population, seed
- [ ] Registered in CLI dispatcher
