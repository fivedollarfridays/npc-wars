# Objective

Create the `GET /api/match/{match_id}` endpoint that returns match result JSON from the results directory, including diff data.

# Implementation Plan

1. Create `server/routes/match.py` with the match retrieval route
2. Accept `match_id` as a path parameter
3. Look up `results/{match_id}.json` on disk
4. If found, return the full match JSON (including diff data) with 200
5. If not found, return 404 with `{"detail": "Match not found"}`
6. Register router on the main FastAPI app

# Acceptance Criteria

- [x] `GET /api/match/{match_id}` endpoint exists in `server/routes/match.py`
- [x] Returns full match JSON with 200 when match exists
- [x] Response includes diff data from the match result
- [x] Returns 404 with `{"detail": "Match not found"}` for missing matches
- [x] Router registered on the main FastAPI app
