# Objective

Wire map selection into the match runner. Expose terrain in state dict. Update PROMPT.md with terrain documentation.

# Implementation Plan

1. Update `run_match()` and `run_match_async()` in game.py:
   - Accept `map_name: str = "arena"` parameter (or random)
   - Build TerrainMap at match start
   - Pass terrain through all functions that need it
   - Store in match data for viewer

2. Update `to_self_dict()`:
   - Add `"on_terrain"`: tile type bot is standing on
   - Add `"terrain"`: dict with map name, walls, water, high_ground, cover, crystals as coord lists

3. Update `to_enemy_dict()`:
   - Add `"on_terrain"`: tile type enemy is on (visible info)

4. Update spawn_positions to avoid walls

5. Update match_writer to include terrain data in match JSON

6. Update PROMPT.md:
   - Document 5 maps with layouts
   - Document terrain effects on combat
   - Document state dict terrain fields
   - Strategy tips for terrain usage

7. Update dict key tests

# Acceptance Criteria

- [ ] Map selected at match start (default arena)
- [ ] state["me"]["on_terrain"] shows current tile type
- [ ] state["terrain"] has map info and tile positions
- [ ] Spawn avoids walls
- [ ] Match JSON includes terrain data
- [ ] PROMPT.md documents terrain system
- [ ] Tests pass, ruff clean
