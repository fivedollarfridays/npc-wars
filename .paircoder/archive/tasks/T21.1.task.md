# Objective

Create `data/bot_memory.py` — a persistence module for per-bot memory dicts, following the same patterns as `engine/watcher_memory.py` and `data/player_profiles.py`.

# Implementation Plan

1. Create `data/bot_memory.py` with:
   - `DEFAULT_MEMORY_DIR = "data/bot_memory"`
   - `MAX_MEMORY_BYTES = 10240` (10KB per bot)
   - `load_bot_memory(emoji: str, memory_dir: str = DEFAULT_MEMORY_DIR) -> dict` — loads `{memory_dir}/{emoji_hash}.json`, returns `{}` if missing
   - `save_bot_memory(emoji: str, memory: dict, memory_dir: str = DEFAULT_MEMORY_DIR) -> None` — serializes to JSON, enforces size limit, creates parent dirs
   - `clear_all_memory(memory_dir: str = DEFAULT_MEMORY_DIR) -> int` — deletes all memory files, returns count deleted
   - `load_all_memories(memory_dir: str = DEFAULT_MEMORY_DIR) -> dict[str, dict]` — loads all bot memories keyed by emoji
2. Use a hash of the emoji for filenames (emoji chars aren't filesystem-safe)
3. Size limit: if serialized JSON > MAX_MEMORY_BYTES, truncate oldest keys or raise ValueError
4. Create `data/bot_memory/.gitkeep`

# Acceptance Criteria

- [x] `load_bot_memory` returns empty dict for missing files
- [x] `save_bot_memory` creates parent dirs and writes JSON
- [x] Size limit enforced — ValueError if memory exceeds 10KB
- [x] `clear_all_memory` deletes all `.json` files in memory dir
- [x] Emoji-based filenames are filesystem-safe (hashed)
- [x] Tests pass in `tests/test_bot_memory.py`
