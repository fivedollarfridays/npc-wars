# Objective

Create The Watcher as a special bot entity with the 🍆 emoji and full action access. The Watcher is a persistent, community-wide nemesis bot that is not authored by any player. It exists across all matches, learning from every human encounter. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7.

# Implementation Plan

1. **Create `tests/test_watcher.py`** with tests for:
   - `WatcherBot` has `emoji` attribute equal to `"🍆"`
   - `WatcherBot` has `name` attribute equal to `"The Watcher"`
   - `WatcherBot` has all 7 actions unlocked: `move`, `attack`, `rest`, `defend`, `ranged_attack`, `dash`, `taunt`
   - `WatcherBot.is_watcher` returns `True`
   - `WatcherBot` is not counted as a regular player bot (has `is_player_bot` == `False`)

2. **Create `engine/watcher.py`**:
   - Constants: `WATCHER_EMOJI = "🍆"`, `WATCHER_NAME = "The Watcher"`
   - `WATCHER_ACTIONS = ["move", "attack", "rest", "defend", "ranged_attack", "dash", "taunt"]`
   - `WatcherBot` class extending or wrapping `Bot` with:
     - `emoji = WATCHER_EMOJI`
     - `name = WATCHER_NAME`
     - `is_watcher = True`
     - `is_player_bot = False`
     - `unlocked_actions = WATCHER_ACTIONS`
   - `decide(state)` method that delegates to the pattern engine (placeholder returning `("rest",)` until T12.4 wires up the brain)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Watcher emoji is 🍆
- [ ] Watcher name is "The Watcher"
- [ ] All actions unlocked (move, attack, rest, defend, ranged_attack, dash, taunt)
- [ ] Watcher does NOT count as a regular player bot
