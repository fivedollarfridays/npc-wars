# Objective

Create `engine/traps.py` — the trap action system. Bots at level 12+ can place traps on tiles. Traps are invisible zones that trigger when an enemy steps on them.

# Design Decisions

- **Energy cost:** 15 (same as dash)
- **Trap damage:** 20 base, scaled by POWER stat (+0.5 per POWER point above 25)
- **Max active traps:** Unlimited (gated by cooldown and energy cost)
- **Trap visibility:** Hidden from enemies until triggered. Visible to the placing bot in state dict.
- **Trap lifetime:** 10 rounds or until triggered, whichever comes first
- **Cooldown:** 3 rounds between trap placements

# Implementation Plan

1. Create `engine/traps.py` with:
   - `Trap` dataclass: `owner_emoji`, `x`, `y`, `damage`, `placed_round`, `expires_round`
   - `TrapManager` class:
     - `place_trap(bot, x, y, round_num) -> Trap | None` — validates placement (in bounds, not on own tile, cooldown check), creates trap
     - `get_traps_for(emoji) -> list[Trap]` — bot's own active traps
     - `check_triggers(bot, round_num) -> list[dict]` — check if bot stepped on enemy traps, return trigger events
     - `expire_traps(round_num) -> list[Trap]` — remove expired traps
     - `remove_dead_bot_traps(emoji)` — cleanup when bot dies
2. Add "trap" to `ACTION_COSTS` in `engine/combat.py` (cost: 15)
3. Add `trap_cooldown: int` field to Bot (tracks rounds until next trap allowed)
4. Parse trap action in `resolve_decisions()`: `("trap", direction)` or `("trap", x, y)`
5. Trap placement happens during the action phase (after movement, before attacks)

# Acceptance Criteria

- [ ] Bots can place traps with `("trap", "north")` or similar direction syntax
- [ ] Trap costs 15 energy
- [ ] Unlimited active traps (gated by cooldown + energy)
- [ ] 3-round cooldown between placements
- [ ] Traps expire after 10 rounds
- [ ] Trap damage = 20 + 0.5 * max(0, POWER - 25)
- [ ] Dead bot traps are cleaned up
- [ ] Tests pass, ruff clean, < 400 lines
