# Objective

Create an in-browser code editor page using Monaco Editor that lets players write bot code, submit it to the server, see validation errors inline, and join the match lobby.

# Implementation Plan

1. Create `server/static/editor.html` as a single-page editor interface
2. Load Monaco Editor from CDN (jsdelivr or cdnjs)
3. Pre-load a bot template in the editor (starter code with `decide()` function skeleton)
4. Add a Submit button that POSTs source code to `POST /api/submit-bot`
5. Display scan errors inline in the editor (red markers/annotations) on 400 response
6. Show lobby countdown timer synced with server lobby state
7. On successful match completion, show a link to the match viewer page
8. Mount `server/static/` as a static files directory in the FastAPI app

# Acceptance Criteria

- [x] `server/static/editor.html` exists with Monaco Editor loaded from CDN
- [x] Bot template with `decide()` skeleton is pre-loaded in the editor
- [x] Submit button calls `POST /api/submit-bot` with editor contents
- [x] Scan errors from 400 response are displayed inline in the editor
- [x] Lobby countdown timer is visible and updates
- [x] Link to match viewer is shown when match result is ready
- [x] Static files directory mounted in the FastAPI app
