# Objective

Implement four remaining spectacle effects: skull_flash, pulse_wave, multiball, and split_screen to complete the viewer's visual effects system.

# Implementation Plan

1. **skull_flash**: Create `skullFlashEffect()` -- white flash overlay (opacity 0.8 -> 0, 0.3s) with a skull emoji overlay centered on screen that fades in/out
2. **pulse_wave**: Create `pulseWaveEffect(x, y)` -- render 3 concentric expanding rings (canvas or CSS) radiating from Watcher position, each ring fading as it expands (0.6s)
3. **multiball**: Create `multiballEffect(positions)` -- on chain-bump events, spawn bouncing particle trails from each bump position with physics-based trajectories (0.8s)
4. **split_screen**: Create `splitScreenEffect(player1, player2)` -- when final 2 players remain, split viewport into two panels tracking each player with a divider line
5. Wire each effect to its corresponding event type in the match playback logic
6. Ensure all effects clean up properly after their duration

# Acceptance Criteria

- [ ] skull_flash: white flash overlay plus skull emoji overlay on trigger
- [ ] pulse_wave: concentric rings radiate outward from the Watcher position
- [ ] multiball: bouncing particle trails appear on chain-bump events
- [ ] split_screen: viewport splits to track the final 2 players simultaneously
- [ ] All four effects clean up after completion (no lingering artifacts)
- [ ] Effects do not interfere with each other when triggered in sequence
