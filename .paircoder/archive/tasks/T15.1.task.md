# Objective

Fix broken audio stinger paths in viewer/match.html so that sound effects play correctly during match playback.

# Implementation Plan

1. Open `viewer/match.html` and search for audio path references (e.g. `audio/assets/`)
2. Change stinger path from `audio/assets/${name}.wav` to `../audio/assets/${name}.wav` to fix the relative path from the viewer directory
3. Verify all stinger trigger points (hit, kill, bump, etc.) reference the corrected path
4. Confirm volume controls still function with the updated paths

# Acceptance Criteria

- [x] Stinger path changed from `audio/assets/${name}.wav` to `../audio/assets/${name}.wav`
- [x] Stingers play on hit, kill, bump, and other mapped events
- [x] Volume controls work correctly with the updated paths

# Verification

```bash
# Search for old broken path (should return no results)
grep -n 'audio/assets/' viewer/match.html | grep -v '\.\./audio/assets/'

# Confirm corrected path exists
grep -n '\.\./audio/assets/' viewer/match.html
```
