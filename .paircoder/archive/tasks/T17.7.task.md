# Objective

Create adaptive AI fill bots that use the Cringe brain's accuracy cap system to generate bot configs calibrated to the skill level of human players in the lobby.

# Implementation Plan

1. Create `server/fill_bots.py` with `generate_fill_bot(skill_level)` function
2. Call `engine.watcher_brain.get_accuracy_cap()` with calibrated thresholds to set bot difficulty
3. Ensure generated bot plays within +/-20% of the provided player average skill level
4. Assign each fill bot a distinct emoji from a dedicated AI-only emoji pool (separate from human player emojis)
5. Return a complete bot config dict compatible with `run_match()` input format
6. Support generating multiple fill bots at once for lobby filling

# Acceptance Criteria

- [x] `generate_fill_bot(skill_level)` returns a valid bot config dict
- [x] Uses `engine.watcher_brain.get_accuracy_cap()` for difficulty calibration
- [x] Generated bot skill is within +/-20% of the target skill_level
- [x] Fill bots use a distinct emoji pool separate from human player emojis
- [x] Bot config is compatible with `run_match()` input format
- [x] Can generate multiple distinct fill bots for a single lobby
