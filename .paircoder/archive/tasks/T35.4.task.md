# Objective

Expose equipment in the state dict so bots can see their loadout and bonuses. Update PROMPT.md with full equipment documentation.

# Implementation Plan

1. Update `to_self_dict()` in `engine/combat.py`:
   - Add `"equipment"` dict: weapon, armor, accessories, tactical names
   - Add `"equipment_bonuses"` dict: to_hit, damage, dr, max_hp, etc.

2. Update `to_enemy_dict()`:
   - Add `"weapon"` — enemy's weapon name (visible, like D&D — you can see their sword)
   - Add `"armor"` — enemy's armor name (visible)
   - Do NOT expose accessories or tactical (hidden advantage)

3. Update `tests/test_combat_serialization.py` with new keys

4. Update PROMPT.md:
   - Full equipment catalog table
   - BOT_EQUIPMENT example in bot file format
   - Equipment budget explanation (40 credits)
   - Archetype examples (Bruiser, Assassin, Tank, Mage loadouts)
   - Strategy tips for equipment choices

5. Tests for state dict fields

# Acceptance Criteria

- [ ] state["me"]["equipment"] shows full loadout
- [ ] state["me"]["equipment_bonuses"] shows computed bonuses
- [ ] state["enemies"][i]["weapon"] and ["armor"] visible
- [ ] Accessories and tactical hidden from enemies
- [ ] PROMPT.md documents full equipment system
- [ ] Dict key tests updated
- [ ] Tests pass, ruff clean
