# Objective

Wire the tactical equipment slot into the combat loop. Tactical items are activated abilities with cooldowns — Battle Cry (+50% damage), Fortify (+6 DR), Teleport (3-tile move), Overdrive (passive +2 damage).

# Implementation Plan

1. Create `engine/tactical.py`:
   - `resolve_tactical_activation(bot, round_num) -> list[dict]` — check cooldown, deduct energy, apply effect, generate events
   - `tick_tactical_cooldowns(bots)` — decrement cooldowns each round
   - `TACTICAL_EFFECTS` dict mapping tactical name to effect function
   - Handle each type: battle_cry (damage mult 1 round), fortify (temp DR + HP), teleport (position change), overdrive (passive, no activation)

2. Add to `Bot` class:
   - `tactical_cooldown: int = 0`
   - `tactical_active_effect: dict | None = None`

3. Add `"use_tactical"` to valid actions (level 18+ unlock)

4. Wire into game loop:
   - Parse `("use_tactical",)` action in resolve_decisions
   - Call `resolve_tactical_activation()` during action phase
   - Call `tick_tactical_cooldowns()` at end of each round
   - Apply active effects during damage calc

5. Tests in `tests/test_tactical.py`

# Acceptance Criteria

- [ ] use_tactical action activates equipped tactical item
- [ ] Cooldown prevents re-activation
- [ ] Energy cost deducted
- [ ] Battle Cry applies +50% damage for 1 round
- [ ] Fortify grants +6 DR and +10 temp HP for 1 round
- [ ] Teleport moves bot 3 tiles
- [ ] Overdrive passively adds +2 damage and +3 energy cost
- [ ] Tactical events in round data
- [ ] Tests pass, ruff clean, < 400 lines
