# Objective

Create a WebSocket server that accepts human actions from the HTML viewer during live play. The server implements the `HumanInputAdapter` interface and handles the real-time action/state exchange protocol.

# Implementation Plan

1. **Create `tests/test_websocket_server.py`** with tests for:
   - Server starts and accepts a WebSocket connection on configurable port
   - Client sends action JSON `{"action": ["move", "east"]}` and server receives it via `get_action`
   - Client sends `{"action": null}` (pass to bot) and `get_action` returns `None`
   - Timeout: if no message within 2 seconds, `get_action` returns `None`
   - Server sends state dict + round info to client each round
   - Client disconnect is handled gracefully (bot takes over, no crash)

2. **Create `realtime/` package**:
   - `realtime/__init__.py`
   - `realtime/server.py`:
     - `WebSocketInputAdapter(HumanInputAdapter)`:
       - `__init__(host: str = "localhost", port: int = 8765)` -- configurable host/port
       - `async start()` -- starts the WebSocket server, awaits a single client connection
       - `get_action(state: dict, timeout_s: float) -> tuple | None`:
         - Send state dict as JSON to connected client
         - Await client response within `timeout_s`
         - Parse `{"action": ["move", "east"]}` into `("move", "east")` tuple
         - Return `None` on timeout or `{"action": null}`
       - `async stop()` -- gracefully close connection and server
     - Protocol messages:
       - Server -> Client: `{"type": "state", "round": int, "state": dict}`
       - Client -> Server: `{"action": ["move", "east"]}` or `{"action": null}`

3. **Handle edge cases**:
   - Client disconnects mid-match: mark adapter as disconnected, all future `get_action` calls return `None`
   - Invalid JSON from client: log warning, return `None` for that round
   - Multiple connection attempts: reject after first client connects (single-player per adapter)

# Acceptance Criteria

- [ ] WebSocket server starts on configurable port
- [ ] Accepts action JSON from connected client and returns as tuple
- [ ] Returns `None` on timeout (2-second window)
- [ ] Sends state update to client each round
- [ ] Handles disconnect gracefully (bot takes over)
