# Objective

Wire the scoring/ranking and mutation systems into a complete generation lifecycle: evaluate → select → mutate → fill → next generation.

# Implementation Plan

1. Add to `npcwars/tournament.py`:
   - `evolve_generation(gen_result, bot_sources, config, rng) -> list[dict]`:
     1. Rank bots by composite score
     2. Select survivors (top 50%)
     3. For each survivor, create 1 mutant via `create_mutant()`
     4. If population still not full, fill with new wizard-generated bots
     5. Return new bot_configs list for next generation
   - `_generate_filler_bot(gen_num, slot, rng) -> dict`: create a wizard bot to fill empty slots
2. Wire into `run_tournament()`: after each generation, call `evolve_generation()` to produce next gen
3. Track lineage: each mutant bot stores `{"parent": "original_emoji", "generation": N, "mutations": [...]}`
4. Assign unique emojis to mutants from a pool (generation_num + slot → deterministic emoji)
5. Write mutant bot files to `data/tournament/gen_N/` directory

# Acceptance Criteria

- [ ] `evolve_generation` produces a new population from ranked results
- [ ] Top 50% of bots survive, bottom 50% replaced by mutants/fillers
- [ ] #1 bot survives unchanged (elitism)
- [ ] Mutant bots have unique names and emojis
- [ ] Lineage metadata tracked per mutant
- [ ] Filler bots generated for empty slots
- [ ] Tests verify population size is maintained across generations
