# Objective

Add a `npcwars generate` command that helps users create bots using AI. It outputs the PROMPT.md content with optional strategy hints, ready to paste into any AI tool. If an Anthropic API key is set, it calls Claude directly and writes the bot file.

# Implementation Plan

1. Create `npcwars/cli/cmd_generate.py` with `register()` and `run()`
2. `npcwars generate` (no flags): prints the full prompt to stdout for copy-pasting
3. `npcwars generate --strategy "aggressive defender that baits attacks"`: appends the strategy to the prompt
4. `npcwars generate --name "Baiter" --emoji "🪤" --strategy "..."`: includes bot identity in prompt
5. `npcwars generate --auto --name "Baiter" --emoji "🪤" --strategy "..."`: if `ANTHROPIC_API_KEY` env var is set, calls Claude API directly, writes bot file, validates it
6. `--output` flag to specify output file path (default: `bots/{name}.py`)
7. Register in CLI dispatcher

# Acceptance Criteria

- [ ] `npcwars generate` prints the agent prompt to stdout
- [ ] `--strategy` appends custom strategy text to the prompt
- [ ] `--name` and `--emoji` include bot identity in the prompt
- [ ] `--auto` mode calls Claude API when `ANTHROPIC_API_KEY` is set
- [ ] `--auto` mode validates the generated bot before writing
- [ ] Prints clear instructions when API key is not set
- [ ] Registered in CLI dispatcher

# Verification

```bash
# Manual mode
npcwars generate --strategy "energy denial specialist" > /tmp/prompt.txt

# Auto mode (requires API key)
ANTHROPIC_API_KEY=sk-... npcwars generate --auto --name "Denier" --emoji "⚡" --strategy "energy denial"
npcwars validate bots/denier.py
```
