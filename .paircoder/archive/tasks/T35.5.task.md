# Objective

Create example bots with different equipment loadouts and run balance simulation to validate equipment doesn't break the game.

# Implementation Plan

1. Update existing bots with equipment loadouts:
   - `bots/reaper.py` — axe + leather (glass cannon)
   - `bots/example_tank.py` — mace + plate + ring_of_health (full tank)
   - `bots/example_aggro.py` — sword + chain_mail (balanced aggressive)
   - `bots/example_trapper.py` — spear + reinforced (control fighter)

2. Create 1 new equipment-focused bot:
   - `bots/example_knight.py` — mace + plate + ring_of_health + charm_of_evasion
   - High ARMOR stats, equipment stacks defense
   - Demonstrates full 4-item loadout

3. Run 200-match balance sim:
   - Pool: all bots with equipment
   - Track: win rate per bot, damage sources, equipment effectiveness
   - Ensure no archetype > 60% win rate

4. Save results to `tools/equipment_balance_results.json`

5. Balance regression test in `tests/test_s35_regression.py`

# Acceptance Criteria

- [ ] At least 4 existing bots updated with thematic equipment
- [ ] 1 new equipment-focused example bot
- [ ] 200-match sim shows no bot > 60% win rate
- [ ] Balance regression test passes
- [ ] All bots pass security scan
