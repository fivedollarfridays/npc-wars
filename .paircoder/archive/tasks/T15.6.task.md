# Objective

Wire player profile persistence into play.py so that player profiles are saved and loaded between matches via a JSON file.

# Implementation Plan

1. In `play.py`, add `from pathlib import Path` import
2. Add `profiles_path=Path("data/profiles.json")` parameter to the `run_match()` call
3. Ensure the `data/` directory is created if it does not exist (use `profiles_path.parent.mkdir(parents=True, exist_ok=True)`)
4. Write tests that verify: profiles.json is created after a match, profiles persist between matches, profiles_path parameter is passed correctly

# Acceptance Criteria

- [x] play.py passes `profiles_path=Path("data/profiles.json")` to `run_match()`
- [x] Player profiles persist between matches in data/profiles.json
- [x] data/ directory is created automatically if missing
- [x] Tests verify profiles.json is created/updated after a match
