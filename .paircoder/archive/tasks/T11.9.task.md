# Objective

Detect AFK (away-from-keyboard) humans by tracking consecutive missed inputs. Display AFK status in the viewer and match JSON. After 10 consecutive missed inputs, kick the human from active play and let their bot continue autonomously.

# Implementation Plan

1. **Create `tests/test_afk.py`** with tests for:
   - 1-2 consecutive missed inputs: no penalty, no AFK badge, bot plays normally
   - 3+ consecutive missed inputs: AFK badge set to `True` in match data for that player
   - 10+ consecutive missed inputs: human kicked (adapter detached), bot plays permanently
   - Successful input resets the consecutive miss counter to 0
   - AFK badge appears in the round's player data
   - Kicked status persists for the rest of the match

2. **Add AFK tracking to match state**:
   - Per-human tracking dict: `{"player_emoji": str, "consecutive_misses": int, "afk": bool, "kicked": bool}`
   - After each round's human input window: if adapter returned `None`, increment `consecutive_misses`; if adapter returned an action, reset to 0
   - At `consecutive_misses >= 3`: set `afk = True`
   - At `consecutive_misses >= 10`: set `kicked = True`, detach the human adapter from the bot

3. **Embed AFK status in match JSON**:
   - Add `"afk_status"` to each round's player data: `{"emoji": str, "afk": bool, "kicked": bool, "missed_inputs": int}`
   - Only present for human-controlled bots (not pure bots)

4. **Viewer display**:
   - When `afk: true` for a player: render "AFK" badge next to their emoji on the grid
   - When `kicked: true`: show "BOT" badge (indicating bot-only control)
   - Badge styling: small text overlay in red (AFK) or grey (BOT)

# Acceptance Criteria

- [ ] 1-2 missed inputs: no penalty, bot plays normally
- [ ] 3+ missed inputs: AFK badge appears in match data
- [ ] 10+ missed inputs: human kicked, bot takes over permanently
- [ ] AFK badge appears in viewer rendering
