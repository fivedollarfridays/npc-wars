# Objective

Add a `npcwars watch` CLI command that plays back a match JSON file in the terminal, frame by frame, using the ANSI renderer.

# Implementation Plan

1. Create `npcwars/cli/cmd_watch.py` with `register()` and `run()` functions
2. Accept a match JSON file path as argument
3. Load the match data and iterate through rounds
4. Call `TerminalRenderer.render_frame()` for each round with a delay between frames
5. Support speed controls: `--speed 1` (1 round/sec), `--speed 2`, `--speed 4`
6. Support `--no-clear` mode for piping output (no ANSI clear, just prints each frame)
7. Show winner banner at end with final stats
8. Register in `npcwars/cli/__init__.py` dispatcher

# Acceptance Criteria

- [x] `npcwars watch <file.json>` plays back a match in the terminal
- [x] Each round renders as a full ANSI frame with grid, bots, HP bars
- [x] `--speed` flag controls playback speed (default 1)
- [x] Winner banner displays at match end
- [x] `--no-clear` mode works for non-interactive output
- [x] Registered in CLI dispatcher
