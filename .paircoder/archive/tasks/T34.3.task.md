# Objective

Create a trap-using example bot that demonstrates defensive and offensive trap strategies. Uses setup and react callbacks for advanced gameplay.

# Implementation Plan

1. Create `bots/example_trapper.py`:
   - `BOT_NAME = "Trapper"`
   - `BOT_EMOJI = "🕸️"`
   - `BOT_GLYPH = "◇"`
   - `BOT_BIO = "Controls the battlefield with hidden traps"`
   - `BOT_AUTHOR = "NPC Wars"`
   - Stats: POWER-focused for trap damage scaling (e.g., 35/20/25/20)

   Strategy:
   - **setup()**: Note spawn position, plan trap zones
   - **react()**: Track enemy movement patterns, adapt trap placement
   - **decide()**:
     - Place traps on predicted enemy movement paths
     - Prefer trap placement near chokepoints (center, storm edges)
     - If trap on cooldown, attack nearby enemies or defend
     - When low HP, retreat and lay defensive traps
   - Must have `unlocked_actions` including "trap" and appropriate `unlocked_callbacks`

2. Ensure bot passes `scan_bot_source()` security check
3. Ensure bot works in a real match (test via `run_match()`)

# Key Context

- Trap action: `("trap", direction)` where direction is "north", "south", etc.
- Trap costs 15 energy, 3-round cooldown
- `state["me"]["trap_cooldown"]` shows when next trap is available
- `state["me"]["traps"]` shows own active traps
- `state["me"]["callbacks"]` shows active callbacks
- `setup(state)` called once before round 1
- `react(state, events)` called each round with nearby events
