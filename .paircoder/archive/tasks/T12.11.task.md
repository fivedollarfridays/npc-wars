# Objective

Ensure The Watcher bypasses the action unlock gating system so it can use all 7 actions regardless of streak requirements. Regular bots must earn ranged_attack (3-win streak), dash (5-win), and taunt (10-win), but The Watcher has these from the start. Depends on T12.1, T9.8 (action gating). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Full Action Set).

# Implementation Plan

1. **Add tests to `tests/test_watcher.py`** for:
   - Watcher can use `ranged_attack` through sandbox validation (not rejected)
   - Watcher can use `dash` through sandbox validation (not rejected)
   - Watcher can use `taunt` through sandbox validation (not rejected)
   - Other bots without sufficient streak still have actions gated normally
   - Watcher's `unlocked_actions` list contains all 7 actions

2. **Update `engine/sandbox.py` `validate_action()`**:
   - Before checking `unlocked_actions` gating, check if the bot is The Watcher (via `is_watcher` attribute or by checking emoji == `"🍆"`)
   - If Watcher, skip the unlock check entirely -- all actions are valid
   - Regular bots continue to be gated as before (T9.8 logic unchanged)

3. **Verify Watcher's profile always has `WATCHER_ACTIONS`** as its `unlocked_actions` (set in T12.1's `WatcherBot` class)

4. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Watcher can use all 7 actions
- [ ] No streak requirement for Watcher
- [ ] Other bots still gated normally
