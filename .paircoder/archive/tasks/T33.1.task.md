# Objective

Create `engine/callbacks.py` — a callback registry that discovers, validates, and stores callback functions from bot modules. Supports: `setup`, `on_kill`, `react`.

# Background

The level table (levels.py) defines callback unlocks at levels 5 (on_kill), 8 (setup), and 12 (react), but no infrastructure exists to discover or invoke them. Bot modules currently only expose `decide(state)`. This task builds the foundation that T33.2 and T33.3 build on.

# Callback Signatures

| Callback | Unlocked | Signature | Timing |
|----------|----------|-----------|--------|
| `setup` | Level 8 | `setup(state) -> None` | Once at match start, before round 1 |
| `on_kill` | Level 5 | `on_kill(state, victim_emoji) -> None` | After a kill is attributed |
| `react` | Level 12 | `react(state, events) -> None` | After combat, before next decide |

# Implementation Plan

1. Create `engine/callbacks.py` with:
   - `CALLBACK_NAMES = ("setup", "on_kill", "react")` constant
   - `CallbackSet` dataclass: holds optional callables for each callback type
   - `discover_callbacks(module, unlocked_callbacks: set[str]) -> CallbackSet` — introspects a bot module for callback functions, validates signatures, respects level-gated unlock set
   - `execute_callback(callback, *args, timeout=0.1) -> None` — safe executor with timeout and error swallowing (bot bugs shouldn't crash the match)
2. Add `callbacks: CallbackSet` field to `Bot.__init__` in `engine/combat.py`
3. Update `_create_bots()` in `engine/game.py` to call `discover_callbacks()` and attach to bot
4. Update `bot_scanner.py` to allow callback function names (don't flag as dead code)

# Acceptance Criteria

- [ ] `discover_callbacks()` finds setup/on_kill/react from bot modules
- [ ] Callbacks gated by `unlocked_callbacks` set (level check)
- [ ] `execute_callback()` catches exceptions, respects timeout
- [ ] Bot.callbacks field populated during match setup
- [ ] Bots without callbacks get empty CallbackSet (no errors)
- [ ] Tests pass, ruff clean, < 400 lines
