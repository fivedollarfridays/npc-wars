# Objective

Add special spectacle triggers for Watcher actions. The Watcher's spawn, kills, and sync milestones generate unique spectacle events with bonus drama weight. These events drive distinctive visual/audio treatment in the viewer and video renderer. Depends on T12.1, T10.1 (SpectacleEngine). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 3 (Trigger -> Effect Map) and Section 7.

# Implementation Plan

1. **Create `tests/test_watcher_spectacle.py`** with tests for:
   - `watcher_spawn` event generates a spectacle trigger with type `"watcher_spawn"`
   - Watcher kill generates a `"watcher_kill"` spectacle trigger with victim emoji and current sync
   - Sync milestones at 50%, 75%, and 90% generate `"watcher_sync"` spectacle triggers
   - `SpectacleEngine.score_round` gives watcher events bonus weight (watcher_sync_milestone * 3 per the drama formula)
   - Event schemas match: `{"type": "watcher_spawn", "sync": 15}`, `{"type": "watcher_kill", "victim": "🦆", "sync": 73}`

2. **Update `engine/spectacle.py` SpectacleEngine**:
   - Add watcher-specific event types to the trigger detection:
     - `"watcher_spawn"` — detected when a `watcher_spawn` event appears in round events
     - `"watcher_kill"` — detected when a kill event has killer emoji == `"🍆"`
     - `"watcher_sync"` — detected when sync crosses 50%, 75%, or 90% thresholds (milestone events injected by watcher_brain)
   - Watcher events contribute to drama score per existing formula (watcher_sync_milestone * 3)
   - Add watcher triggers to spectacle metadata output in match JSON

3. **Create helper to emit watcher events**:
   - `emit_watcher_spawn_event(sync: float) -> dict` — returns `{"type": "watcher_spawn", "sync": sync}`
   - `emit_watcher_kill_event(victim_emoji: str, sync: float) -> dict` — returns `{"type": "watcher_kill", "victim": victim_emoji, "sync": sync}`
   - `emit_sync_milestone_event(sync: float) -> dict` — returns `{"type": "watcher_sync", "sync": sync}`

4. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] SpectacleEngine scores watcher events with bonus weight
