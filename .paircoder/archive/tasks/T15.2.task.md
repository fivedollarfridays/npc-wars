# Objective

Implement a shatter spectacle effect that triggers on kill events, making the victim tile explode with particle fragments for dramatic visual feedback.

# Implementation Plan

1. Add a canvas overlay element (or reuse existing) for rendering particle effects in `viewer/match.html`
2. Create a `shatterEffect(x, y, color)` function that spawns 8-12 particle fragments radiating outward from the victim tile position
3. Each particle: random velocity vector, decaying opacity, 0.5s total duration
4. Use `requestAnimationFrame` loop for smooth rendering; clean up particles after animation completes
5. Wire the shatter effect to the kill event handler in the match playback logic

# Acceptance Criteria

- [ ] Kill events trigger a shatter spectacle effect on the victim tile
- [ ] Victim tile explodes with particle fragments radiating outward
- [ ] Effect is canvas-rendered with smooth animation
- [ ] Effect duration is approximately 0.5 seconds
- [ ] Particles clean up after animation completes (no memory leak)
