# Objective

Implement a three-layer audio mixing pipeline (ambient + stingers + hype track) for the video renderer. The mixer reads spectacle metadata from match JSON, places stinger audio at correct timestamps, loops ambient audio for the match duration, and scales hype track volume with drama tier. Final output is muxed into the MP4 via ffmpeg.

# Implementation Plan

1. **Create `tests/test_audio_mixer.py`** with tests for:
   - `build_audio_timeline` returns list of `(timestamp_ms, audio_file)` tuples from match data
   - Stingers placed at correct timestamps based on round number and round duration
   - Empty match data produces empty timeline (ambient only)
   - Hype track volume config scales with drama tier

2. **Create `audio/mixer.py`**:
   - `build_audio_timeline(match_data: dict, round_duration_ms: int) -> list[tuple[int, str]]`
     - Iterate rounds, for each event check `STINGER_MAP`, compute timestamp as `round_num * round_duration_ms`
     - Return sorted list of (timestamp_ms, audio_file_path) tuples
   - `build_hype_volume_curve(match_data: dict, round_duration_ms: int) -> list[tuple[int, float]]`
     - Map each round's drama tier to a volume level: calm=0.1, heating=0.3, intense=0.5, hype=0.8, chaos=1.0
     - Return list of (timestamp_ms, volume_float) keyframes

3. **Create `audio/renderer.py`**:
   - `mix_audio(timeline: list, hype_curve: list, duration_ms: int, output_path: str) -> str`
     - Use ffmpeg to layer: ambient track (looped), stingers at timestamps, hype track with volume automation
     - Ambient volume dips during stinger playback (ducking)
     - Output intermediate WAV or directly mux into video

4. **Wire into `video/video_render.py`**:
   - After rendering video frames, call `build_audio_timeline` and `mix_audio`
   - Mux audio into final MP4 using ffmpeg `-i video -i audio -c:v copy -c:a aac`
   - Support `--no-audio` flag to skip audio mixing entirely

# Acceptance Criteria

- [ ] Output MP4 contains an audio stream
- [ ] Stingers trigger at correct round timestamps (round_num * round_duration_ms)
- [ ] Ambient track loops for the full match duration
- [ ] Hype track volume scales with drama tier (calm=quiet, chaos=full)
- [ ] No audio in video output when `--no-audio` flag is passed
