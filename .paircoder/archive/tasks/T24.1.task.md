# Objective

Change TankBot's emoji from 🛡️ to 🐢 to free the shield icon for defend animation indicators. Also add a `defend` event to the engine so the renderer can react to blocking.

# Implementation Plan

1. **Change TankBot emoji**
   - `agentgrounds/wars/builtin_bots/example_tank.py`: `BOT_EMOJI = "🐢"`
   - Update any test fixtures that reference TankBot's emoji

2. **Emit defend event from engine**
   - In `engine/rounds.py` (or wherever actions resolve), emit a `defend` event when a bot's action is "defend":
     ```python
     {"type": "defend", "emoji": bot.emoji}
     ```
   - Emit when the defense bonus is applied, not just when the action is chosen

3. **Update PROMPT.md** if it references TankBot's emoji

4. **Run tests** — all existing tests pass, TankBot references updated

# Acceptance Criteria

- [ ] TankBot uses 🐢 emoji
- [ ] Engine emits `{"type": "defend", "emoji": ...}` events
