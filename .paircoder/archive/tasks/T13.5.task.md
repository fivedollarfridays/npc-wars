# Objective

Implement Gauntlet mode: a solo human survives escalating waves of bots. Waves start at 3 bots and increase (3 -> 5 -> 7 -> 10 -> boss wave with The Watcher). Bot stats scale with wave number (+5 HP and +2 attack per wave). Match ends when the human dies or survives all waves. Streamer bait. Depends on T13.1, T11.4 (async tick). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 10 (Gauntlet).

# Implementation Plan

1. **Create `tests/test_gauntlet.py`** with tests for:
   - Gauntlet mode accepts exactly 1 human
   - Wave 1 starts with 3 bots
   - New wave spawns when all bots from current wave are eliminated
   - Wave progression: 3 -> 5 -> 7 -> 10 -> boss wave
   - Bot stats scale: wave N bots have `base_hp + (N-1) * 5` HP and `base_attack + (N-1) * 2` attack
   - The Watcher spawns at wave 5 (boss wave)
   - Match ends when human dies (loss) or survives all 5 waves (win)
   - Wave transition events emitted: `{"type": "wave_start", "wave": N, "bot_count": M}`
   - Human HP and energy persist between waves (no free heal)

2. **Create `engine/gauntlet.py`**:
   - `WAVE_BOT_COUNTS = [3, 5, 7, 10, 1]` (wave 5 is Watcher only)
   - `WAVE_HP_BONUS = 5`, `WAVE_ATTACK_BONUS = 2`
   - `GauntletManager` class with:
     - `current_wave: int = 1`
     - `spawn_wave(wave_num: int, rng) -> list[Bot]` — creates bots with scaled stats for given wave
     - `check_wave_clear(bots: list) -> bool` — True if all wave bots are eliminated
     - `advance_wave() -> list[Bot] | None` — returns next wave's bots or None if all waves complete
   - Wire into `run_match(mode=MatchMode.GAUNTLET)` with wave management loop

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Exactly 1 human
- [ ] Bots spawn in waves when previous wave eliminated
- [ ] Difficulty increases per wave (more bots, higher stats)
- [ ] Watcher spawns at wave 5
- [ ] Match ends when human dies or survives all waves
