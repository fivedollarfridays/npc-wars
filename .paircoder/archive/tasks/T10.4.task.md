# Objective

Create an `audio/` module with a stinger sound effect library. Define the `STINGER_MAP` dictionary mapping all 13 game event types to audio file paths, and generate or source the corresponding 8-bit WAV stinger assets.

# Implementation Plan

1. **Create `audio/` directory structure**:
   - `audio/__init__.py` -- package init, exports `STINGER_MAP`
   - `audio/stingers.py` -- `STINGER_MAP` constant and asset path helpers
   - `audio/assets/` -- directory for WAV/MP3 stinger files

2. **Define `STINGER_MAP` in `audio/stingers.py`**:
   - Map 13 event types to relative asset paths:
     - `"hit"` -> `"assets/hit.wav"` (cartoon punch, 0.3s)
     - `"critical_hit"` -> `"assets/critical_hit.wav"` (heavy impact, 0.5s)
     - `"kill"` -> `"assets/kill.wav"` (explosion + crowd pop, 0.8s)
     - `"kill_streak"` -> `"assets/kill_streak.wav"` (air horn, 1.0s)
     - `"bump"` -> `"assets/bump.wav"` (pinball bumper ding, 0.2s)
     - `"chain_bump"` -> `"assets/chain_bump.wav"` (cascading dings, 0.5s)
     - `"wall_splat"` -> `"assets/wall_splat.wav"` (thud + crack, 0.4s)
     - `"storm_damage"` -> `"assets/storm_damage.wav"` (electric zap, 0.3s)
     - `"rest_heal"` -> `"assets/rest_heal.wav"` (gentle chime, 0.3s)
     - `"near_death"` -> `"assets/near_death.wav"` (tension sting, 0.5s)
     - `"watcher_spawn"` -> `"assets/watcher_spawn.wav"` (ominous bass chord, 1.5s)
     - `"human_enter"` -> `"assets/human_enter.wav"` (record scratch + gasp, 1.0s)
     - `"match_end"` -> `"assets/match_end.wav"` (victory fanfare, 2.0s)
   - Add `get_stinger_path(event_type: str) -> Path` helper that resolves absolute path

3. **Generate or source audio assets**:
   - Use jsfxr-style synthesis or Python wave module to generate 8-bit retro stingers
   - Alternatively source royalty-free assets from freesound.org or mixkit
   - Ensure cute aesthetic that matches the game's teletubby-meets-gladiator vibe
   - Keep total asset size under 5MB

4. **Add validation test** in `tests/test_audio.py`:
   - `STINGER_MAP` contains exactly 13 entries
   - All mapped file paths exist on disk
   - All files are valid audio (non-zero size)

# Acceptance Criteria

- [ ] `audio/` directory exists with `__init__.py` and `stingers.py`
- [ ] `STINGER_MAP` maps all 13 event types to file paths
- [ ] All referenced audio files exist and are valid WAV or MP3
- [ ] Total audio asset size < 5MB
