# Objective

Add Server-Sent Events (SSE) streaming so the viewer can receive live match updates in real time instead of polling.

# Implementation Plan

1. Create `server/routes/stream.py` with a `GET /api/match/:id/stream` endpoint
2. Implement an async generator that yields each round result as a JSON SSE event (`data: {...}\n\n`)
3. Send `event: round` for each round and `event: complete` with final standings when the match ends
4. Set appropriate SSE headers (`Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`)
5. Add `retry:` field in the SSE stream so clients auto-reconnect on disconnect
6. Register the route in the FastAPI app
7. Write tests covering round emission, stream closure, and reconnect hint

# Acceptance Criteria

- [x] SSE endpoint exists at `GET /api/match/:id/stream`
- [x] Each round is emitted as a JSON SSE event (`event: round`)
- [x] Stream sends `event: complete` when the match ends and then closes
- [x] Client auto-reconnects on disconnect (SSE `retry` field present)
- [x] Tests pass for round streaming, completion event, and reconnect behavior
