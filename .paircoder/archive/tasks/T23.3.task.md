# Objective

Build `agentgrounds wars analyze` — parses batch sim output and generates kill/death/balance heatmaps, survival curves, and energy economy data. The primary validation tool for map and class balance across all future sprints.

# Context

After running `agentgrounds wars sim`, designers need to verify that maps create the intended fight patterns. The analyze command turns raw match JSON into visual heatmaps and stat curves that answer: "is this map/class balanced?"

The spec defines balance targets:
- Mirror match: 45-55% win rate each side
- Cross-class: no matchup exceeds 60/40
- Storm damage: winning agents average <3 rounds in storm
- Match length: 20-28 rounds average

# Implementation Plan

1. **Create `agentgrounds/wars/cli/cmd_analyze.py`**
   - Register `analyze` subcommand in wars `__main__.py`
   - Arguments: `--input DIR` (sim output dir), `--output DIR` (analysis output), `--format ascii|json|both` (default both)

2. **Heatmap generation**
   - Parse all `match_*.json` in input dir
   - Build 10×10 position frequency grids:
     - **Kill heatmap**: which tiles had a kill resolved on them
     - **Death heatmap**: which tiles agents were eliminated on
     - **Balance map**: kill_count - death_count per tile
     - **Survival heatmap by phase**: where top-3 agents spent early/mid/late game
   - Output as JSON: `heatmaps.json` with `kill`, `death`, `balance`, `survival_early`, `survival_mid`, `survival_late` keys
   - Output as ASCII: 10×10 grid with intensity chars (`·`, `░`, `▒`, `▓`, `█`) per cell

3. **Energy economy curves**
   - For each placement tier (1st, 2nd-3rd, 4th-6th, 7th-8th), compute avg energy per round across all matches
   - Output as `energy_curves.json`: `{"placement_1": [120, 108, 95, ...], ...}`

4. **Class balance matrix** (used when sim has multiple classes)
   - Win rate for each bot name pair
   - Flag any matchup exceeding 60/40 with a warning

5. **Summary report**
   - Print balance verdict to stdout: PASS/WARN/FAIL per balance target
   - Example: `[PASS] avg match length: 23.4 rounds (target: 20-28)`
   - Write `analysis_report.json` with all metrics

6. **Tests** in `tests/test_sim_analyze.py`
   - Generate 10 fixture matches, run analyze, verify heatmap dimensions (10×10)
   - Verify energy curves have one entry per round
   - Verify balance report JSON has expected keys
