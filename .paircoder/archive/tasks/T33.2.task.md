# Objective

Wire the `setup` callback into the match loop. Called once per bot at match start (before round 1) for bots at level 8+.

# Background

The `setup(state)` callback lets bots initialize internal counters, pick targets, or configure strategy before combat begins. The callback registry (T33.1) discovers it; this task executes it.

# Implementation Plan

1. Add `_execute_setup_callbacks(bots)` function in `engine/game.py` (or a new `engine/callback_runner.py` if game.py is getting large)
   - For each bot with `callbacks.setup is not None`:
     - Build the same state dict used for `decide()` (via `to_self_dict()`)
     - Call `execute_callback(bot.callbacks.setup, state)`
     - Log any errors but don't crash
2. Call `_execute_setup_callbacks(bots)` in `run_match()` after `_prepare_match()` but before the round loop
3. Also wire into `run_match_async()` via `engine/game_async.py`
4. Add a test bot fixture with a `setup()` function that sets internal state
5. Verify setup is called exactly once, before round 1

# Acceptance Criteria

- [ ] setup() called once per bot before round 1
- [ ] setup() receives valid state dict (same shape as decide())
- [ ] Bot exceptions in setup() are caught and logged, match continues
- [ ] Bots without setup callback are unaffected
- [ ] Tests pass, ruff clean
