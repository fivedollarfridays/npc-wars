# Objective

Implement a dark_entrance spectacle effect for the Watcher spawn event, creating an ominous entrance sequence with screen dimming, purple vignette, and dramatic emoji scaling.

# Implementation Plan

1. Create a `darkEntranceEffect()` function in `viewer/match.html`
2. Phase 1 (0-0.3s): Dim screen to 30% brightness using an overlay div with `background: rgba(0,0,0,0.7)`
3. Phase 2 (0.3-1.0s): Add purple vignette effect via radial gradient overlay (`rgba(128,0,255,0.3)` fading outward)
4. Phase 3 (0.3-1.5s): Animate the Watcher emoji from 3x scale down to 1x using CSS transform with easing
5. Phase 4 (1.2-1.5s): Fade out overlay and vignette, restore normal rendering
6. Wire the dark_entrance effect to watcher_spawn events in the match playback logic

# Acceptance Criteria

- [x] Watcher spawn triggers a dark_entrance spectacle sequence
- [x] Screen dims to approximately 30% brightness during the effect
- [x] Purple vignette overlay appears around the screen edges
- [x] Watcher emoji scales from 3x down to 1x during the entrance
- [x] Full sequence duration is approximately 1.5 seconds
- [x] All overlays clean up after the sequence completes
