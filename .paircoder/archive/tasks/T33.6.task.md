# Objective

Expose trap and callback data in the state dict so bots can make informed decisions. Update PROMPT.md with callback and trap documentation.

# Implementation Plan

1. Update `to_self_dict()` in `engine/combat.py`:
   - Add `"traps": [{"x": t.x, "y": t.y, "expires_in": t.expires_round - current_round} for t in my_traps]`
   - Add `"trap_cooldown": bot.trap_cooldown`
   - Add `"callbacks": ["setup", "react", ...]` (list of active callback names)
2. Update `to_enemy_dict()`:
   - Do NOT expose enemy traps (they're hidden)
   - Add `"has_traps": bool` (whether enemy has any active traps — gives partial info)
3. Add trap trigger events to round events visible to bots
4. Update match_writer.py to include trap data in match JSON
5. Update PROMPT.md:
   - Document trap action syntax and mechanics
   - Document callback system (setup, on_kill, react)
   - Add strategy tips for traps
   - Document new state dict fields

# Acceptance Criteria

- [ ] state["me"]["traps"] shows own active traps with positions and expiry
- [ ] state["me"]["trap_cooldown"] shows rounds until next trap allowed
- [ ] state["enemies"][i]["has_traps"] shows boolean
- [ ] Enemy trap positions NOT exposed (hidden until triggered)
- [ ] PROMPT.md documents trap action, callbacks, and state dict fields
- [ ] Match JSON includes trap events
- [ ] Tests pass, ruff clean
