# Objective

Add a `--fresh` flag to `npcwars play` and `npcwars battle` that clears all bot memory before running, giving a clean-slate experience.

# Implementation Plan

1. In `npcwars/cli/cmd_play.py: register()`, add `--fresh` flag (store_true)
2. In `npcwars/cli/cmd_battle.py: register()`, add `--fresh` flag (store_true)
3. In both `run()` functions, if `args.fresh`:
   - Call `clear_all_memory(memory_dir)` before loading bots
   - Print "Cleared bot memory" to confirm
4. Also add `--no-memory` flag that disables memory entirely for that run (memory_dir=None)
5. Update help text to explain both flags

# Acceptance Criteria

- [x] `npcwars play --fresh` clears all bot memory before match
- [x] `npcwars battle --fresh` clears all bot memory before match
- [x] `npcwars play --no-memory` runs without loading or saving memory
- [x] Both flags show in `--help` output
- [x] Tests verify memory is cleared with --fresh
- [x] Tests verify no memory file I/O with --no-memory
