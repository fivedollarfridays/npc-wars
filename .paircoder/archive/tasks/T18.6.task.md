# Objective

Add an extended match mode that gives players longer games when the server is under load, automatically selected based on queue depth.

# Implementation Plan

1. In `engine/game.py`, add a `match_mode` parameter supporting `"standard"` and `"extended"` modes
2. Define extended mode constants: `MAX_ROUNDS=400` (vs 200), storm progression 50% slower, `HP=200` (vs 100)
3. Pass `match_mode` through the game initialization and apply the corresponding constants
4. In `server/lobby.py`, check queue depth before starting a match; auto-select `"extended"` mode when queue depth > 3
5. Expose the active match mode in the match result JSON so the viewer can display it
6. Write tests covering both modes' constants, auto-selection logic, and match result metadata

# Acceptance Criteria

- [x] `match_mode="extended"` sets `MAX_ROUNDS=400`, storm 50% slower, `HP=200`
- [x] `match_mode="standard"` keeps defaults (`MAX_ROUNDS=200`, `HP=100`)
- [x] Extended mode is auto-selected when server queue depth > 3
- [x] Match result JSON includes the active `match_mode`
- [x] Tests pass for both modes and auto-selection logic
