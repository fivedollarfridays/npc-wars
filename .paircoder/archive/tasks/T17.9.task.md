# Objective

Create a SQLite-based player registry with player and session tables, using only the Python stdlib `sqlite3` module.

# Implementation Plan

1. Create `server/db.py` with database initialization and CRUD functions
2. Define `players` table: `id` (TEXT PRIMARY KEY), `name` (TEXT NOT NULL), `created` (TEXT ISO timestamp)
3. Define `sessions` table: `token` (TEXT PRIMARY KEY), `player_id` (TEXT FK to players), `expires` (TEXT ISO timestamp)
4. Implement `init_db(db_path)` to create tables if not exists
5. Implement CRUD: `create_player()`, `get_player()`, `list_players()`
6. Implement session ops: `create_session()`, `get_session()`, `expire_session()`
7. Use stdlib `sqlite3` only -- no SQLAlchemy or other ORM

# Acceptance Criteria

- [x] `server/db.py` uses only stdlib `sqlite3` (no third-party ORM)
- [x] `players` table has columns: `id`, `name`, `created`
- [x] `sessions` table has columns: `token`, `player_id`, `expires`
- [x] `init_db(db_path)` creates tables idempotently (IF NOT EXISTS)
- [x] CRUD operations work: `create_player()`, `get_player()`, `list_players()`
- [x] Session operations work: `create_session()`, `get_session()`, `expire_session()`
