# Objective

Run a 1000-match simulation against the current empty 10×10 grid, record baseline metrics, and create a CI-runnable integration test. This establishes the pre-tile-system baseline that Sprint 2's The Pit map results will be compared against.

# Context

Before adding tiles, classes, or events, we need a numerical snapshot of how matches play out on a plain grid. This baseline answers: "what is the natural match length, win distribution, and energy economy without any map features?" Sprint 2 results are only meaningful relative to this baseline.

The spec's balance targets assume a healthy baseline:
- Average match length: 20-28 rounds
- No single bot should dominate (win rate should be roughly uniform across bots)

# Implementation Plan

1. **Run 1000-match baseline**
   - `agentgrounds wars sim --matches 1000 --output docs/sim-baseline/ --seed 100 --quiet`
   - `agentgrounds wars analyze --input docs/sim-baseline/ --output docs/sim-baseline/analysis/`
   - Review: is avg match length in 20-28 range? Is win distribution roughly uniform?
   - If match length is outside range, document the observation (do NOT tune yet — this is a snapshot, not a target to hit)

2. **Create `docs/sim-baseline.md`**
   - Record: avg match length, median, min/max, winner distribution table, energy curve summary
   - Note any anomalies for follow-up in Sprint 2
   - Format: readable markdown with ASCII heatmap screenshot embedded

3. **Write CI integration test `tests/test_sim_integration.py`**
   - Run `agentgrounds wars sim --matches 10 --output /tmp/ci_sim --seed 1` via subprocess
   - Assert: exit code 0
   - Assert: 10 match files created
   - Assert: `sim_summary.json` exists and `avg_match_length` is a positive float
   - Run `agentgrounds wars analyze --input /tmp/ci_sim --output /tmp/ci_analysis`
   - Assert: exit code 0, `heatmaps.json` exists

4. **Add sim integration test to CI workflow**
   - CI currently runs `pytest`. The integration test uses subprocess so it will be picked up automatically.
   - Verify CI passes with the new test (watch for timeout issues — 10 matches should complete in < 30s)

# Acceptance Criteria
