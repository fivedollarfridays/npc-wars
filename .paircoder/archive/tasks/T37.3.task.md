# Objective

Wire terrain effects into the combat system. High ground gives attack bonuses. Cover gives defense. Water penalizes accuracy. Walls block ranged attacks (line of sight).

# Terrain Combat Effects

| Terrain | Attacker On | Defender On |
|---------|------------|-------------|
| high_ground | +2 to-hit, +15% damage | — |
| cover | — | +3 AC (if cover is between attacker and defender) |
| water | -2 to-hit | — |
| wall | — | Blocks ranged LoS |

# Implementation Plan

1. Create `engine/terrain_combat.py`:
   - `get_terrain_to_hit_mod(terrain, attacker_x, attacker_y) -> int` — +2 if high_ground, -2 if water, 0 otherwise
   - `get_terrain_ac_mod(terrain, defender_x, defender_y, attacker_x, attacker_y) -> int` — +3 if cover tile between attacker and defender
   - `get_terrain_damage_mult(terrain, attacker_x, attacker_y) -> float` — 1.15 if high_ground, 1.0 otherwise
   - `has_line_of_sight(terrain, x1, y1, x2, y2) -> bool` — trace line between positions, return False if any wall tile in the way (Bresenham's line algorithm or simple tile walk)
   - `can_rest_heal(terrain, x, y) -> bool` — False if water tile

2. Wire into `engine/rounds_combat.py`:
   - `_roll_melee()`: add terrain to-hit mod and damage mult
   - `_roll_ranged()`: check LoS first (miss if blocked), add terrain mods

3. Wire into `engine/rounds.py`:
   - `apply_energy_and_rest()`: check can_rest_heal before applying rest HP

4. Pass terrain through from game.py to combat functions

5. Tests in `tests/test_terrain_combat.py`
