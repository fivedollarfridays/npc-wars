# Objective

Wire terrain into the movement system. Walls block movement. Water costs extra energy. Power crystals grant energy on first step.

# Implementation Plan

1. Update `resolve_movement()` in `engine/rounds.py`:
   - Accept `terrain: TerrainMap | None` parameter
   - Before moving bot, check `is_walkable(terrain, new_x, new_y)`
   - If wall: generate wall_blocked event, bot stays at current position
   - If water: extra energy cost (+5)
   - Track crystal pickups: set of (x,y) already collected this match

2. Update `_execute_round()` and `_resolve_combat_phases()` in `engine/game.py`:
   - Pass terrain through to resolve_movement

3. Handle crystal tiles:
   - On first step onto crystal: bot.energy += 10, mark crystal as collected
   - Generate crystal_pickup event: `{"type": "crystal_pickup", "emoji": "🤖", "x": 5, "y": 3, "energy": 10}`
   - Track collected crystals on TerrainMap or in match state

4. Update `resolve_movement()` for dash action too — dash checks both intermediate and target tiles

5. Tests in `tests/test_terrain_movement.py`

# Acceptance Criteria

- [ ] Walls block movement (bot stays, event generated)
- [ ] Water tiles cost +5 extra energy to enter
- [ ] Crystal tiles grant +10 energy on first step only
- [ ] Dash blocked by walls in path
- [ ] Spawn positions avoid walls
- [ ] Tests pass, ruff clean
