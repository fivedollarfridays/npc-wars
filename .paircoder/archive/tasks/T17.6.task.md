# Objective

Create a time-limited lobby system that collects player submissions for 30 seconds, triggers a match when the timer expires or 8 players join, and fills remaining slots with AI bots if fewer than 4 humans are present.

# Implementation Plan

1. Create `server/lobby.py` with a `Lobby` class managing the collection window
2. Implement a 30-second countdown timer that starts when the first player joins
3. Accept player submissions into the lobby (max 8 slots)
4. Trigger match immediately if 8 players join before timer expires
5. When timer expires, check player count: if fewer than 4 humans, fill remaining slots with AI bots (delegate to T17.7 fill_bots module)
6. On trigger, enqueue the match via `server/queue.py` and reset the lobby
7. Expose lobby status (time remaining, player count) for the editor UI

# Acceptance Criteria

- [x] `server/lobby.py` implements a `Lobby` class with a 30-second timer
- [x] Lobby accepts player submissions up to 8 slots
- [x] Match triggers immediately when 8 players join
- [x] Match triggers when 30-second timer expires
- [x] Lobbies with fewer than 4 humans are filled with AI bots
- [x] Lobby enqueues the match via `server/queue.py` on trigger
- [x] Lobby status (time remaining, player count) is queryable
