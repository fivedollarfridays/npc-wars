# Objective

Integration gate for S33. Verify full callback + trap pipeline end-to-end. Run a real match with trap-using and callback-using bots.

# Implementation Plan

1. Create `tests/test_s33_integration.py` with test classes:

   **TestCallbackDiscovery**
   - Bot module with setup/react/on_kill discovered correctly
   - Bot module without callbacks gets empty CallbackSet
   - Callbacks gated by level (level 1 bot gets no setup even if function exists)

   **TestSetupExecution**
   - setup() called before round 1 with valid state
   - setup() exception doesn't crash match
   - setup() only called once

   **TestReactExecution**
   - react() called each round with nearby events
   - Events filtered by proximity (3 tiles)
   - react() exception doesn't crash match

   **TestTrapLifecycle**
   - Trap placed → enemy walks on it → damage applied → trap removed
   - Trap expires after 10 rounds
   - Unlimited traps gated by cooldown + energy
   - Trap cooldown enforced
   - Dead bot traps cleaned up

   **TestTrapInMatch**
   - Run a real match with a trap-using bot
   - Verify trap events in match JSON
   - Verify trap damage in stats

   **TestStateDict**
   - state["me"]["traps"] populated for trap-placing bot
   - state["me"]["trap_cooldown"] accurate
   - state["enemies"][i]["has_traps"] reflects reality
   - Enemy trap positions NOT visible

   **TestNoDeadCode**
   - All public functions in engine/callbacks.py have callers outside tests
   - All public functions in engine/traps.py have callers outside tests

2. Run 50-match simulation to check traps don't break balance

# Acceptance Criteria

- [ ] Integration tests verify full callback + trap pipeline
- [ ] Real match with trap bot runs without errors
- [ ] State dict has all new fields
- [ ] No dead code in new modules
- [ ] No regressions, ruff clean
