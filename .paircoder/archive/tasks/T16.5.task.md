# Objective

Add color coding and delta formatting to the diff overlay in the viewer so players can instantly see improvements and regressions.

# Implementation Plan

1. In `viewer/match.html`, add CSS classes for improved (green) and regressed (red) stat rows
2. Set improved background to `#0d4d0d`, regressed background to `#4d0d0d`
3. Format delta values as `+12.5%` (improved) or `-3.2%` (regressed) with sign prefix
4. Use monospace font for stat values to ensure column alignment
5. Sort stat rows by magnitude of delta (largest change first)
6. Apply styles dynamically based on the `classification` field in `matchData.diff`

# Acceptance Criteria

- [ ] Improved stats have green background (`#0d4d0d`)
- [ ] Regressed stats have red background (`#4d0d0d`)
- [ ] Delta displayed as signed percentage (e.g., `+12.5%` / `-3.2%`)
- [ ] Stat values use monospace font and are aligned
- [ ] Stat rows sorted by magnitude of delta (largest change first)
- [ ] Changes contained within `viewer/match.html`
