# Objective

Create a reusable ANSI terminal renderer that draws the NPC Wars battlefield as a DOS-style grid with emoji bots, HP bars, storm overlay, and kill feed.

# Implementation Plan

1. Create `npcwars/cli/renderer.py` with a `TerminalRenderer` class
2. `render_frame(round_data, players, grid_size)` draws one complete frame:
   - Clear screen (`\033[2J\033[H`)
   - Title bar with round number and storm status
   - Grid with storm border (purple `▓▓`), bot emojis, and empty tiles (`·`)
   - Bot roster with HP bars (green/yellow/red) and energy indicators
   - Kill feed (last 5 events)
3. HP bars: `████████░░` format, colored by threshold (>50% green, >25% yellow, red)
4. Storm tiles rendered as `▓▓` in purple ANSI
5. Dead bots shown as dim `💀` on grid and struck-through in roster
6. Use only stdlib (no `rich`, `colorama`, `blessed`) — raw ANSI escapes
7. Support variable grid sizes (10-12)

# Acceptance Criteria

- [ ] `TerminalRenderer.render_frame()` produces a complete ANSI frame string
- [ ] Grid shows storm border as purple block characters
- [ ] Bot emojis render at correct grid positions
- [ ] HP bars are color-coded (green >50%, yellow >25%, red ≤25%)
- [ ] Dead bots show as dim skulls on grid
- [ ] Kill feed shows last 5 events with round numbers
- [ ] Works with grid sizes 10-12
- [ ] No third-party dependencies (stdlib ANSI only)
