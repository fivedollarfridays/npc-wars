# Objective

Add a `memory` field to the Bot object and include it in the state dict passed to `decide()`, so bots can read and write persistent data.

# Implementation Plan

1. In `engine/combat.py: Bot.__init__`, add `self.memory: dict = {}` field
2. In `engine/combat.py: Bot.to_self_dict()`, include `"memory": self.memory`
3. In `engine/state.py: build_state()`, the memory is already included via `to_self_dict()` — verify it appears in `state["me"]["memory"]`
4. Actually, memory should be top-level for cleaner API: add `"memory": bot.memory` directly to the state dict in `build_state()`
5. In `engine/game.py: _create_bots()`, if bot config has a `"memory"` key, set it on the Bot object
6. Bots can modify `state["memory"]` during decide() — but since state is a copy, changes won't persist automatically. Instead: after each round, copy back from the state. Or simpler: give bots a reference to their Bot.memory dict directly.

**Key design decision:** `state["memory"]` should be the SAME dict object as `bot.memory`, not a copy. This way bots mutate it in-place during decide(), and the engine saves it after the match. This matches how the Watcher's pattern_table works.

# Acceptance Criteria

- [x] Bot object has a `memory: dict` field (default empty)
- [x] `state["memory"]` is available in the state dict passed to decide()
- [x] `state["memory"]` is the same object as `bot.memory` (mutations persist)
- [x] `_create_bots()` accepts `"memory"` from bot config
- [x] Tests verify memory is readable and writable from decide()
