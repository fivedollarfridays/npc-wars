# Objective

Create `engine/terrain.py` — terrain map definitions with 5 maps, tile types, and a TerrainMap data model.

# Terrain Types

| Terrain | Char | Movement | Combat | Energy |
|---------|------|----------|--------|--------|
| open | `.` | Normal | Normal | Normal |
| wall | `#` | Blocked | Blocks ranged LoS | — |
| water | `~` | Cost +5 energy | -2 to-hit | No rest healing |
| high_ground | `^` | Normal | +2 to-hit, +15% damage | Normal |
| cover | `%` | Normal | +3 AC when behind cover | Normal |
| crystal | `*` | Normal | Normal | +10 energy on first step |

# Map Definitions (5 maps)

1. **Arena** — Open field, no terrain features. Default map (current behavior).
2. **Fortress** — Central walls creating 4 corridors. Chokepoints.
3. **Highlands** — Elevated center plateau, water along edges.
4. **Maze** — Dense wall grid with multiple paths.
5. **Storm Pit** — Small map, minimal terrain, fast storm.

# Implementation Plan

1. Create `engine/terrain.py`:
   - `TileType` enum or string constants: "open", "wall", "water", "high_ground", "cover", "crystal"
   - `TILE_CHARS` mapping tile type to render character
   - `TerrainMap` dataclass: name, grid_size, tiles (2D list of tile types)
   - `get_tile(terrain, x, y) -> str` — returns tile type at position
   - `is_walkable(terrain, x, y) -> bool` — False for walls
   - `MAP_DEFINITIONS` dict: map name -> builder function that returns TerrainMap
   - `build_map(name, grid_size) -> TerrainMap` — creates terrain for given map and size
   - `get_random_map(rng) -> str` — pick a random map name
   - Arena map: all open tiles
   - Fortress: walls in center cross pattern with 4 corridor gaps
   - Highlands: high_ground in center 3x3, water along bottom 2 rows
   - Maze: wall grid with gaps every 2-3 tiles
   - Storm Pit: all open (small grid, fast storm via mode)
2. Crystal placement: 2-4 crystals placed symmetrically
3. Cover placement: 4-8 cover tiles near walls/corridors
