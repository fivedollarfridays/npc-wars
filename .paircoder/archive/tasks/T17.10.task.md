# Objective

Create a comprehensive server integration test suite that exercises all S17 endpoints and flows end-to-end using httpx TestClient.

# Implementation Plan

1. Create `tests/test_server_integration.py` using httpx `TestClient` against the FastAPI app
2. Test health endpoint returns 200 with `{"status": "ok"}`
3. Test bot submission: valid source returns 202, invalid source returns 400 with errors
4. Test match retrieval: existing match returns 200 with JSON, missing match returns 404
5. Test stats endpoint: valid player returns stats, unknown player returns 404
6. Test leaderboard endpoint: returns ranked list
7. Test lobby flow: submit players, verify lobby fills and triggers match
8. Use fixtures to seed test data (mock results, mock player stats)
