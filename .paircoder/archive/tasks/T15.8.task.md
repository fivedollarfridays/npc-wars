# Objective

Add smooth movement interpolation between rounds so that emoji positions tween fluidly instead of snapping between grid positions.

# Implementation Plan

1. Track previous and next grid positions for each emoji/NPC in a state map (e.g. `prevPositions`, `nextPositions`)
2. When a new round begins, store current positions as `prevPositions` and target positions as `nextPositions`
3. Implement a `lerp(a, b, t)` function for linear interpolation between coordinates
4. Use `requestAnimationFrame` to animate emoji positions from prev to next over the round transition duration
5. Scale interpolation duration by the current playback speed (1x, 2x, 4x) so animations remain smooth at all speeds
6. Ensure dead/eliminated NPCs do not interpolate (they disappear or play their death effect)

# Acceptance Criteria

- [ ] Emoji positions tween smoothly between rounds via requestAnimationFrame
- [ ] Interpolation works correctly at 1x playback speed
- [ ] Interpolation works correctly at 2x playback speed
- [ ] Interpolation works correctly at 4x playback speed
- [ ] Eliminated NPCs do not produce stale interpolation artifacts
