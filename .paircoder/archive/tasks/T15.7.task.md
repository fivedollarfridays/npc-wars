# Objective

Maximize the battlefield arena in the viewer layout so it dominates the viewport, with a compact sidebar for supplementary information.

# Implementation Plan

1. Update the CSS layout in `viewer/match.html` to use CSS Grid or Flexbox with the arena taking 70%+ of viewport width
2. Set sidebar to `max-width: 250px` with fixed positioning or flex-shrink
3. Place kill feed and roster panels inside the sidebar with `max-height` and `overflow-y: auto` for scrollable containers
4. Add a CSS media query for `min-width: 1024px` to ensure responsive behavior
5. Test at various viewport sizes to confirm arena maintains 70%+ width

# Acceptance Criteria

- [x] Arena occupies 70% or more of viewport width
- [x] Sidebar has a maximum width of 250px
- [x] Kill feed is in a fixed-height scrollable container
- [x] Roster is in a fixed-height scrollable container
- [x] Layout is responsive down to 1024px viewport width

# Verification

```bash
# Check for layout CSS rules
grep -n 'max-width.*250\|70%\|overflow.*auto\|1024' viewer/match.html
```
