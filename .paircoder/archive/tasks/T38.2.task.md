# Objective

Wire the diff display into cmd_play, cmd_battle, and run_match.py so players see the diff after every match.

# Implementation Plan

1. Update `agentgrounds/wars/cli/cmd_play.py`:
   - After match playback, compute diff and display formatted summary for each bot
   - Load lifetime stats, compute diff via `compute_diff()`
   - Print `format_match_complete()` for the player's bot (or all bots in local mode)

2. Update `agentgrounds/wars/cli/cmd_battle.py`:
   - After match results, print diff summary

3. Update `run_match.py`:
   - After XP summary, print diff for each bot

4. Ensure lifetime stats directory (`results/`) is scanned correctly
5. Handle edge cases: no previous matches, bot name not found in history

# Acceptance Criteria

- [ ] Diff displays after `agentgrounds wars play`
- [ ] Diff displays after `agentgrounds wars battle`
- [ ] Diff displays after `python run_match.py`
- [ ] First match shows "First match!" instead of diffs
- [ ] Tests pass, ruff clean
