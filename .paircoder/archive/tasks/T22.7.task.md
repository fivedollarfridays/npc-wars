# Objective

Export the tournament's best bot as a standalone .py file and generate a lineage report showing its evolutionary history.

# Implementation Plan

1. `npcwars tournament --best DIR` reads tournament state and:
   - Copies the best bot to `bots/evolved_champion.py`
   - Prints lineage: which bot it descended from, what mutations occurred, scores per generation
2. Lineage report format:
   ```
   ═══ Tournament Champion ═══
   🔮 Evolved_Reaper (Generation 4)

   Lineage:
     Gen 0: 💀 Reaper (original)     WR: 45%
     Gen 1: 💀 Reaper (survived)     WR: 52%
     Gen 2: 🔮 Reaper_v1 (mutant)    WR: 68%
       ↳ energy_threshold: 30 → 24
       ↳ chase_distance: 4 → 5
     Gen 3: 🔮 Reaper_v1 (survived)  WR: 71%
     Gen 4: 🔮 Reaper_v2 (mutant)    WR: 78%
       ↳ deny_hp_threshold: 40 → 48

   Final Stats: W:39 L:11 K:87 WR:78%
   Saved to: bots/evolved_champion.py
   ```
3. Integration test: run a small tournament, export best, verify file is valid

# Acceptance Criteria

- [ ] `--best` exports champion bot to bots/
- [ ] Lineage report shows evolutionary path with mutations
- [ ] Exported bot passes `npcwars validate`
- [ ] Report includes per-generation win rates
- [ ] Tests verify export and lineage output
