# Objective

Render terrain in CLI and browser viewer. Run balance sim across maps.

# Implementation Plan

1. Update CLI renderer (`agentgrounds/wars/cli/renderer.py`):
   - Render terrain tiles: walls as `#`, water as `~`, high_ground as `^`, cover as `%`, crystals as `*`
   - Terrain renders as background layer, bots render on top
   - Use dim ANSI colors for terrain (walls gray, water blue, high_ground yellow)

2. Add feed formatters for terrain events:
   - `crystal_pickup`: "{emoji} ✨ picked up power crystal! +10 energy"
   - `wall_blocked`: "{emoji} hit a wall"
   - `ranged_blocked`: "{emoji} 🏹 blocked by wall"

3. Run 200-match balance sim across all 5 maps:
   - 40 matches per map
   - Track win rate per bot per map
   - Verify no map creates >60% win rate for any bot

4. Save to `tools/terrain_balance_results.json`
5. Regression test

# Acceptance Criteria

- [ ] CLI shows terrain tiles with appropriate characters
- [ ] Terrain events in kill feed
- [ ] 200-match sim across all maps balanced
- [ ] No bot >60% on any single map
- [ ] Tests pass, ruff clean
