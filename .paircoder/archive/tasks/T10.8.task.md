# Objective

Play stinger sound effects in the HTML viewer using the Web Audio API. Stinger audio assets are either embedded as base64 or loaded from the `audio/assets/` directory. Sounds trigger on game events during round playback, with volume controlled by a master slider and scaled by drama tier.

# Implementation Plan

1. **Embed or load audio assets in the viewer**:
   - Option A: Base64-encode WAV stingers and embed as data URIs in the HTML file
   - Option B: Load from `audio/assets/` directory via fetch (requires serving the directory)
   - Recommendation: Base64 for the 13 stingers (small files, <5MB total) to keep single-file viewer

2. **Create `AudioEngine` JS class** in the viewer's `<script>` block:
   - `constructor()`: create `AudioContext`, initialize gain nodes
   - `preload(stingerMap)`: decode all base64 audio into `AudioBuffer` objects, store in a map
   - `play(eventType, tier)`: look up buffer for event type, create `BufferSource`, connect to gain node, adjust volume by tier, call `start()`
   - `setMasterVolume(value)`: update master gain node (0.0 to 1.0)
   - `mute()` / `unmute()`: toggle master gain to 0 or restore previous value

3. **Wire into `renderRound` function**:
   - For each event in `round.events`, check if event type exists in the stinger map
   - Call `audioEngine.play(event.type, round.spectacle.tier)` for matching events
   - Tier-based volume scaling: calm=0.3, heating=0.5, intense=0.7, hype=0.9, chaos=1.0

4. **Add volume control UI**:
   - Master volume slider in the viewer controls bar (range input, 0-100)
   - Mute/unmute button (speaker icon toggle)
   - Persist volume preference in `localStorage`

# Acceptance Criteria

- [ ] Stingers play on hit, kill, and bump events during viewer playback
- [ ] Volume slider controls master volume (0-100 range)
- [ ] Stinger volume scales with drama tier (calm=quiet, chaos=full)
- [ ] Audio can be muted and unmuted via button
