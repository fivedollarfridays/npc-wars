# Objective

Implement The Watcher's adaptive target rotation for co-op matches with multiple humans. The Watcher maintains separate pattern profiles per human and hunts whichever has the highest sync rating (most predictable). When the current target starts improvising and sync drops, the Watcher pivots to a different human. It never stops observing non-targeted humans. Depends on T12.4, T12.5. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Co-op Behavior -- Adaptive Target Rotation).

# Implementation Plan

1. **Create `tests/test_watcher_rotation.py`** with tests for:
   - With 2 humans, Watcher targets the one with higher sync rating
   - When current target's sync drops below another human's sync, Watcher switches target
   - Pattern profiles maintained for ALL humans simultaneously (not just current target)
   - Non-targeted humans are still observed (watcher_observer records their actions)
   - With only 1 human, that human is always the target
   - Switching target does not reset pattern data for previous target

2. **Add to `engine/watcher_brain.py`**:
   - `select_target(sync_tracker: SyncTracker, human_bots: list) -> str` — returns the `player_id` of the human with the highest sync rating:
     - Iterate all human bots, query `sync_tracker.get_sync(player_id)` for each
     - Return the player_id with the highest sync
     - Ties broken by proximity (closer human preferred) or arbitrarily
   - Update `select_counter_action` to accept a `target_id` parameter (selected by `select_target`)
   - Ensure the watcher_observer (T12.3) continues recording data for ALL humans each round, not just the target

3. **Run tests and verify** all pass

# Acceptance Criteria
