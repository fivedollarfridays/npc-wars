# Objective

Create `agentgrounds/wars/tournament.py` — the core tournament runner that executes multi-match generations and tracks results.

> **Ordering note:** Requires T23.1 (rename) to complete first so all modules use the `agentgrounds.wars` package namespace.

# Implementation Plan

1. Create `agentgrounds/wars/tournament.py` with:
   - `TournamentConfig` dataclass: `generations`, `matches_per_gen`, `population_size`, `seed`
   - `GenerationResult` dataclass: `generation_num`, `bot_scores: dict[str, BotScore]`, `best_bot_emoji`, `matches_played`
   - `BotScore` dataclass: `wins`, `losses`, `kills`, `damage_dealt`, `rounds_survived`, `win_rate`
   - `run_generation(bot_configs, config, gen_num) -> GenerationResult`: runs N matches with the given bots, aggregates scores
   - `run_tournament(bot_dir, config) -> list[GenerationResult]`: orchestrates all generations
2. Each generation: load bots from `agentgrounds.wars` package → run matches → score → return results
3. Use fixed seeds per generation for reproducibility: `seed + gen_num * 1000 + match_num`
4. Print progress: `Generation 1/10: Running match 5/20...`

# Acceptance Criteria

- [ ] `run_generation()` runs N matches and returns aggregated scores
- [ ] `BotScore` tracks wins, kills, damage, win_rate
- [ ] Seeds are deterministic per generation/match
- [ ] Progress output printed during execution
- [ ] Tests pass with a small tournament (2 generations, 3 matches each)
