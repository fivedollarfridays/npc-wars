# Objective

Create a Docker-based sandbox for executing match bot code securely, with automatic fallback to multiprocessing when Docker is unavailable.

# Implementation Plan

1. Create `Dockerfile.sandbox` with a minimal Python image, no network access, and a 10s execution timeout
2. Create `server/docker_sandbox.py` with a `run_in_sandbox(bot_code: str) -> dict` function
3. Spawn an ephemeral container per match: pass bot code via stdin, collect result via stdout JSON
4. Enforce 10-second hard timeout using Docker's `--stop-timeout` and a watchdog timer
5. Disable network access with `--network=none`
6. Implement `multiprocessing` fallback when Docker daemon is unavailable (detect via `docker info`)
7. Write tests covering sandbox execution, timeout enforcement, network isolation, and fallback behavior

# Acceptance Criteria

- [x] Each match runs in an ephemeral Docker container
- [x] Container has a 10-second timeout enforced
- [x] Container has no network access (`--network=none`)
- [x] Bot code is passed via stdin and result returned via stdout JSON
- [x] Falls back to `multiprocessing` execution when Docker is unavailable
- [x] Tests pass for sandbox execution, timeout, and fallback
