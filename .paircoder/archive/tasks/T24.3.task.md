# Objective

Update `cmd_play.py` and `cmd_watch.py` to render sub-frames (action + resolution) per round instead of a single frame.

# Implementation Plan

1. **Update frame loop in both commands**:
   - For each round:
     1. Render action sub-frame (`renderer.render_action_frame()`) — 300ms
     2. Render resolution sub-frame (`renderer.render_frame()`) — remaining delay
   - Total per-round time stays the same (controlled by `--speed`)
   - At speed=1: 300ms action + 700ms resolution = 1s total
   - At speed=4: 75ms action + 175ms resolution = 250ms total

2. **Skip action frame for rounds with no combat events**
   - If no hit/miss/defend/ranged events, just show the resolution frame
   - Keeps quiet rounds fast

3. **Add `--no-fx` flag** to both commands:
   - Disables sub-frame animation, reverts to single frame per round
   - Useful for fast playback, scripted pipelines, agents-developing-agents

4. **Ctrl+C handling** — both sub-frame renders exit alt screen cleanly

# Acceptance Criteria

- [ ] `agentgrounds wars play --seed 42` shows combat indicators during attacks
- [ ] `agentgrounds wars watch file.json` shows combat indicators
- [ ] `--no-fx` disables sub-frame animation
- [ ] Quiet rounds (no combat) render as single frame
- [ ] Ctrl+C exits cleanly from any sub-frame
- [ ] Tests pass, ruff clean
