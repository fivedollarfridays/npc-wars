# Objective

Create the `POST /api/submit-bot` endpoint that accepts bot source code, validates it via the existing AST scanner, and returns scan errors or a queued job ID.

# Implementation Plan

1. Create `server/routes/submit.py` with the submit-bot route
2. Accept JSON body with `source` field containing bot Python code
3. Call `engine.bot_scanner.scan_bot_source()` to validate the submission
4. If scan finds errors, return 400 with `{"errors": [...]}`
5. If scan passes, generate a `job_id` (UUID) and return 202 with `{"job_id": "..."}`
6. Implement rate limiting: 1 submission per 30 seconds per session (in-memory tracker)
7. Register router on the FastAPI app

# Acceptance Criteria

- [x] `POST /api/submit-bot` endpoint exists in `server/routes/submit.py`
- [x] Calls `bot_scanner.scan_bot_source()` for AST validation
- [x] Returns 400 with `{"errors": [...]}` when scan fails
- [x] Returns 202 with `{"job_id": "..."}` when scan passes
- [x] Rate limited to 1 request per 30 seconds per session (returns 429 on violation)
- [x] Router registered on the main FastAPI app
