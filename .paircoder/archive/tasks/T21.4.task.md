# Objective

Enforce the 10KB memory limit per bot to prevent memory-based abuse or accidental bloat.

# Implementation Plan

1. In `data/bot_memory.py: save_bot_memory()`, after serializing to JSON:
   - Check `len(json_str.encode('utf-8')) <= MAX_MEMORY_BYTES`
   - If exceeded, log a warning and truncate: remove oldest keys until under limit
   - If still over after truncation (single key too large), raise `MemoryLimitExceeded` error
2. Create `MemoryLimitExceeded(ValueError)` exception class
3. In `engine/game.py: _finalize_match()`, catch `MemoryLimitExceeded` and log warning (don't crash the match)
4. Add memory size to match stats or bot metadata so players can see usage
5. Test edge cases: exactly at limit, 1 byte over, empty memory, single huge key

# Acceptance Criteria

- [x] Memories > 10KB trigger truncation attempt
- [x] Truncation removes oldest keys first
- [x] If single key > 10KB, `MemoryLimitExceeded` raised
- [x] Match doesn't crash when limit exceeded — warning logged, memory truncated
- [x] Tests cover boundary conditions
