# Objective

Implement Invasion mode: a single human drops into a match with 5-10 bots. All bots receive a bounty on the human, incentivizing them to hunt the human player. The Watcher can spawn if the human proves skilled. This is "death sentence by design -- exists for the clip." Depends on T13.1, T11.4 (async tick loop for human input). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 10 (Invasion).

# Implementation Plan

1. **Create `tests/test_invasion.py`** with tests for:
   - Invasion mode accepts exactly 1 human (rejects 0 or 2+)
   - Match starts with 5-10 bots plus the human
   - Bounty automatically placed on the human at match start (in `state["bounties"]`)
   - Watcher can spawn if human meets spawn conditions (T12.7)
   - Match JSON includes `"mode": "invasion"` in metadata
   - Special invasion start event: `{"type": "human_enter", "emoji": human_emoji}` in round 1 events
   - Match announcement text: "A HUMAN HAS ENTERED THE ARENA"

2. **Add Invasion mode handling to `engine/game.py`** (or `engine/invasion.py` if game.py is large):
   - Validate exactly 1 human bot in bot list
   - Select 5-10 random bots from available pool (configurable via ModeConfig)
   - Place bounty on human: `{"target_emoji": human.emoji, "reward": "full_restore", "bonus_damage": 3}`
   - Emit `human_enter` event in round 1
   - Enable watcher spawn checks each round
   - Wire into `run_match(mode=MatchMode.INVASION)`

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Exactly 1 human allowed
- [ ] Bounty placed on human automatically
- [ ] Watcher spawns if human is skilled
- [ ] Special invasion start event in match JSON
