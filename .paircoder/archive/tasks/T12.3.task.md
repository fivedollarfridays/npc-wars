# Objective

Populate the pattern table from observed human actions during matches. The observer watches each round's events and game state, classifies the context for each human bot, and records the human's actual action into the pattern table. This bridges game events to The Watcher's learning system. Depends on T12.2 (PatternTable). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (The Pattern Table, Counter-Action Selection).

# Implementation Plan

1. **Create `tests/test_watcher_observer.py`** with tests for:
   - Human who took damage last round is classified as `"after_damage"` context; their action is recorded
   - Human at distance 1 from nearest enemy is classified as `"at_range_1"` context
   - Human below 30 HP is classified as `"below_30_hp"` context
   - Human near storm border is classified as `"storm_closing"` context
   - Human whose action differs from their bot's `decide()` output is classified as `"override_detected"` context
   - Both per-player and `__global__` profiles are updated
   - Multiple contexts can apply in the same round (e.g., below 30 HP AND at range 1)

2. **Create `engine/watcher_observer.py`**:
   - `classify_contexts(human_bot, round_events, state) -> list[str]` — examines game state to determine which contexts apply:
     - `"after_damage"`: human's HP decreased since last round (check events for damage to this bot)
     - `"at_range_1"`: Manhattan distance to nearest enemy is 1
     - `"below_30_hp"`: human's current HP < 30
     - `"storm_closing"`: storm border is within 2 tiles of human's position
     - `"override_detected"`: human's actual action differs from their bot's decided action
   - `observe_round(pattern_table, human_bots, round_events, state) -> None` — for each human bot, classify contexts and record their actual action for each applicable context

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Correctly classifies context from game state
- [ ] Records human action per context per player
- [ ] Detects when human overrides bot (action differs from bot's decide)
- [ ] Updates both per-player and __global__ profiles
