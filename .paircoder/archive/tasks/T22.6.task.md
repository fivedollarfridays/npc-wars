# Objective

Save tournament state after each generation so tournaments can be resumed from checkpoints.

# Implementation Plan

1. After each generation, save state to `{output_dir}/state.json`:
   ```json
   {
     "config": {...},
     "current_generation": 3,
     "generations": [
       {"gen": 0, "rankings": [...], "best": "💀", "best_score": 0.82},
       ...
     ],
     "bot_sources": {"💀": "source...", "🌟": "source...", ...}
   }
   ```
2. `npcwars tournament --resume DIR` loads state and continues from last completed generation
3. Save mutant bot files to `{output_dir}/gen_{N}/` directories
4. Each generation directory contains the bot .py files used in that generation
5. Validate that resumed tournament has compatible config

# Acceptance Criteria

- [ ] Tournament state saved after each generation
- [ ] `--resume` continues from last completed generation
- [ ] Bot sources preserved per generation
- [ ] Resume detects and rejects incompatible configs
- [ ] Tests verify save/load/resume cycle

# Verification

```bash
npcwars tournament --generations 5 --seed 42  # interrupt after gen 3
npcwars tournament --resume data/tournament/   # continues from gen 3
pytest tests/test_tournament_resume.py -v
```
