# Objective

Create a Redis-backed match queue and a separate worker process that dequeues jobs, builds bot configs, runs matches, and stores results.

# Implementation Plan

1. Create `server/queue.py` with functions to enqueue/dequeue match jobs via Redis lists
2. Create `server/worker.py` as a standalone process that polls the queue
3. Worker dequeues a job, builds bot configs from submitted source, calls `engine.game.run_match()`
4. Store match result JSON in `results/` directory keyed by job_id
5. Implement graceful shutdown via signal handling (SIGTERM/SIGINT)
6. Add `redis>=5.0` to project dependencies
7. Write tests with a mocked Redis client

# Acceptance Criteria

- [x] `server/queue.py` provides `enqueue_match()` and `dequeue_match()` functions
- [x] `server/worker.py` runs as a separate process (`python -m server.worker`)
- [x] Worker calls `engine.game.run_match()` to execute matches
- [x] Match results stored as JSON in `results/{job_id}.json`
- [x] Graceful shutdown on SIGTERM/SIGINT (finishes current match before exiting)
- [x] `redis>=5.0` added to project dependencies
