# Implementation Plan

1. Create `engine/equipment.py` with:
   - `EQUIPMENT_BUDGET = 40`
   - `EquipmentSlot` enum: WEAPON, ARMOR, ACCESSORY, TACTICAL
   - `EQUIPMENT_CATALOG` dict with all items organized by slot
   - `EQUIPMENT_DEFAULTS` — sword + leather, no accessories, no tactical
   - `validate_equipment(selections: dict) -> tuple[bool, str]` — budget check, mandatory slots, max counts
   - `EquipmentBonuses` dataclass — computed bonuses from a loadout (to_hit, damage_min, damage_max, dr, max_hp, max_energy, dodge, crit_mult, initiative, energy_regen, action_cost_mods)
   - `compute_equipment_bonuses(selections: dict) -> EquipmentBonuses` — aggregate all item bonuses
2. Tests in `tests/test_equipment.py`
