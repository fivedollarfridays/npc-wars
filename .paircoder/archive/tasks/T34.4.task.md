# Objective

Run balance simulations with trap-using bots to validate trap parameters. Tune if needed so traps are viable but not dominant.

# Implementation Plan

1. Run 200-match simulation with bot pool including trapper bot:
   - Pool: example_trapper, reaper, example_aggro, example_tank, example_kiter, goose_loose
   - Matches: 200, random 4-6 bot subsets
   - Track: win rate per bot, trap placement rate, trap trigger rate, trap kills

2. Analyze results:
   - **Trap usage rate**: What % of rounds does trapper place traps?
   - **Trap trigger rate**: What % of placed traps actually trigger?
   - **Trap kill rate**: What % of kills come from traps?
   - **Trapper win rate**: Is it competitive (30-60%) or degenerate?

3. Tune parameters if needed:
   - If trap trigger rate < 10%: reduce cooldown or increase lifetime
   - If trapper win rate > 60%: increase cooldown or reduce damage
   - If trapper win rate < 20%: increase damage or reduce energy cost
   - Update constants in `engine/traps.py`

4. Save results to `tools/trap_balance_results.json`

5. Add balance regression test in `tests/test_s34_regression.py`:
   - Trapper win rate between 20-60%
   - No bot wins >65% with traps in play

# Acceptance Criteria

- [ ] 200-match simulation completes
- [ ] Trap usage and effectiveness data collected
- [ ] Parameters tuned if needed (or documented as correct)
- [ ] Balance regression test added
- [ ] Results saved to tools/
