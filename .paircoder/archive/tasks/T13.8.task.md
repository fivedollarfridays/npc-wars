# Objective

Auto-post match results to Discord after scheduled matches complete. Wire the existing discord_integration notify_match_end and announcements.py embed builders into the scheduled match script. Graceful degradation if Discord is not configured (no crash, just skip posting). Depends on T13.7 (scheduled match script). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 11 (Community Hooks).

# Implementation Plan

1. **Add tests to `tests/test_scheduled_match.py`** for:
   - Discord posting called after match completes (mock the Discord client)
   - Embed includes winner emoji, final stats, elimination order
   - Graceful skip if DISCORD_TOKEN or RESULTS_CHANNEL_ID not configured (no exception raised)
   - Embed format matches existing announcements.py builders
   - Results include match mode, round count, and participant list

2. **Update `scripts/scheduled_match.py`**:
   - After saving match results, attempt Discord notification:
     - Check for `DISCORD_TOKEN` and `RESULTS_CHANNEL_ID` environment variables
     - If not set, log "Discord not configured, skipping post" and continue
     - If set, use existing `discord_integration.notify_match_end()` or `announcements.py` embed builder
   - Add `--no-discord` flag to skip posting even if configured
   - Post to `RESULTS_CHANNEL_ID` with embed containing: winner, stats, elimination order, match link (if viewer deployed)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Results posted to Discord after match
- [ ] Uses existing embed format
- [ ] Graceful degradation if Discord not configured
- [ ] Includes winner, stats, elimination order
