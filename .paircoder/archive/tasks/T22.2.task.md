# Objective

Implement a scoring and ranking system that determines which bots survive to the next generation and which get culled.

# Implementation Plan

1. Add to `npcwars/tournament.py`:
   - `rank_bots(scores: dict[str, BotScore]) -> list[tuple[str, BotScore]]`: sort by composite score
   - Composite score = `win_rate * 0.5 + (kills / max_kills) * 0.3 + (rounds_survived / max_rounds) * 0.2`
   - `select_survivors(ranked: list, keep_ratio: float = 0.5) -> list[str]`: top N bots survive
   - `select_for_mutation(ranked: list, mutate_count: int) -> list[str]`: pick bots to clone+mutate
2. Elitism: the #1 bot always survives unchanged
3. Handle ties by secondary sort (kills, then rounds_survived)

# Acceptance Criteria

- [ ] `rank_bots` produces a sorted list by composite score
- [ ] Top 50% survive by default (configurable)
- [ ] #1 bot always preserved (elitism)
- [ ] Ties broken deterministically
- [ ] Tests verify ranking with known scores
