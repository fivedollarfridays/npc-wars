# Objective

Refactor the existing match runner (`run_match`) to accept a mode parameter, defaulting to CLASSIC. Classic mode produces identical output to the current (pre-refactor) behavior. This establishes the mode system foundation that all other modes build upon. Depends on T13.1.

# Implementation Plan

1. **Update `tests/test_game.py`** with tests for:
   - `run_match()` with no mode parameter produces identical output to current behavior
   - `run_match(mode=MatchMode.CLASSIC)` produces identical output
   - Mode parameter is accepted and stored in match JSON metadata
   - CLASSIC mode uses 0 humans, 5-20 bots (existing defaults)

2. **Update `engine/game.py` `run_match()`**:
   - Add `mode: MatchMode = MatchMode.CLASSIC` parameter
   - Load `ModeConfig` from `get_config(mode)` at match start
   - Apply mode config: validate bot count against min/max, set watcher_enabled flag
   - Include `"mode": mode.value` in match JSON metadata
   - Ensure CLASSIC mode path is identical to existing behavior (no regressions)

3. **Run full test suite** to verify no regressions

# Acceptance Criteria

- [ ] Default mode is CLASSIC
- [ ] CLASSIC mode output identical to pre-refactor
- [ ] Mode parameter accepted by run_match
