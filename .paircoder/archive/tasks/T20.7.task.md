# Objective

Wire everything together: make `npcwars play` the default experience, add the starter bot to `npcwars init`, and update README with the new flow.

# Implementation Plan

1. Update `npcwars/cli/cmd_init.py` to include `starter.py` in the scaffolded bots
2. Update `README.md` quick start to use the new flow:
   ```
   pip install npc-wars
   npcwars init
   npcwars play          # watch your first match!
   # Edit bots/starter.py to make it your own
   npcwars play --seed 42  # test your changes
   ```
3. Add `npcwars generate` to README as the "AI agent" path
4. Update `CONTRIBUTING.md` with the agent arena angle
5. Ensure `npcwars play` is the highlighted command everywhere (not `battle`)

# Acceptance Criteria

- [ ] `npcwars init` includes starter.py in scaffolded bots
