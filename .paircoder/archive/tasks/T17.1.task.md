# Objective

Create the FastAPI application skeleton with a health check endpoint, Uvicorn runner, and CORS middleware configured for the hosted server layer.

# Implementation Plan

1. Create `server/__init__.py` package init
2. Create `server/app.py` with FastAPI app instance, CORS middleware (allow all origins for dev), and `GET /health` returning `{"status": "ok"}`
3. Add Uvicorn runner block (`if __name__ == "__main__"`) for `python -m server.app`
4. Add `fastapi>=0.115` and `uvicorn>=0.34` to project dependencies
5. Write tests for health endpoint and CORS headers
