# Objective

End-to-end validation of the human play pipeline. Run a full async match with `MockInputAdapter`, verify human override events appear in match JSON, verify bounty placement and claiming, and verify AFK detection triggers correctly.

# Implementation Plan

1. **Create `tests/test_integration_human.py`** with:
   - **Test: mock human match runs to completion** -- create 5 bots + 1 with `MockInputAdapter` (pre-configured action sequence), run `run_match_async`, verify match completes with all rounds and a winner
   - **Test: override events in match JSON** -- verify `"human_override"` events appear in rounds where the mock adapter returned an action different from the bot's decision
   - **Test: bounty placement** -- verify `state["bounties"]` is non-empty during rounds where the human bot is alive; verify bounty `target_emoji` matches the human's bot emoji
   - **Test: bounty claiming** -- set up a scenario where a bot kills the human; verify `"bounty_claimed"` event in round events; verify killer receives HP/energy restore
   - **Test: AFK detection** -- use a `MockInputAdapter` that returns `None` for 10+ consecutive rounds; verify AFK badge appears at round 3+ and kicked status at round 10+
   - **Test: no override event on timeout** -- verify rounds where mock adapter returns `None` do not contain `"human_override"` events
   - **Test: match with 0 humans identical to sync** -- run same seed with `run_match` and `run_match_async` (no humans), verify identical output

2. **Fix any failures** discovered during integration:
   - Trace through the async pipeline if overrides are not recorded
   - Verify bounty wiring in combat resolution
   - Check AFK counter increments correctly

3. **Run full test suite** to verify no regressions from Sprint 4 work

# Acceptance Criteria

- [ ] All integration tests pass
- [ ] Mock human match runs to completion with correct output
- [ ] Override events present in match JSON for rounds with human overrides
- [ ] Bounty placed and claimed correctly in match flow
