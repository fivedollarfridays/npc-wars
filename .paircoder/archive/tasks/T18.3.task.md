# Objective

Add permalink sharing for match replays so players can share short URLs that load the viewer with the correct match data and display social sharing previews.

# Implementation Plan

1. Create `server/routes/share.py` with a `GET /m/:id` route that resolves to the viewer with embedded match data
2. Add Open Graph meta tags (`og:title`, `og:description`, `og:image`) to the served HTML for social sharing previews
3. Add a "Copy Link" button to the viewer UI in `viewer/match.html` that copies the permalink to the clipboard
4. Generate match thumbnail or use a default image for the `og:image` tag
5. Register the share route in the FastAPI app
6. Write tests covering URL resolution, OG meta tag presence, and copy-link button rendering

# Acceptance Criteria

- [x] `/m/:id` short URLs resolve to the viewer with the correct match data loaded
- [x] Open Graph meta tags are present in the HTML response for social sharing previews
- [x] Copy-link button exists in the viewer UI and copies the permalink
- [x] Tests pass for URL resolution and OG tag rendering
