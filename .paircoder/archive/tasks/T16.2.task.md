# Objective

Create a per-player lifetime stats API that computes per-stat averages from all historical match results for a given player.

# Implementation Plan

1. Create `data/lifetime_stats.py` with `get_lifetime_stats(results_dir, emoji)` function
2. Use `data/match_history.py:get_all_matches()` to load all historical match JSON files from `results_dir`
3. Filter match data to the target player (identified by `emoji`)
4. Use `data/leaderboard.py:aggregate_stats()` to compute per-stat averages across all matches
5. Return a dict of stat name to average value
6. Write tests in `tests/test_lifetime_stats.py` with fixture match files

# Acceptance Criteria

- [x] `get_lifetime_stats(results_dir, emoji)` returns per-stat averages from all historical matches
- [x] Reuses existing `aggregate_stats()` from `data/leaderboard.py`
- [x] Reuses existing `get_all_matches()` from `data/match_history.py`
- [x] Returns empty dict or sensible default when player has no history
- [x] All tests in `tests/test_lifetime_stats.py` pass
