# Objective

Implement Boss Fight mode: 2-4 humans fight a single community bot promoted to Boss with boosted stats (500 HP, 2x damage, all actions unlocked). The boss bot's `decide()` code runs unmodified -- only stats change. No regular bots, no Watcher. Weekly event format. Depends on T13.1, T11.4 (async tick). Reference: docs/RESEARCH-spectacle-and-human-play.md Section 10 (Boss Fight Details).

# Implementation Plan

1. **Create `tests/test_boss_fight.py`** with tests for:
   - Boss Fight mode accepts 2-4 humans
   - Boss bot has 500 HP (5x base 100)
   - Boss bot deals 2x base damage (50 instead of 25)
   - Boss bot has all actions unlocked (same as Watcher: move, attack, rest, defend, ranged_attack, dash, taunt)
   - Boss bot's `decide()` function runs unmodified (the original bot code)
   - No regular bots in the match (just boss + humans)
   - No Watcher spawns (watcher_enabled=False)
   - Match ends when boss dies (humans win) or all humans die (boss wins)
   - Match JSON includes `"mode": "boss_fight"` and `"boss_emoji"` in metadata

2. **Create `engine/boss_fight.py`** (or add to game.py):
   - `BOSS_HP = 500`, `BOSS_DAMAGE_MULTIPLIER = 2`
   - `promote_to_boss(bot: Bot) -> Bot` — creates boss variant of an existing community bot:
     - Sets HP to `BOSS_HP`
     - Multiplies attack_power by `BOSS_DAMAGE_MULTIPLIER`
     - Unlocks all actions
     - Preserves original `decide()` function unmodified
   - Wire into `run_match(mode=MatchMode.BOSS_FIGHT, boss_bot=selected_bot)`
   - Match end condition: boss.hp <= 0 (humans win) or all humans eliminated (boss wins)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Boss has 500 HP and 2x base damage
- [ ] Boss has all actions unlocked
- [ ] Boss code is an existing community bot (not custom)
- [ ] 2-4 humans fight the boss
- [ ] Match ends when boss dies or all humans die
