# Objective

Handle the first-match edge case when no historical data exists for a player, ensuring no crashes and a clear "first match" UX.

# Implementation Plan

1. In `data/stat_diff.py`, update `compute_diff()` to detect when `lifetime_avg` is empty or None
2. Return a special result indicating first match (e.g., `{"first_match": True, ...}`) with all stats classified as improved and no deltas
3. In `viewer/match.html`, detect the first-match flag in diff data
4. Display a "FIRST MATCH!" banner instead of the normal diff table
5. Show all stats in green with current values only (no delta arrows)
6. Write tests for empty history, None lifetime_avg, and missing player scenarios

# Acceptance Criteria

- [x] First match shows "FIRST MATCH!" banner in the viewer overlay
- [x] All stats shown in green when no historical data exists
- [x] No delta values displayed for first match (no arrows, no percentages)
- [x] No crashes when `lifetime_avg` is empty dict or None
- [x] `compute_diff()` returns a recognizable first-match result structure
- [x] Tests cover empty history, None input, and missing player cases
