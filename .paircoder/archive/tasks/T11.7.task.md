# Objective

Allow human play via Discord message buttons. Create a `DiscordInputAdapter` that implements the `HumanInputAdapter` interface using `discord.ui.View` with directional buttons for movement, attack, defend, and rest actions. Each round sends an ephemeral button view and collects the human's press within a 2-second window.

# Implementation Plan

1. **Create `tests/test_discord_human.py`** with tests for:
   - Button press returns the correct action tuple (e.g., north move button returns `("move", "north")`)
   - Timeout (no button press within 2s) returns `None`
   - All action types produce correct tuples: move directions, attack directions, defend, rest
   - Disconnect/error handling returns `None` gracefully

2. **Create `discord_bot/human_play.py`**:
   - `DiscordInputAdapter(HumanInputAdapter)`:
     - `__init__(interaction: discord.Interaction, user_id: int)`
     - `get_action(state: dict, timeout_s: float) -> tuple | None`:
       - Create a `HumanPlayView` (discord.ui.View) with action buttons
       - Send as ephemeral followup message to the interaction
       - Wait for button press with `asyncio.wait_for(timeout=timeout_s)`
       - Return action tuple on press, `None` on timeout
   - `HumanPlayView(discord.ui.View)`:
     - Row 1 (movement): north, south, east, west arrow buttons
     - Row 2 (attack): north, south, east, west sword buttons (prefixed with attack emoji)
     - Row 3 (utility): defend button, rest button
     - Each button callback sets `self.action` and calls `self.stop()`
   - Button-to-action mapping:
     - Arrow buttons: `("move", direction)`
     - Sword buttons: `("attack", direction)`
     - Shield button: `("defend",)`
     - Sleep button: `("rest",)`

3. **Handle edge cases**:
   - Ephemeral messages prevent channel spam (only the player sees their buttons)
   - If the user disconnects, `get_action` returns `None`
   - View timeout auto-disables buttons after the round window

# Acceptance Criteria

- [ ] Discord buttons send correct action tuples for all action types
- [ ] 2-second timeout returns `None` (bot fallback)
- [ ] Ephemeral messages prevent channel spam
- [ ] Handles disconnect/timeout gracefully without errors
