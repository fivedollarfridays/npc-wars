# Objective

Deploy the HTML match viewer as a static site on GitHub Pages. Add URL parameter support so `?match=URL` loads match JSON from any URL (enabling shareable replay links). Include an index page with match selector listing available results. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 14 (Open Questions - Hosted viewer).

# Implementation Plan

1. **Create `.github/workflows/deploy-viewer.yml`**:
   - Trigger on push to main branch
   - Copy `viewer/match.html` to gh-pages deployment
   - Copy `results/*.json` to deployment (latest N matches)
   - Deploy using `actions/deploy-pages` or `peaceiris/actions-gh-pages`

2. **Update `viewer/match.html`**:
   - Add URL parameter parsing: check for `?match=URL` on load
   - If `?match=` present, fetch match JSON from that URL via `fetch()` (CORS-aware: catch errors, show user-friendly message if blocked)
   - If no parameter, show match selector UI

3. **Create `viewer/index.html`** (or integrate into match.html):
   - List available match JSON files from `results/` directory
   - Each entry links to `match.html?match=results/match_XXX.json`
   - Simple, clean UI matching existing dark theme

4. **Add README badge** with viewer link: `https://fivedollarfridays.github.io/npc-wars/`

# Acceptance Criteria

- [ ] Viewer accessible at https://fivedollarfridays.github.io/npc-wars/
- [ ] ?match=URL loads remote match JSON
- [ ] Match selector lists available matches
- [ ] Deploys automatically on push to main
