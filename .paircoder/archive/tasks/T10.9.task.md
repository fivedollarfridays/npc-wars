# Objective

Create a background music escalation system where the hype track intensity follows the drama score. Three intensity levels (ambient, mid, peak) crossfade as tier changes. For the video renderer, pre-render hype track volume automation. For the HTML viewer, automate Web Audio gain nodes.

# Implementation Plan

1. **Create `audio/hype.py`** with:
   - `HYPE_TRACKS` dict mapping intensity levels to audio file paths:
     - `"ambient"` -> cute bubbly baseline track (calm/heating tiers)
     - `"mid"` -> mid-energy track (intense tier)
     - `"peak"` -> EDM/boss-fight track (hype/chaos tiers)
   - `select_hype_track(tier: str) -> dict` returning `{"track": path, "volume": float, "intensity": str}`
   - Tier-to-intensity mapping: calm/heating -> ambient, intense -> mid, hype/chaos -> peak
   - Volume levels: ambient=0.15, mid=0.4, peak=0.8

2. **Add crossfade logic**:
   - `build_hype_timeline(match_data: dict, round_duration_ms: int) -> list[dict]`
   - Each entry: `{"timestamp_ms": int, "track": str, "volume": float, "crossfade_ms": int}`
   - When tier changes between rounds, insert a crossfade event (500ms fade)
   - Consecutive rounds at the same tier produce no new events

3. **Video renderer integration** (in `audio/renderer.py`):
   - Use hype timeline to build ffmpeg volume filter with keyframes
   - Layer hype track under stingers using ffmpeg amix with volume automation
   - Crossfade between tracks using ffmpeg acrossfade filter

4. **Viewer integration** (in HTML viewer JS):
   - Create 3 `<audio>` elements for the 3 intensity levels
   - Use Web Audio `GainNode` per track
   - On tier change: fade out current track's gain over 500ms, fade in new track's gain
   - Drama score drives gain node `.value` property via `linearRampToValueAtTime`

5. **Add tests in `tests/test_hype.py`**:
   - `select_hype_track("calm")` returns ambient config
   - `select_hype_track("chaos")` returns peak config
   - `build_hype_timeline` produces crossfade events on tier transitions
   - No crossfade events when tier stays constant

# Acceptance Criteria

- [ ] Music intensity matches current drama tier (ambient for calm, peak for chaos)
- [ ] Smooth crossfade between intensity levels (500ms transition)
- [ ] Video renderer outputs correct hype track volume curve via ffmpeg
- [ ] Viewer gain node follows drama score with smooth transitions
