# Objective

Create a pure stat diff computation module that compares a player's lifetime averages against their current match stats and classifies each stat as improved, regressed, or neutral with delta values.

# Implementation Plan

1. Create `data/stat_diff.py` with a `compute_diff(lifetime_avg, current_stats)` function
2. For each stat key present in both dicts, compute the raw delta (`current - lifetime`)
3. Compute percentage delta relative to the lifetime average
4. Classify each stat: "improved" if delta > 0, "regressed" if delta < 0, "neutral" if delta == 0
5. Return a dict keyed by stat name, each value containing `classification`, `delta`, and `percentage`
6. Write tests in `tests/test_stat_diff.py` covering normal, zero-delta, and edge cases

# Acceptance Criteria

- [x] `compute_diff(lifetime_avg, current_stats)` returns a dict with each stat marked improved/regressed/neutral
- [x] Each stat entry includes `delta` (raw numeric difference) and `percentage` (percent change)
- [x] Function is pure -- no I/O, no side effects, no file reads
- [x] Handles stats present in one dict but not the other gracefully
- [x] All tests in `tests/test_stat_diff.py` pass
