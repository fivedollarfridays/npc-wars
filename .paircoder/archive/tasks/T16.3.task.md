# Objective

Create a diff overlay HTML component in the match viewer that displays lifetime average vs. current match stats after a match ends.

# Implementation Plan

1. Add a hidden overlay `<div>` to `viewer/match.html` positioned at the bottom 40% of the viewport
2. Structure the overlay with two columns: LEFT "Lifetime Average", RIGHT "This Match"
3. Each row displays: stat name, old value (lifetime), new value (current), delta arrow
4. Add CSS for slide-up animation triggered when the match ends
5. Add a "Continue" button that dismisses the overlay
6. Wire overlay display to the match-end event in the viewer JS

# Acceptance Criteria

- [x] Diff overlay slides up from the bottom after match ends, occupying bottom 40% of viewport
- [x] Two-column layout: LEFT "Lifetime Average", RIGHT "This Match"
- [x] Each row shows stat name, old value, new value, and delta arrow
- [x] "Continue" button dismisses the overlay
- [x] Overlay reads data from `matchData.diff` in the match JSON
- [x] Changes contained within `viewer/match.html`
