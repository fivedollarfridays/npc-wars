# Objective

Implement a glitch spectacle effect for storm kill events, applying a CRT-style visual distortion to convey the chaos of a storm elimination.

# Implementation Plan

1. Define a CSS class (e.g. `.glitch-effect`) with CRT-style distortion: RGB channel offset via `filter` or `mix-blend-mode`, horizontal scanline overlay
2. Create a `glitchEffect()` function in `viewer/match.html` that applies the glitch class to the battlefield container
3. Duration: 0.4 seconds, then remove the class to restore normal rendering
4. Use CSS `@keyframes` for the RGB offset animation (red/blue channel shift 2-4px)
5. Add a scanline pseudo-element overlay that appears during the effect
6. Wire the glitch effect to storm_kill events in the match playback logic

# Acceptance Criteria

- [x] Storm kill events trigger a CRT-style glitch distortion effect
- [x] Effect includes RGB channel offset (red/blue shift)
- [x] Effect includes scanline overlay
- [x] Effect duration is approximately 0.4 seconds via CSS filter/animation
- [x] Effect cleans up after completion (no lingering visual artifacts)
