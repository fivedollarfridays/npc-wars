# Objective

Add archetype classification to bots and track matchup records (win/loss vs each archetype type).

# Design

Archetype inference from stat allocation:
- Dominant stat > 35 → named after that stat
- Two stats > 30 → hybrid name
- All stats 20-30 → "Balanced"

| Classification | Rule | Name |
|---------------|------|------|
| POWER > 35 | Highest stat | Bruiser |
| SPEED > 35 | Highest stat | Assassin |
| ARMOR > 35 | Highest stat | Tank |
| MIND > 35 | Highest stat | Controller |
| All 20-30 | Balanced | Balanced |
| Two > 30 | Hybrid | e.g., "Power/Armor" |

# Implementation Plan

1. Create `engine/archetype.py`:
   - `classify_archetype(stats: StatAllocation) -> str` — returns archetype name
   - `ARCHETYPE_NAMES` dict for display

2. Add archetype to match JSON:
   - In `_finalize_match()` or match_writer, add `archetype` field to each player's stats
   - Archetype computed from stat allocation at match start

3. Create `data/matchup_stats.py`:
   - `compute_matchup_profile(bot_emoji, results_dir) -> dict[str, dict]`
   - Scans match JSONs, groups opponents by archetype
   - Returns: `{"Tank": {"wins": 2, "losses": 5, "rate": 28.6}, ...}`

4. Add matchup section to diff display:
   ```
   ── Matchup Profile ──
   vs Tank:    2W / 5L (28%) ▼ weak
   vs Assassin: 4W / 2L (67%) ▲ strong
   vs Balanced: 3W / 3L (50%) ─ even
   ```

5. Tests in `tests/test_archetype.py`

# Acceptance Criteria
