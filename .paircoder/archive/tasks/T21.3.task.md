# Objective

Wire bot memory loading and saving into the match lifecycle so memories persist between matches automatically.

# Implementation Plan

1. In `engine/game.py: _prepare_match()`, add optional `memory_dir: str | None` parameter
2. Before creating bots, load all bot memories via `load_all_memories(memory_dir)`
3. Attach each bot's memory to its config dict: `config["memory"] = memories.get(emoji, {})`
4. In `engine/game.py: _finalize_match()`, add memory saving:
   - For each bot, call `save_bot_memory(bot.emoji, bot.memory, memory_dir)`
   - Only save if memory_dir is provided (skip for tests that don't want persistence)
5. Thread `memory_dir` through `run_match()` and `run_match_async()` as an optional parameter
6. In `play.py`, pass `memory_dir=Path(project_dir) / "data" / "bot_memory"`
7. In `npcwars/cli/cmd_play.py` and `cmd_battle.py`, pass memory_dir

# Acceptance Criteria

- [x] `run_match()` accepts optional `memory_dir` parameter
- [x] Bot memories loaded from disk before match starts
- [x] Bot memories saved to disk after match ends
- [x] Memory persists across two sequential `run_match()` calls
- [x] No memory saved when `memory_dir` is None (test isolation)
- [x] `play.py` wires memory_dir automatically
