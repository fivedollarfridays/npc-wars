# Objective

Keep the battlefield visible after the match ends. Show the final round state with the winner highlighted, then print a persistent summary to normal scrollback.

# Implementation Plan

1. **Add `render_final_frame()` to `TerminalRenderer`**:
   - Renders the last round's grid + roster
   - Highlights the winner's cell (bold/gold)
   - Shows "WINNER" label next to their roster entry
   - Still in alt screen

2. **Update `cmd_play.py` and `cmd_watch.py` endgame flow**:
   - After last round: render final frame, pause 2 seconds
   - Exit alt screen
   - Print to normal scrollback:
     - Winner banner
     - Final standings table (rank, emoji, name, kills, damage dealt, rounds survived)
     - Replay path

3. **Final standings data** — extract from `match_data["stats"]` and `match_data["eliminations"]`:
   ```
   Final Standings
   1. 🧠 Cognify      K:2 D:120 Survived: 38 rounds
   2. 🐢 TankBot      K:1 D:80  Eliminated: R38 (storm)
   3. 🪿 GooseLoose   K:1 D:150 Eliminated: R34
   ...
   ```

# Acceptance Criteria

- [ ] Final board state visible for 2 seconds after last round
- [ ] Winner highlighted on the final grid
- [ ] Alt screen exits, summary printed to normal scrollback
- [ ] Final standings show placement, kills, damage, elimination round
- [ ] Summary persists in terminal history after command completes
- [ ] Tests pass, ruff clean
