# Objective

Add a `npcwars play` command that validates bots, runs a match, and immediately renders the replay in the terminal — the complete experience in one command.

# Implementation Plan

1. Create `npcwars/cli/cmd_play.py` with `register()` and `run()` functions
2. Pipeline: validate all bots → run match → render in terminal
3. Accept `--bots-dir` (default: `bots/`), `--seed`, `--speed` (playback speed)
4. If validation fails, show errors and exit (don't run broken bots)
5. After match completes, automatically play back using `cmd_watch` logic
6. Save replay to `results/` and print the file path for re-watching
7. Print match summary after playback (winner, kills, stats)
8. Register in CLI dispatcher

# Acceptance Criteria

- [ ] `npcwars play` validates, battles, and watches in one command
- [ ] Validation errors shown before match runs
- [ ] Match plays back in terminal automatically
- [ ] `--seed` flag for reproducible matches
- [ ] `--speed` controls playback speed
- [ ] Replay saved to results/ for re-watching
- [ ] Registered in CLI dispatcher
