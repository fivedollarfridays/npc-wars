# Objective

Write an end-to-end integration test that runs two matches and verifies the second match JSON contains correct diff classifications and deltas.

# Implementation Plan

1. Create `tests/test_diff_integration.py`
2. Set up a temporary results directory with fixture data
3. Run (or simulate) Match 1 -- produces baseline stats, no meaningful diff (first match case)
4. Run (or simulate) Match 2 -- produces stats that differ from Match 1 averages
5. Load the Match 2 JSON and assert the `"diff"` key exists
6. Verify each player's diff contains correct classifications (improved/regressed/neutral)
7. Verify delta values and percentages are mathematically correct against the Match 1 baseline
8. Verify first-match case is handled correctly in Match 1 output

# Acceptance Criteria

- [x] E2E test runs 2 matches (or simulates their output)
- [x] Second match JSON contains `"diff"` key with per-player data
- [x] Diff classifications (improved/regressed/neutral) are correct relative to Match 1 averages
- [x] Delta values and percentages are mathematically accurate
- [x] First match output handles the no-history case without errors
- [x] Test is self-contained with temp directories (no side effects on real data)
