# Objective

Create a comprehensive PROMPT.md that users paste into any AI (Claude, Gemini, GPT, etc.) to generate a competitive NPC Wars bot. The prompt should produce working bots without the user needing to understand Python.

# Implementation Plan

1. Create `PROMPT.md` at project root with:
   - Game overview (battle royale, simultaneous resolution, last bot standing)
   - Complete state dict reference (what `decide(state)` receives)
   - All actions with costs and effects
   - Resolution order (defend → move → attack → storm → energy → deaths)
   - Key constants (HP, energy, attack power, storm timing)
   - The helpers API (`Me`, `Enemies`, `Storm`) with all methods
   - Winning strategies (priority ladder, defend-counter, energy denial, storm prediction, Watcher randomization)
   - Required bot file format (BOT_NAME, BOT_EMOJI, BOT_BIO, def decide)
   - 2-3 example bots at different skill levels
   - Explicit instruction: "Return ONLY the complete Python file, no explanation"
2. Test the prompt by pasting it into Claude and verifying the output passes `npcwars validate`
3. Keep under 3000 words — LLM context is precious

# Acceptance Criteria

- [ ] `PROMPT.md` exists at project root
- [ ] Contains complete state dict reference
- [ ] Contains all actions with costs
- [ ] Contains resolution order
- [ ] Contains helpers API reference
- [ ] Contains winning strategies
- [ ] Contains bot file format specification
- [ ] Contains 2-3 example bots
- [ ] Bots generated from this prompt pass `npcwars validate`
