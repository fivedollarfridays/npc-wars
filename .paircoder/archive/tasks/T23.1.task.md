# Objective

Restructure the `npcwars` package into the `agentgrounds` platform layout. The platform CLI is `agentgrounds`, each game is a subcommand group. This game becomes `agentgrounds wars`.

# Context

Agent Grounds (`agentgrounds.ai`) is the multi-game platform. Each game lives under `agentgrounds/{game}/`. The CLI pattern is `agentgrounds {game} {command}`:

```
agentgrounds wars play
agentgrounds wars watch
agentgrounds wars generate
agentgrounds race play    ← future
agentgrounds kitchen play ← future
```

Package layout after rename:

```
agentgrounds/
  __init__.py
  __main__.py             ← platform CLI dispatcher
  wars/                   ← current npcwars contents
    __init__.py
    __main__.py           ← wars subcommand group
    engine/
    cli/
    builtin_bots/
    helpers.py
    config.py
    presets.py
    _me.py
    _enemies.py
    _storm.py
    _util.py
```

# Implementation Plan

1. **Create platform package shell**
   - `mkdir agentgrounds/`
   - Create `agentgrounds/__init__.py` (empty or version stub)
   - Create `agentgrounds/__main__.py` — platform CLI dispatcher that routes `agentgrounds wars *` to wars subcommand group

2. **Move npcwars → agentgrounds/wars/**
   - `mv npcwars/ agentgrounds/wars/`
   - All sub-packages, `__init__.py`, and module files carry over (content updated in step 3)

3. **Update `pyproject.toml`**
   - `name = "npc-wars"` → `name = "agent-grounds"`
   - Entry point: `npcwars = "npcwars.__main__:main"` → `agentgrounds = "agentgrounds.__main__:main"`
   - Package discovery: update to include `agentgrounds` and `agentgrounds.wars`

4. **Update all Python imports**
   - `from npcwars.*` → `from agentgrounds.wars.*` across all files in `agentgrounds/`, `engine/`, `scripts/`, `tests/`
   - `import npcwars.*` → `import agentgrounds.wars.*`
   - Use scripted replacement — verify no `npcwars` references remain

5. **Wire wars subcommand group into platform CLI**
   - `agentgrounds/__main__.py` parses first arg as game name (`wars`, `race`, etc.)
   - Routes to `agentgrounds.wars.__main__:main` for `wars` commands
   - `agentgrounds wars play`, `agentgrounds wars watch`, etc. all work

6. **Update helpers API namespace**
   - Bot files in `bots/` and `agentgrounds/wars/builtin_bots/`: `from npcwars.helpers import` → `from agentgrounds.wars.helpers import`
   - Update `PROMPT.md`, `README.md`, `CONTRIBUTING.md`, `docs/` references

7. **Update config filename references**
   - `CONFIG_FILENAME` constant: `"npcwars.config.yaml"` → `"agentgrounds.config.yaml"`

8. **Update `.paircoder/config.yaml`**
   - `project.name`: `npc-wars` → `agent-grounds`

9. **Reinstall and verify**
   - `pip install -e ".[dev]"`
   - `agentgrounds wars --help` — verify subcommand works
   - `agentgrounds wars play --seed 42` — verify full match runs

10. **Run full test suite**
    - `python -m pytest` — all 2257 tests must pass
    - `ruff check .` — must be clean
