# Objective

Add canvas-rendered attack swoosh animations and death particle explosions to the match viewer for visual feedback on combat events.

# Implementation Plan

1. In `viewer/match.html`, add an attack animation system that triggers on `attack` events in the round data
2. Implement canvas-drawn slash/swoosh arcs (not CSS) originating from the attacker toward the target
3. Add a particle explosion system that triggers on `kill` events, spawning debris particles at the death location
4. Sync animation timing with the current game speed setting so animations scale with playback speed
5. Integrate both systems into the existing `requestAnimationFrame` render loop
6. Ensure animations do not block or interfere with the main battlefield rendering
7. Test visually by running a match replay and confirming animations appear at correct moments

# Acceptance Criteria

- [x] Attack slash animations render on canvas (direct draw calls, not CSS) when attack events occur
- [x] Death particle explosions render on canvas when kill events occur
- [x] Animations are synced with the game speed setting
- [x] Animations are integrated into the existing render loop in `viewer/match.html`
- [x] Visual verification confirms animations appear at correct moments during replay
