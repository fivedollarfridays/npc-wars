# Objective

Enforce line budget in the AST scanner by counting `decide()` function body lines. Only lines inside `decide()` count -- blank lines, comments, and docstrings are excluded. Bots exceeding their budget are rejected at validation time. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 8 (Enforcement, Line Counting Rules).

# Implementation Plan

1. **Create `tests/test_line_enforcement.py`** with tests for:
   - `count_decide_lines` on a minimal decide function
   - `count_decide_lines` skips blank lines
   - `count_decide_lines` skips comment-only lines
   - `count_decide_lines` skips docstring lines
   - `validate_line_budget` passes when count <= budget
   - `validate_line_budget` raises `BotValidationError` when count > budget
   - Semicolon chaining on a single line is rejected

2. **Add to `engine/bot_scanner.py`**:
   - `count_decide_lines(source: str) -> int` -- parse AST, find `decide` function def, count body lines excluding blanks, comments, and docstrings
   - `validate_line_budget(source: str, budget: int) -> None` -- raises `BotValidationError` if `count_decide_lines(source) > budget`

3. **Wire into `scan_bot_file()`** with an optional `budget: int | None` parameter. When provided, call `validate_line_budget` during scan.

# Acceptance Criteria

- [x] count_decide_lines counts only lines in decide() body
- [x] Blank lines and comment-only lines excluded from count
- [x] Docstring lines excluded from count
- [x] validate_line_budget raises BotValidationError when count > budget
- [x] No semicolon chaining (enforced by existing AST rules or new check)
