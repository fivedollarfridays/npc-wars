# Objective

Create the frequency counter data structure that stores human behavioral patterns observed by The Watcher. The pattern table is a per-player frequency map keyed by context (e.g., "after_damage", "at_range_1") that records how often each action is taken. This is the core data structure for The Watcher's prediction engine. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (The Pattern Table).

# Implementation Plan

1. **Create `tests/test_pattern_table.py`** with tests for:
   - Empty `PatternTable` returns empty dict from `predict()` for unknown player
   - `record(player_id, context, action)` increments the counter for that triple
   - Multiple records for same (player, context) accumulate correctly
   - `predict(player_id, context)` returns probability distribution (dict of action -> float, summing to 1.0)
   - Different players have isolated profiles (recording for player A does not affect player B)
   - `__global__` profile is updated on every `record()` call alongside the per-player profile
   - Supported contexts: `"after_damage"`, `"at_range_1"`, `"below_30_hp"`, `"storm_closing"`, `"override_detected"`

2. **Create `engine/watcher_memory.py`**:
   - `CONTEXTS = ["after_damage", "at_range_1", "below_30_hp", "storm_closing", "override_detected"]`
   - `GLOBAL_PROFILE = "__global__"`
   - `PatternTable` class with:
     - Internal storage: `dict[str, dict[str, dict[str, int]]]` (player_id -> context -> action -> count)
     - `record(player_id: str, context: str, action: str) -> None` — increments counter for both `player_id` and `__global__`
     - `predict(player_id: str, context: str) -> dict[str, float]` — returns normalized probability distribution; empty dict if no data
     - `get_raw_counts(player_id: str, context: str) -> dict[str, int]` — returns raw frequency counts
     - `players() -> list[str]` — returns all tracked player IDs (excluding `__global__`)

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] PatternTable stores per-player frequency data
- [ ] record() increments counter for (player, context, action)
- [ ] predict() returns probability distribution
- [ ] Players have isolated profiles
- [ ] Global aggregate (__global__) also updated on every record
