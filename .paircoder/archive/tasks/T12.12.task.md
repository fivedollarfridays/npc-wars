# Objective

Track The Watcher's lifetime stats publicly as part of the community narrative. Stats include total matches, kill counts (human vs bot breakdown), deaths, win rate, current streak, and per-player encounter history. Stats persist across sessions alongside the pattern table. Depends on T12.1. Reference: docs/RESEARCH-spectacle-and-human-play.md Section 7 (Kill/Death Tracking).

# Implementation Plan

1. **Create `tests/test_watcher_stats.py`** with tests for:
   - `WatcherStats` initializes with all counters at 0
   - `record_kill(victim_type="human")` increments `human_kills` and total `kills`
   - `record_kill(victim_type="bot")` increments `bot_kills` and total `kills`
   - `record_death()` increments `deaths`
   - `record_match(won=True)` increments `matches` and updates `win_rate` and `current_streak`
   - `record_match(won=False)` resets `current_streak` to 0
   - Per-player encounter tracking: `record_encounter(player_id, won)` updates encounter count and per-player win rate
   - Stats survive save/load roundtrip (serialization)

2. **Add to `engine/watcher_memory.py`**:
   - `WatcherStats` dataclass with fields:
     - `matches: int = 0`
     - `kills: int = 0`, `human_kills: int = 0`, `bot_kills: int = 0`
     - `deaths: int = 0`
     - `win_rate: float = 0.0`
     - `current_streak: int = 0`
     - `encounters: dict[str, dict] = {}` — per-player `{"count": int, "wins": int}`
   - Methods: `record_kill`, `record_death`, `record_match`, `record_encounter`
   - `to_dict()` and `from_dict(data)` for serialization
   - Save/load alongside pattern table in the same JSON file or a separate `data/watcher_stats.json`

3. **Run tests and verify** all pass

# Acceptance Criteria

- [ ] Lifetime kill count tracked (human vs bot breakdown)
- [ ] Death count tracked
- [ ] Per-player encounter count and win rate
- [ ] Stats persist across sessions
