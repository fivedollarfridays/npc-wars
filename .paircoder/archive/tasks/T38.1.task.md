# Objective

Create `agentgrounds/wars/cli/diff_display.py` — formatters for the post-match diff view and progression display. This is the core visual of the product: "the diff IS the game."

# Design (from proposal mockup)

```
┌─────────────────────────────────────────────┐
│              MATCH COMPLETE                  │
│                                              │
│  Your Bot: ◆ Wraith                         │
│  Result:   2nd place — 3 kills, 22 rounds   │
│  Score:    52 pts (peaked: Tier 3)           │
│                                              │
│  ── Stats vs Lifetime Average ──            │
│  Win Rate:    35% → 38%  ▲ +3%             │
│  Avg Kills:   1.8 → 2.4  ▲ +33%           │
│  Avg Survived: R18 → R22  ▲ +22%           │
│  Damage/Round: 8.2 → 11.4 ▲ +39%          │
│                                              │
│  ── Progression ──                          │
│  Level 7 → 8  (+85 XP)                     │
│  🔓 UNLOCKED: taunt action                  │
│  Next unlock: trap (Level 12, 1600 XP away) │
└─────────────────────────────────────────────┘
```

# Implementation Plan

1. Create `agentgrounds/wars/cli/diff_display.py`:
   - `format_diff_summary(bot_name, bot_glyph, match_stats, diff_data, xp_data) -> str`
     - Header: bot name, placement, kills, rounds, score
     - Diff section: compare lifetime avg vs current for win_rate, avg_kills, avg_survived, damage_per_round
     - Use ▲ green for improved, ▼ red for regressed, ─ for neutral
     - ANSI color codes for visual impact
   - `format_progression(xp_data, current_level, new_level) -> str`
     - Level change line
     - Newly unlocked actions/callbacks
     - Next unlock preview (from levels.py)
   - `format_match_complete(all_data) -> str` — combines everything into the boxed display

2. Use existing infrastructure:
   - `data/stat_diff.py` `compute_diff()` — already returns per-stat classification/delta/percentage
   - `data/lifetime_stats.py` — already aggregates match history
   - `engine/levels.py` `unlocks_at_level()` — shows what's available at each level

3. Tests in `tests/test_diff_display.py`

# Acceptance Criteria

- [ ] Diff formatter shows lifetime avg vs current with ▲/▼/─ indicators
- [ ] Progression shows level change, unlocked items, next unlock
- [ ] First-match players get "First match!" message instead of diff
- [ ] ANSI colors for improved (green) and regressed (red)
- [ ] Boxed display matches proposal mockup style
- [ ] Tests pass, ruff clean, < 400 lines
