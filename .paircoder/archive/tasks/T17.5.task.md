# Objective

Create the `GET /api/stats/{player_id}` and `GET /api/leaderboard` endpoints that expose player lifetime statistics and ranked leaderboard data.

# Implementation Plan

1. Create `server/routes/stats.py` with both routes
2. `GET /api/stats/{player_id}` calls into `data/lifetime_stats.py` to return lifetime averages (wins, kills, accuracy, etc.)
3. `GET /api/leaderboard` calls into `data/leaderboard.py` to return the ranked player list
4. Return 404 if player_id not found in stats
5. Register router on the main FastAPI app

# Acceptance Criteria

- [x] `GET /api/stats/{player_id}` returns lifetime averages for the given player
- [x] Returns 404 when player_id is not found
- [x] `GET /api/leaderboard` returns a ranked list of players
- [x] Both endpoints reuse existing `data/leaderboard.py` and `data/lifetime_stats.py` modules
- [x] Router registered on the main FastAPI app
