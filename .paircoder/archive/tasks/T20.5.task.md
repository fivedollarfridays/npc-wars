# Objective

Create a well-commented starter bot template that teaches by example. Each decision point has a TODO with suggested modifications and explanations. Designed for both human learners and AI agents to use as a base.

# Implementation Plan

1. Create `bots/starter.py` — a bot that works out of the box but is designed to be tweaked
2. Structure as a clear priority ladder with numbered comments:
   - Priority 1: Storm escape (TODO: try pre-positioning 2 rounds early)
   - Priority 2: Energy management (TODO: experiment with threshold — try 30 vs 50)
   - Priority 3: Kill finishing (TODO: change HP threshold for "killable")
   - Priority 4: Defense (TODO: try always defending when adjacent to 2+ enemies)
   - Priority 5: Hunt wounded (TODO: adjust wounded threshold and chase distance)
   - Priority 6: Positioning (TODO: try different target selection — closest vs weakest)
   - Priority 7: Idle behavior (TODO: try pure random vs defend-heavy for anti-Watcher)
3. Each TODO block should include:
   - What the current behavior does
   - 2-3 alternative approaches to try
   - What to observe when testing the change
4. Bot should be competitive enough to win ~20% of matches against built-in bots
5. Update `npcwars/builtin_bots/` to include starter.py

# Acceptance Criteria

- [ ] `bots/starter.py` exists and passes `npcwars validate`
- [ ] Each priority level has a commented TODO with alternatives
- [ ] Bot wins ~20%+ of matches against built-in bots (test with 10 seeds)
- [ ] Comments explain the "why" not just the "what"
- [ ] Bot uses the helpers DSL (Me, Enemies, Storm)

# Verification

```bash
npcwars validate bots/starter.py
```
