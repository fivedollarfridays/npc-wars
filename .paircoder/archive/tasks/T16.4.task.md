# Objective

Inject diff data into the match JSON output so the viewer can read per-player stat diffs from `matchData.diff`.

# Implementation Plan

1. In `engine/match_writer.py:build_match_data()`, import `compute_diff` from `data/stat_diff.py` and `get_lifetime_stats` from `data/lifetime_stats.py`
2. After building match stats, compute lifetime averages for each player
3. Call `compute_diff(lifetime_avg, current_stats)` for each player
4. Add a `"diff"` key to the match JSON output, keyed by player emoji
5. Update `engine/game.py` if needed to pass `results_dir` to the match writer
6. Write or update tests to verify the `"diff"` key appears in output JSON

# Acceptance Criteria

- [x] Match JSON output contains a `"diff"` key with per-player diff data
- [x] Each player's diff entry includes classification, delta, and percentage for each stat
- [x] Viewer can access diff data via `matchData.diff`
- [x] Reuses `build_match_data()` from `engine/match_writer.py`
- [x] All existing tests continue to pass (no regressions)
